# 武功山全程 3D 地图

> **已归档为实验。** 2026-10-18 用户确认项目主线为 **2D + 精细手绘水彩 + 旅途手帐收集**，详见 [游戏理念与设计美学约定](game-design-charter.md)。本页记录的三维地图、人物、路线与验证结果仅用于技术参考，不接入主流程，也不应继续扩展。

2026-10-18，开发始于10月17日。用户明确要求完成整张武功山地图的 3D。本轮将草甸试片扩为东江村经典反穿全程，观音宕／星空营地过夜，第二天经吊马桩登金顶，再从景区下山至大门。只处理武功山，未发布、未提交，也不改写已有手帐。

本地入口：<http://127.0.0.1:8000/wugong-3d.html>。原 `wugong-meadow.html` 也展示当前完整版本。主页面原有武功山快捷入口已指向新地图；原二维行走页保留，并增加立体山路入口。

## 已实现

全程使用 Three.js 的同一套坐标与光照，包含山脚村落、森林山路、草甸弯道、营地、连续山脊、金顶石碑及景区下山后的门楼。路径保持真实地点的先后关系，位置与山形经过艺术化调整，不能作为导航。

全程长约 751.34 场景单位，覆盖爬升和下降，使用统一的三角形地表高度。道路、草根与人物鞋底共用该地表；村落、营地和山顶做了局部缓坡整理。远处地形在原高程数据边界外补了示意支脊，消除边界横向拉伸形成的平面条带；这些补形不称为真实测绘。

近景继续使用 three-stylized 的 GrassLayer。草甸按 24 单位见方分块，只保留人物周围最多九块，一帧最多建立一块；全图用完整山体与地表颜色显示草甸。云雾边缘按视角渐隐，保留山脊可见。全图另用 Three.js Line2 保持道路清楚。进入默认随行，地图右上角由用户主动切换全图。

林带、石块与营地使用 Kenney 的 CC0 模型。Nature Kit 的两种绿色树木沿低处和林缘成片布置，Survival Kit 提供帐篷、石块、路牌和倒木。使用实例化重复绘制；人物继续使用 Quaternius 背包角色及作者 Walk / Idle。山体、人物和景物统一为草木绿、灰褐色与低反光材质。

刚性鞋子的新版本去掉了原模型鞋底上的小腿混合权重，分别绑定到现有 Foot 控制骨骼。步幅与播放相位跟随实际位移，腿部使用标准 CCDIKSolver 适配地表，鞋底按模型顶点检查接触。本轮没有新增作者现成的上坡、下坡或坐下动画。

东江村、绝望坡、高山草甸、观音宕营地、吊马桩、金顶和景区大门使用统一大小的纯图标。图标按三维位置投影，随行时只显示附近可见地点，全图会避让重叠。可提前查看介绍，提前查看不算抵达；实际走到会自动停步并展开真实照片与来源。营地停留后通过“第二天 · 出发”继续，景区大门之后结束全程。页头也可从营地进入第二天；跳过的第一天地点不会记成已抵达，重走按钮仍回到东江村。

照片沿用此前已有许可与署名的武功山实景，不把区域照片改称定点照片。卡片保留地区说明、作者、原始出处和许可；加载失败可重试，也可继续阅读和退出。新地图没有新建手帐记录或自动发放奖励。

时间与天气复用原武功山的 SceneEnvironment。白天、黄昏、营地夜色、第二天晨光与下山过程连续变化，影响天空、雾、光线、草动、星点与小雨。左上角可选择时光、天气和行程速度。1× 为默认，2× / 4× 供快速浏览全程。切后台暂停，照片打开时暂停行进与环境时钟。

## 源码与可重复处理

- `src/wugong-meadow/terrain.ts`：全程地表、道路、地点与空间索引。
- `journey.ts`：启程、行走、照片、营地、第二天和终点状态。
- `assets.ts` 与 `vegetation.ts`：现成模型加载与实例化、近景草甸分块。
- `scene.ts`：山地、地标、天气、相机与道路。
- `main.ts` 与 `landmarks.ts`：页面控件、地点图标和实景卡片。
- `src/wugong-walk/environment.ts`：天气时钟的输入改为最小结构接口，原二维调用仍使用同一行为。
- `scripts/art/vendor-wugong-environment.py`：从作者 ZIP 按范围获取选定树木及许可，按 ZIP CRC 检查缓存。
- `scripts/art/prepare-wugong-environment.mjs`：保留模型形状，将调色板转换为顶点色，统一哑光材质。帐篷合并作者匹配的骨架与布面，并保存为新文件 `tent-v2.glb`。七个环境 GLB 合计 88,680 字节，无运行时图片解码依赖。
- `scripts/art/prepare-wugong-hiker.mjs`：生成新文件 `wugong-adventurer-v2.glb`，约 1.06 MB，保留旧版文件与来源。

许可和处理记录位于 `art/wugong-environment/`、`art/wugong-hiker/provenance-v2.json`，站点的“素材与组件来源”有对应署名。Nature Kit 的个别模型原用 unlit 材质，当前统一使用场景光照；Survival Kit 的恒定调色板 UV 已烘成线性顶点色。

## 验证

沿用用户已授权的武功山全程行走与事件验证范围。严格 TypeScript 编译与 bundle 构建已完成。

`node scripts/check-wugong-meadow.mjs` 检查实际地形的 654 个道路顶点和 81 个行走位置。射线直接检测原始网格的对应三角形，道路顶点离地 0.035 单位，最大误差小于 0.000009，通过。

`node scripts/check-wugong-hiker.mjs` 使用实际 GLB、AnimationMixer、CCDIKSolver 与 CPU 蒙皮顶点模拟完整行走。已检查 930 个鞋子顶点、6,453 个姿态采样，包括停步和重置；未发现低于路面的鞋底采样，最大支撑间隙约 0.0449 单位。该结果是几何检查，不代表所有腿部穿插或视觉问题已消除。

`node scripts/check-wugong-full-route.mjs` 以实际状态机完整走到终点。七个事件顺序与第一／第二天一致，照片暂停、营地休息、回看早先照片、第二天出发、终点停止和重走通过。详细记录位于 `docs/previews/wugong-full-3d/`。

真实浏览器中已从东江村经过七个地点走到景区大门，进度 100%，结束状态为 finished，按钮变为“再走一遍”。开头以默认 1× 查看行走，随后使用页面可见的 4× 行程速度完成全程。照片实际加载成功；营地停留后由按钮进入第二天，未通过注入状态或传送完成。记录见 `browser-events.json` 及对应截图。

全程检查开始后，另修复了帐篷缺少布面的问题、软化云雾边缘，并补回公开的“从营地出发”入口。这些更新在另一个加载当前构建的营地页面复查，完整帐篷、第二天起步与照片回看通过。营地回看按钮会恢复原状态，不会在第二天误导为再次过夜。新起点图标可直接触发启程事件。

真实浏览器分别检查 390 × 844 与 320 × 740 视野，无横向溢出；主要行走与视角按钮高 44 像素，照片卡片能显示、退出，关闭按钮位于内部滚动区域之外。全图、默认跟随和按钮返回通过。控制台未读到错误或警告，临时屏幕尺寸在交付前还原。截图和尺寸记录同在 `docs/previews/wugong-full-3d/`。

未发布，尚未执行实体手机、听感或 GPU 性能验收。营地目前是停步与过夜流程，尚未补坐下、卸包和喝水动作；本轮没有给新地图接入配乐。

交付预览保持默认随行；全图截图用于查看整张地图，不把全图保存为默认视角。
