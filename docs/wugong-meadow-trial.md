## 已实现的场景

试片沿用武功山高程与既有路线数据，截取草坡上行、草甸弯道到营地的一段。山体与自然比例的背包人物都由 Three.js 绘制，共用方向光、雾色和克制的草木色。人物直接复用工程已有的 `createMountainHiker`，没有改动其原调用路线。

草甸接入 [three-stylized](https://github.com/Steve245270533/three-stylized) 的 `GrassLayer`，固定到 `8eb0dde5a8e7eae985d69f923b627b0cf253bed5`。该组件是 MIT 开源小组件，不称为成熟的大型引擎。工程已有的 Three.js 保持 0.186.1，没有新增 React、Vite 或另一套应用脚手架。

近处草叶通过实例化绘制，共用风动着色器。覆盖权重避开道路与营地，在场边渐退，陡处露出岩色。接入层缩短草叶、降低反光，并把生长方向向竖直方向修正，保留坡面根部坐标。雾与颜料色差通过材质适配加入，上游源码保持原样。

可见近地面以 0.45 场景单位细分。道路、草根、人物位置共用该网格的三角形高度插值，避免道路被另一套粗网格盖住。小人沿路线爬升、转弯并走到营地，末端停步。本试片没有营地坐下或景点照片弹窗，不将原行走页的事件写成新试片已接入。

进入时默认跟随。地图右上角保留跟随和全图切换，仅主动点击全图时拉远。底部可停步、继续、重走和关闭山风。切后台暂停画面与行进，减少动态效果设置冻结草动和人物次级摆动。

## 源码与来源

- `src/wugong-meadow/terrain.ts`：原地形和路线适配、共同地表、道路与草甸权重。
- `src/wugong-meadow/scene.ts`：Three.js 场景、第三方草层、材质适配和相机。
- `src/wugong-meadow/main.ts`：独立试片控制与生命周期。
- `dist/wugong-meadow.html` 与 `dist/wugong-meadow.css`：页面与窄屏布局。
- `scripts/art/vendor-wugong-grass.mjs`：固定源码下载、Git blob 校验及来源记录，不运行第三方安装脚本。

`src/vendor/three-stylized/provenance.json` 记录固定版本与源码散列。组件、其原始参考项目 [stylized-components](https://github.com/cortiz2894/stylized-components)、Three.js 和原地形署名均保留在预览页的来源入口中。没有新增外部模型或图像贴图。

## 本轮实际检查

沿用已授权的武功山行走与场景检查范围。`npm run build` 已完成，TypeScript 严格编译与独立浏览器 bundle 生成通过。

真实浏览器发现并修复了道路被粗地表遮住的问题。随后查看草坡、人物落脚和连续弯道；草叶不再使用原 Canvas 尖草簇。已检查默认跟随、主动切换全图、停步与继续、山风开关，以及 390 和 320 像素视野的按钮边界。两种窄屏均无横向溢出，控制按钮高 44 像素。

真实浏览器中，人物已从试片起点经过上坡、弯道走到营地，进度为 100%，行走状态变为停止，主按钮切换为“再走一遍”。记录为 `docs/previews/wugong-meadow-trial/arrival.json` 与同目录截图。末端只停步，没有自动发放手帐或奖励。抵达检查后修正了帐篷屋面绕序和全图取景，随后检查新 bundle 的场景展开、视角切换和重走入口，没有再次重复整段行走。

`node scripts/check-wugong-meadow.mjs` 以真实 Three.js 网格和垂直射线检查 298 个道路顶点及 81 个行走位置，通过。道路离可见地表 0.035 场景单位，最大误差小于 0.000005。该脚本不模拟 WebGL，也不替代浏览器和 GPU 验收。

未执行其他路线回归、实体手机、听感或 GPU 性能验收。本次没有音频接入。预览临时屏幕尺寸已还原。
