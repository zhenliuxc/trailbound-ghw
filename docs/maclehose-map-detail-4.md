# 麦理浩径地图细化

2026-10-20。用户在上一轮集中验收后要求“优化地图细节”。本轮只修改麦理浩径地图的绘制，不调整路线顺序、地点坐标、照片、小游戏规则或手帐数据。沿用已获得的麦理浩径测试授权。未提交、推送或发布。

## 实际改动

- 复用 PixiJS 8.22 的 `GraphicsPath`、批量图形和正反遮罩；没有引入新引擎或整幅底画。
- 西湾山、大浪坳增加相连支脊、浅色坡面、沟谷和细坡线。远处山坡以更浅的颜色区分，坡脚采用曲线收束。
- 浪茄、西湾、咸田湾的沙带沿实际绘制的海岸边界展开，补湿沙线、砂粒和岸边碎石。修正沙滩尖角、描边平切端点与坡面直截边。
- 添加低矮灌丛、局部林地和贴地草丛，避开山径；路侧岩石按坡度分布。石阶改为疏密有别的小组，避免整段出现规则格子。
- 西湾、咸田湾与赤径补小型屋舍和院落；赤径内湾补码头、木板、系桩和两条小船。它们是示意性绘制，不是建筑实测还原。
- 外海用浅水色带与细浪，内湾用小幅倒影。海面与浪线通过反向海岸遮罩限制在水中。全图弱化细碎纹理，随行恢复细节浓度。

修改源文件为 `src/maclehose-walk/terrain.ts`、`scene.ts`，入口 `dist/maclehose-walk.html` 更新资源版本为 `coast-detail-4`。`dist/maclehose-walk.js` 由构建生成。
