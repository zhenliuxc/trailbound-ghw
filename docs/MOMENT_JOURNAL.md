# 沿途瞬间手帐 · 未发布改动

手帐记录虚拟旅程中遇见的一片云、一抹光、一次动物相遇，以及自己停留的感受。每页保留所属路线、山野情境、当时天气、旅程时间与记录日期，不再对应照片打卡点。

- 武功山：草尖上的小鸟、擦过草脊的云、照亮草坡的阳光。
- 虎跳峡：高路转角的山羊、越过江谷的飞鸟、金沙江上的一瞬水光。
- 秦岭 / 太白山：薄雪里的小脚印、岩石上的一点绿、风雪之后落在石海上的阳光。

只展示已经记下的页，没有未收集的地点格子、完成率或必须写满的清单。记下瞬间不打断行走；错过没有惩罚。重走同一路线可以添加新的页，保留这一次的天气和时间。地点自然知识折叠在“这片山野”中，照片继续留在沿途相册。

这些瞬间是沿途插画和故事中的虚拟相遇，不以区域照片冒充现场快照。日期记录保存该页的时间。旧版本只保存过记录ID，没有日期、天气或现场内容，因此迁移时标为旧回忆并保持这些字段空缺。浏览器手帐采用v2记录格式，沿用原存储键，最多保留最近120页；存储不可用时仍可在当前页面记录。

一并保留照片性能修复：选路线时提前获取并解码本路线的三张照片，打开或重看时复用相同图片节点，避免私有站点的新图片请求延迟。预取失败可重试，正在加载或失败时仍可继续旅程。

按用户要求暂不部署；`npm run check`通过，106项Node自动测试全部通过，包含照片预取/解码/复用、三张地图的完整旅程、旧记录迁移、重复旅程和瞬间上下文保存。受管浏览器预览仍受proc挂载权限限制，真实移动端画面与加载耗时没有完成验证。
