# 武功山程序地图细化

2026-10-17。本轮只调整武功山。用户最新反馈是：不另标当前位置，所有地点图标大小一致，背景地图完整重新设计；此前默认全图、起终点图标与事件的要求继续保留。其他路线待讨论和确认后再继续。

## 本轮实现

- 移除“当前位置”标签、引线、左下说明卡及其布局占位。人物仍沿路线行走，原有旅程进度条继续显示行进进度。
- 武功山始终使用完整地图，取消该路线的跟随切换按钮。准备出发时直接展示地图，通过中庵起点图标或底栏出发按钮进入整装事件。
- 重画完整程序背景：山体从左下林缘向右上金顶抬升，草甸亮面、背阴坡、远谷、树林、路边草石和山谷云层分别绘制。道路位于山脊上，装饰在生成时避开道路。宽屏使用可用画幅布局山体与路线，树木、石块和图标保持各自比例。
- 路线使用十个构图节点生成平滑曲线，保留地点顺序和原进度锚点。展示位置是艺术化路线示意，不作为 GPS 坐标；真实路线数据、照片来源、事件进度和手帐内容没有改写。
- 中庵、山脊草甸、云海观景、金顶共用同一个图标构造器：44 × 44 CSS 像素底板、统一描边、48 像素触控区、统一字号和文字宽度。文字与图标一起避开人物和控件；起终点仍用山门和山峰旗帜区分。沿途照片与终点图标使用相同规格。
- 起终点接续已有事件：进度 0 的整装事件只触发一次；进度 1 先触发抵达事件，确认后展开金顶真实照片，收起照片后结束旅程。提前点击未来地点只显示介绍，不改变进度、不提前解锁照片。已抵达的草甸和云海图标可重看照片。
- 人物继续使用上一批的程序关节步态、帽檐、背包扣具、围巾与上坡姿态。小游戏、音频、真实照片和手帐流程沿用现有实现。

## 截图中的绘图问题

从源码定位到旧版武功山局部路径的数字替换会丢失分隔：例如紧凑写法 `Q-13-3-14-9` 中的负数被替换成正的世界坐标后，可能连成一个大数，产生越界尖刺。新绘图直接为每个点序列化 `x y`，不再对紧凑 SVG 路径做数字替换，也不调用同类转换的共享树木函数。武功山在场景构建时直接进入专用绘图分支，不叠加通用地形或边界替换；其余路线的绘图分支没有改动。
