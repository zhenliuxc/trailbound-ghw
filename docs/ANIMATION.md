# v0.9 动作、场景与过渡

## 人物表达

- 沿路行走：原关节步态保留，围巾随步伐轻摆；风雪中躯干略向前。
- 暂停观察：驻足远望，登山杖暂时收起，双脚保持着地。
- 照片打卡或重看：举起小相机；收起后恢复此前行走或暂停状态。
- 风雪情境：手臂护住衣领，表现寒意。没有把虚拟动作当作真实避险教学。
- 记住发现：1.2秒短手势，期间逻辑行走继续；结束恢复正常摆臂。
- 旅程结束：静态结束姿态，提前结束的回忆与文案仍保留平安主题。

## 地貌细节

草甸的草叶与蝶翼、峡谷的落叶与水光、雪地的浮雪、脚印与呼气，以及飞鸟均是代码绘制的虚构插画。脚印位置通过已有路线距离插值计算，位于人物身后，不修改参考轨迹。每段场景只有10至17个小型SVG演员，沿用当前相机；不是整屏录像或大型GIF。

环境、小景物、云雾和步态共用旅程时钟。暂停、照片/情境停留与切到后台时保持当前环境姿态，继续时不跳过时间。`prefers-reduced-motion`冻结这些环境运动并保留观察、拍照与完成旅程的功能。

## 界面过渡

- 情境/结尾卡片约0.38秒淡入，照片卡片约0.45秒入场。
- 收起照片有0.72秒的小照片归入旅程动画。
- 收集发现有1.05秒纪念条，切图有0.7秒轻雾淡出。
- 动效层设置`aria-hidden`和`pointer-events:none`，不获得焦点、不阻挡操作。
- 动画结束清理节点；快速换图时替换旧效果，旧结束事件不会清除新效果。
- 减少动态效果时不创建这些过渡，CSS同样停用关键帧。

照片卡片更紧凑，打开照片时镜头为人物留出上方空间。实机仍需检查小屏照片的署名、关闭和继续按钮是否易于查看；卡片内容可以滚动。

## 验证范围

74项Node.js检查通过，包含11项新增动画状态验证。六种人物姿态、三种场景经Sharp静态SVG渲染检查。最小DOM夹具不执行CSS关键帧或WebGL；真实浏览器动效衔接、320/390px设备布局、流畅度与能耗没有实测，不能以自动测试代替这些结果。所有新增实现由ChatGPT/Codex完成，没有Cursor操作记录。
