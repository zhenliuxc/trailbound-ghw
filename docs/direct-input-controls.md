# 画面直操、手绘提示与桌面适配 · 2026-10-16

用户要求：“所有游戏都可以直接鼠标或者手机操作，比如接雨水的向左向右的按键就完全冗余。”本轮以鼠标点击/拖动与触屏点击/滑动为主要操作，移除重复工具，不重做其他路线的玩法。

**用户已在本轮授权“测试，修复问题后发布”；集中验证和修复结果见 [发布记录](direct-input-release.md)。** 本批开发起点为版本 43，原来的 85 项结果不属于本轮修改。

必要的严格 TypeScript 构建已成功，生成 `dist/runtime.js`；[构建输出](previews/direct-input/build.txt) 明确未运行玩法、浏览器或音频测试。

## 操作与界面

| 玩法 | 画面上的操作 | 删除或保留 |
| --- | --- | --- |
| 竹筒接雨 | 轻点画面开始；电脑移动鼠标，手机按住滑动，让竹筒接住落滴 | 删除向左/向右及单独开始按钮；未开始时悬停不启动，切后台/退出不接收迟到操作 |
| 古道留痕 | 轻点画面中的脚印出发，等脚印亮起再点；下一脚移向另一侧 | 删除外置左右脚和开始按钮；脚印与命中区域共用位置，命中范围至少覆盖 44px 触控宽度；空白区域、按下后取消不算落脚；保留“慢一点” |
| 竹叶弹弓 | 按住纸叶向后拉，松手发射；力度与方向由拉动决定 | 删除发射按钮、角度/力度滑块及微调展开入口；纸叶有克制的抓取提示，实际弹道与完成条件不变 |
| 金顶石语拼图 | 拖动拼片到画框，也可先点拼片再点位置 | 保持原有直操，无旋转和重复确认面板 |
| 茶芽消除 | 点两片相邻叶形或滑动交换 | 删除“选中这片/与选中叶形交换”；提示、重排、撤回仍有独立作用，继续保留 |
| 纸鸢、拨云、溪流及其他路线轻互动 | 沿用已有画面点击/按住/拖动，不依赖方向按钮 | 没有为这些玩法新增按钮或改变奖励条件 |
| 邂逅拍照 | 拖动取景框，用鼠标/触屏点快门，查看并交付照片 | 快门、远近调整、重拍和剧情选择有各自作用，保留；本轮不声称新增双指缩放 |

莫干山周围只留一处即时提示、进度、声音、重试、退出和适用时的慢速设置，移除重复说明行和空工具栏。电脑、手机、短横屏分别安排舞台与提示区。键盘辅助仍保留，并放进可访问说明，不把键位文字作为主要玩法教学。

## 实现

- 公共控制器继续统一鼠标和触屏 Pointer Events；适配器可选择处理鼠标悬停，其他玩法不会因为新接雨的鼠标跟随而自动响应悬停。
- `mogan/rules.ts` 提供石阶和脚印位置，场景绘制与输入命中共同使用，按下/移动不直接判落脚，释放或键盘明确激活才处理时机。
- 移除 HTML 控件及对应事件绑定、状态更新、CSS，不只是把旧按钮藏起来。弹弓旧渲染适配路径也移除了数值面板与重复发射控件。
- 自然声音、实际完成判定、原画 ID 和手帐保存沿用；不新增导入、导出、清空或自动删记录。

## 本次集中验证范围

1. 电脑鼠标、手机触控完成接雨、点脚印、拉弓；验证没有方向/调参按钮也能完整操作和收藏。
2. 鼠标悬停不擅自开始、点击空白不判落脚、按下后取消不领奖、退出与后台正确停止，键盘辅助仍可用。
3. 拼图、消除、拍照及公共 Pointer Events 的相关回归；不无理由重复全套。
4. 实际浏览器查看手机/电脑/短横屏的留白、可点击范围和脚印时机；实体手机与听感单独记录。
5. 同批提示样式改造：溪流只引导下一处水口、石阶就绪时箭头与脚印变清晰、纸叶开始拉动后提示收起；检查箭头不挡操作，图片失败的铅笔降级可用，正常与减少动态效果均不残留旧提示。
6. 桌面适配：在 1280、1440、1920 和更宽窗口检查页边距、路线换行、地图高度和手帐列数；缩放窗口后地图、人物和交互位置保持一致，没有横向溢出。手机仍需回看，但本次没有改动手机断点。

已同步 `tests/mogan-ui-helpers.cjs`、相关 DOM 案例和 `scripts/test-mogan-browser.cjs`，后续脚本改用画面点击/拖动。手机尺寸的弹弓脚本使用 Chromium 原生触摸事件；实际执行结果和边界见本轮发布记录，不当作实体手机证据。

## 追加：水彩提示样式

用户反馈：“当前是一个黄色的椭圆，我希望更符合当前的画风。”本次替换溪流目标圈、石阶时机圈和纸叶抓取圈，主画作、玩法判定及之前的直操修改保留。

- 使用原创草木绿水彩箭头，保留自然纸边、颜料颗粒和米白衬边，约 12 KB；文件为 `sprites/hint-brush-v1.webp`，原始图和处理方式、哈希、实际箭尖锚点记录在同名 JSON 中。`scripts/package-hint-art.py` 仅裁去透明留白、等比缩放和 WebP 编码，不重绘原图。
- 溪流只提示下一处水口，开放式短水纹对应实际通过范围，不再摆三个黄色椭圆；同步去掉“金色水口”的旧说明。
- 石阶以水彩箭头指向当前脚印，等可落脚时箭头和鞋印一起变清晰；删除不断缩放的黄圈。纸叶只在待拉动时显示提示，拉动、飞行和完成后收起。
- 共用 `src/runtime/hint-art.ts` 管理 SVG / Pixi 画面。按真实箭尖锚点定位，提示层不接收指针；同一纹理和节点持续复用，不逐帧重建或请求素材。素材提前加入路线缓存，失败时保留铅笔箭头，主画面不用等它；减少动态效果时取消循环显隐。
- 场景内真实水纹、筒口水面和投影继续保留。本轮经用户授权后的测试与发布记录见 `direct-input-release.md`。

提示改造后的必要构建已完成，生成 `dist/runtime.js`、供旧场景使用的 `dist/hint-art.js` 与浏览器入口；[本次构建记录](previews/direct-input/hint-build.txt) 不代表测试或体验验收。

## 追加：桌面两侧留白

用户提供电脑截图，指出站点没有适应电脑屏幕、侧边留白过多。原因在于原来的 `main` 最大只有 1050px，页头最大 1120px，宽屏时外侧空白不断增加。

- 在 `dist/style.css` 的桌面断点（1024px 起）改为流动宽度，取消页头和正文的固定宽度上限，两者使用同一份 `clamp(24px, 3vw, 72px)` 页边距。
- 1440px 起七条路线排成一行，更窄桌面保持四列；路线名按可用空间设置字号，不改变既有水彩配色和卡片美术。
- 主地图高度按窗口高度自适应并设上下限，避免宽度增加后按旧纵横比无限拉高；继续使用现有基于实际容器尺寸的相机和 Pixi/SVG 坐标，未拉伸美术。
- 手帐标签墙按可用宽度自动增加列数，保留点击后图文详情的阅读尺寸。
- 初版修改桌面 CSS；集中浏览器截图发现主地图旧画幅仍产生内部空边后，增加 `map-viewport.ts`，将等比路线投影放入当前可见画幅，同步 SVG/Pixi 取景、标记/人物比例，并在调整窗口后合并重绘。手机概览和断点保留，先前的直操与手绘提示继续沿用。修复后已重新构建，定向复测与发布见本轮记录。
