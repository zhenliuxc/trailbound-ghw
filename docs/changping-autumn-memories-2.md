# 长坪沟十月彩林 · 四段手绘互动

## 范围与依据

用户在确认十月彩林的一日山谷徒步后，要求玩法简单、有趣，取消重复的让路机制，每一关都发圆形徽章。本轮“继续完成后续的游戏实施”按随后讨论的四关方案实施，只调整长坪沟。

地图保留 2D 示意图、两位可选 Q 版旅人和默认跟随。行程改为喇嘛寺出发、木骡子折返、回到喇嘛寺。钟面从 08:30 走到 16:30，是压缩后的游戏叙事，不是 GPS 计时或现实行程承诺。

地景参考[四姑娘山管理局长坪沟介绍](https://www.sgns.cn/understand/cpg)：栈道后为土路、马道及上下干海子，木骡子为开阔草甸；[红石阵介绍](https://www.sgns.cn/sign/cpg/4142-2021-10-17-12-13-29)说明红石阵位于两河口之后。示意图按森林、枯树滩、干海子、红石阵、木骡子的关系组织，不作为实地导航。

## 本轮实现

| 路段 | 游戏 | 操作与反馈 | 徽章 |
| --- | --- | --- | --- |
| 去程枯树滩 | 枯枝认影 | 对照纸上速写，分两次点选对应倒影；点错可直接重选 | 枯林水镜 |
| 去程干海子马道休息处 | 马铃解绳 | 先拖开上层绳头，再拖开下层绳圈；拉错只绷紧，解开后铃铛摆动与铃声回应 | 铃响山谷 |
| 木骡子林缘 | 画里有条路 | 上下移动一层前景纸页，对齐画中小径；松手后当前 Q 版旅人自动前行，站在开阔处 | 长谷见峰 |
| 返程下游彩林栈道 | 叶脉留秋 | 在覆叶纸面来回轻擦，显出秋叶；保留本局笔迹，完成后保存进徽章 | 一叶长坪 |

每关沿用发现线索、手绘展开、圆形徽章自动保存与淡回山路。未完成或跳过不发奖。地图没有小游戏按钮。三处原有实拍入口保留，区域配图标签仍明确说明范围；本轮没有补换定点实拍。

地图加入金黄、赭色落叶树，与常绿针叶树混合，草甸退绿；返程暖光增强。起点显示“起终点”，木骡子显示“折返点”。返程沿相同几何小径反向走，镜头前视点、人物朝向、坡度同步反向；照片和去程事件不会重复自动弹出。

## 实现边界

- `src/content/changping-memories.ts`：玩法标题、提示、徽章名称与记忆文案。
- `src/runtime/changping-memories/`：类型明确的四种状态、Canvas 水彩图层、输入适配；复用现有小游戏控制器、图片缓存、声音接口与收藏。
- `src/journey/day-route.ts`：增加可选原路往返行程，总路程与几何位置分开，其他日间路线默认仍为单程。
- `scripts/build-day-pages.mjs`：从内容生成旧目录所需的四条手帐元数据，旧条目与保存标识保留。
- `scripts/build-changping-art.mjs`：水彩素材 WebP 与备用圆形徽章构建。
- `src/runtime/mini-game-controller.ts`：在释放画布前读取完成结果，避免拓印捕获丢失；其他路线玩法不变。

本轮三张新水彩原图在 `art/changping-autumn-v1/`，部署素材与说明在 `dist/scenes/changping-autumn-v1/`。马道相遇是游戏创作，铃声为现有程序拟音；手绘山谷不冒充照片或精确峰形测绘。
