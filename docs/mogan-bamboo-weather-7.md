# 莫干山地图：雨后的竹林与古道

2026-10-22。接续九溪地图，用户要求继续莫干山。本轮落实已有湿润竹林剧本的地图表现，沿用莫干岭西坡、竹林、古道石阶、莫干岭口、林间步道、山涧、大坑侧山林的单向半日行程。

## 实现

| 路段与内容 | 地图处理 |
| --- | --- |
| 西坡与竹林 | 连续林底色叠加疏密不同的竹丛，竹竿有明暗与节环，叶片为细长成簇的形状；近景竹子围绕根部轻摆 |
| 雨歇后的林间 | 水珠从实际绘制的叶尖落下，落地出现小水纹；雨歇薄雾时仍保留部分滴水，晴后渐弱 |
| 古道石阶 | 沿同一条行走曲线铺短段不齐石阶，转弯留平台，路侧补苔石与少量旧叶；湿痕和石面微光随天气变化 |
| 莫干岭口 | 保留岭口开阔空间与原有歇脚石，近景竹群在这里留出间隔，便于辨认翻岭两侧的坡面 |
| 大坑侧山林与山涧 | 下行路段逐渐出现阔叶林与林隙斑光；溪道补谷地色差、汇流浅潭和绕石水纹，踏石仍落在原溪道交点 |

季节保持既有绿竹林设定，未把剧本中的“春末初夏”建议写入月份。天气顺序继续读取路线已有配置：细雨、雨歇薄雾、林隙微光，不在地形模块另设切换进度。地图为艺术化 2D 示意，新增竹丛、苔石和浅潭不表示定点实测。

三段小游戏、发现过渡、照片、圆形徽章和手帐存储沿用现有实现。没有新增地点或游戏标记。默认跟随、全图切换、Q 版角色及公共镜头继续复用。

## 复用与生命周期

- `landscape/bamboo.ts` 提供同一套静态竹丛与近景竹子绘制，并返回叶尖坐标；远处使用较少竹竿，近处保留细节。
- `landscape/mogan-path.ts` 从 `DayTrail` 获取石阶、平台、湿痕和路旁斑光坐标。
- `landscape/mogan-weather.ts` 通过 `LandscapeEffects` 使用统一时钟、天气与减少动态效果设置。照片、手帐、小游戏和后台暂停沿用宿主生命周期，节点随地图释放。
- 原九溪水纹提取为 `landscape/stream-motion.ts`，两图各自传入水道、急流石块和浅潭位置；九溪参数沿用，其他路线没有接入新效果。
- 减少动态效果时保留静止竹子、水珠和水纹；天气层切换到对应明暗，不播放摆动或落滴。
- 声音沿用已有莫干山竹叶、雨滴、石路和溪声配置，没有新增素材或改动音量。
