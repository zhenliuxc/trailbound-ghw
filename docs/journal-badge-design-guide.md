# 旅行手帐徽章 · 设计审美与制作规范

适用于七条路线完成小游戏后获得的手帐徽章，包括固定画作、保留玩家笔触或取景的画作，以及历史收藏的展示兼容。地图上的地点图标另见[地点图标规范](landmark-icon-design-guide.md)。

**设计目标：一枚圆形水彩小画，留下这段旅途中具体的一刻。画心有记忆，纸边有完整的收束，放进收藏墙时属于同一套手帐。**

圆形、每关独立、自动入帐和淡出是产品要求。下文的制作尺寸与动效时长是新稿基准，具体显示以公共组件和实际画面为准。

## 1. 徽章应留下什么

每枚徽章对应一个已完成的游戏事件，选取玩家刚刚经历的一个明确瞬间：转过山弯看见江谷、客栈入夜亮起窗灯、亲手涂过的岩壁与瀑布、近处巨石分开的白浪。

- 一个主体，最多两组辅助景物。先看见山弯、窗灯或白浪，再读到山石和草木细节。
- 同一路线的几枚徽章在构图、明暗和主要物件上有区别；圆框、纸张与整体尺寸保持统一。
- 地貌、植被、季节、天气和光照对应事件发生的路段。生成画作标明为艺术表达，不能冒充该地点的实拍。
- 需要人物时沿用旅程中的 Q 版形象与衣着；人物大小服从场景关系。以山水为主体的记忆可以不画人。
- 名称、地点、日期和回忆放在徽章外的界面中。画内默认不加标题、数字、等级、横幅或小字。

地点照片用于认识地点，地图图标用于定位；两者都不直接当作新徽章。小游戏完成画面也需重新构成圆形画心，不能把整屏界面缩成一张收藏图。

## 2. 圆形与边缘是共同的结构

从外到内统一为：**透明留边 → 完整纸边 → 圆形画心**。

| 部位 | 要求 | 应避免的问题 |
| --- | --- | --- |
| 外轮廓 | 视觉上保持正圆，所有方向都有余量；可有很轻的纸纤维起伏 | 椭圆、盾牌形、锯齿章、星芒突出，圆边被画布切掉 |
| 透明留边 | 圈外真正透明、干净；按实际可见外径统一摆放 | 不透明方底、残片、孤立色点、不同透明余量导致大小不一 |
| 纸边 | 一整圈米白暖纸底，宽度稳定，纸纹细而轻 | 只有局部装饰、缺口、粗白边、圆框融进浅色画心 |
| 收边线 | 低饱和暖灰金或草木灰细线，连接完整、笔压自然 | 亮黄色粗金框、镜面高光、金属浮雕、发光外圈 |
| 内缘 | 一条更淡的收边线或颜料沉积，区分画心与纸边 | 重复套很多圆、双重厚框、线条压住主景 |
| 画心 | 场景连续铺到内缘，主体落在安全区 | 圆底中央再放矩形小照片、四角缺景、大块空白填充 |

纸纹可以局部淡出，**纸边的整体轮廓须完整可读**。缩成小图后应先看到完整的圆形小画，不要求看清每一根装饰线。

局部边饰可选，用路线已有的叶形、细水纹或石纹轻轻点到即可。边饰沿圆环内部生长，不突破外轮廓，不围满厚重花环，也不与主体争夺注意。先做好共同纸边，再决定是否需要边饰。

## 3. 水彩材质与颜色

画心保留纸张颗粒、透明叠色、颜料在边缘的轻微沉积，以及清楚的前后景层次。远山少细节、近景有材质；不靠全图锐化和高饱和让缩略图显得精细。

| 用途 | 建议基色 | 使用方式 |
| --- | --- | --- |
| 纸边 | `#F3EDDA` | 暖米白，明暗变化很轻 |
| 外缘 | `#A58C61` | 灰金色细线，无金属反光 |
| 内缘与少量枝叶 | `#89947C` | 草木灰，低于主体对比度 |
| 山石与远景 | 青灰、石褐、灰绿 | 随路线光照变化，不统一涂成同一种绿色 |
| 记忆中的暖色 | 窗灯、日照、秋叶原有颜色 | 少量聚焦；不能每枚都改成金色夕阳 |

这些色值用于起稿和共用边框，不限制水彩画心的自然色阶。把同一路线的整组徽章放在一起调色，避免单张各自漂亮、并排后纸色和光感完全不同。

## 4. 构图与制作尺寸

以下为新稿的建议坐标基准，使用同一比例适配其他分辨率；不是当前代码已经统一的参数。

| 项目 | 1024 × 1024 母版基准 |
| --- | --- |
| 圆心 | `(512, 512)` |
| 外圆 | 半径 `480`，直径 `960` |
| 四周透明余量 | 每侧 `32`，约画布宽的 3.1% |
| 画心 | 半径 `448`，直径 `896` |
| 纸边径向宽度 | `32`，约画布宽的 3.1% |
| 关键主体安全区 | 距圆心约 `336` 以内；山峰尖、动物头部等辨识点尽量留在此处 |
| 外缘／内缘线 | 约 `4`／`2`，根据缩小后的实际显示调整 |

安全区约束关键辨识点，不限制溪流、山路、植被等连续景物伸到内缘。构图围绕圆形展开：山路可以弧形穿入，瀑布形成纵向重点，江流和巨石形成斜向动势。避免先做横幅，再默认中心裁切。

新画稿建议保留至少 `1024 × 1024` 的无损母版。交付透明 PNG 或支持 alpha 的 WebP；实际输出尺寸按显示像素和清晰度选择，不把低分辨率图片插值放大后标为高清。当前详情图约 280 CSS px，可先以 768 px 的正方形分发图覆盖常用显示，具体压缩质量仍以实图为准。

先看 `64 px` 的轮廓与主体，再看 `128 px` 的收藏墙表现，最后看 `280 px` 的纸纹与画面细节。三种尺寸都要保留完整外圈，不用拉伸来填满容器。

## 5. 固定画作、玩家创作与历史收藏

| 类型 | 画心处理 | 边缘处理 |
| --- | --- | --- |
| 固定徽章 | 按圆形专门构图，保留该关独立主体 | 使用同一套纸边，画作本身已带框时不重复套框 |
| 玩家涂色、笔迹 | 保存真实完成状态及笔触，不换成默认成品画 | 内容只在圆形画心内合成，最后覆盖共同纸边 |
| 玩家取景 | 使用完成时确认的取景与场景状态，不重新居中裁切 | 取景范围与最终圆形画心一致，边框不侵占任务目标 |
| 旧圆形无框作品 | 保留原画内容与大小关系 | 可在展示层外围补纸边，不覆盖原作、不改写收藏记录 |
| 旧矩形画作或截图 | 保留完整原件；经逐项确认后可增加仅用于展示的圆形构图 | 不把矩形原件缩在圆底中当成已完成统一；暂不能保全内容时明确保留为旧画作 |

历史兼容优先保护玩家作品。新圆形展示不得删掉关键笔迹、改变首次取景或假装是原来的创作；不能安全构图时，先保留旧展示并记录例外。详情仍能阅读原件，新的展示缓存也不覆盖原存储。

**合成顺序：圆形画心遮罩 → 实际画作与玩家结果 → 完整纸边 → 轻微边缘纹理。** 同一几何定义控制裁切、画心和边框，避免每关分别写半径。纸边放在最上层，瀑布涂色、波浪动画和玩家笔迹不得把它盖掉。

固定徽章和动态合成结果都通过同一展示入口进入奖励、收藏墙和详情；不能奖励时有框，入帐后又回到无框截图。浏览旧收藏不重新发奖、不写入新记录。

## 6. 接入与复用约定

复用已有边界，先完善公共徽章能力，再逐项接入，不按路线复制一套奖励与收藏逻辑。

| 内容 | 维护位置与责任 |
| --- | --- |
| 圆形几何与纸边 | `src/runtime/badge-paper.ts`；虎跳峡使用此公共合成能力 |
| 画作与旧记录展示 | `src/runtime/journal-badge.ts` 为公共入口；虎跳峡在 `tiger-badge.ts` 中读取画心和保留原件 |
| 事件身份、标题与素材引用 | 沿用内容目录及现有注册来源，保持一个事件一份定义 |
| 玩家结果捕获 | 各游戏渲染器负责提供真实结果；调用共同圆形合成能力，不复制边框参数 |
| 完成展示与转场 | `src/runtime/reward-controller.ts`；展示已经完成并处理保存结果的回忆 |
| 收藏墙与详情 | `src/runtime/journal-controller.ts`；与奖励复用同一画作呈现方式 |
| 写入与去重 | `src/runtime/journal-store.ts`；不因换边框改变事件 ID、首次日期或首次画作 |

素材记录须包含事件 ID、路线和地点、画心类型、来源及许可或生成提示词、母版路径、分发路径、可见圆尺寸、边框是否已合成、裁切位置和素材版本。已有字段能表达时继续复用，避免另造一份会失同步的目录。更新素材引用与清单，保留旧收藏依赖的资源。

SVG 或 Canvas 可负责共同遮罩、辅助轮廓与失败降级；精细画心仍使用合适的手绘素材，不能以粗糙几何图元替代。纸边纹理若使用独立素材，各路线共用同一版本。

## 7. 完成后的展示节奏

沿用“完成互动 → 展开本关徽章 → 自动入帐 → 淡回山路”。保存失败须明确反馈并允许重试，不能先显示已入帐。玩家主动开启声音后，使用轻纸声与克制的收藏反馈，避免金币或抽奖式音效。

建议起点：显现 `0.4–0.6 秒`，清楚停留 `1.2–1.8 秒`，淡出 `0.5–0.8 秒`。具体时长按实际体验调整，不新增每关的独立定时器。徽章不旋转翻飞、不弹跳放大、不伴随星芒爆闪。减少动态效果时保留静态展示和必要阅读时间。

奖励展示、收藏墙、详情使用同一圆形比例。屏幕空间变化时缩放整体，正文放到合适位置，不切边、不拉伸，不让徽章在窄屏挤出关闭按钮。

## 8. 从设计到交付

1. **写一张简报。** 说明哪条路线、哪个事件、季节与时刻、玩家刚做了什么，以及最该记住的一个主体。确认是固定画作还是保留玩家创作。
2. **先做圆形构图。** 标出画心、纸边和安全区；看小图是否一眼能认出本关。先确定整组构图差异，再加细节。
3. **绘制或生成画心。** 使用已确认的同组参考，保留纸纹与自然光照。景物依据路线内容，不为装饰混入别处的建筑、植物或天气。
4. **统一纸边。** 使用共用基准，检查外圈完整、宽度与颜色一致。批量生成的每一枚都单独看，提示词不能代替成品检查。
5. **整理素材。** 清理圈外残点，核对真实 alpha、可见直径、裁切和清晰度；保留母版，更新引用与来源记录。每枚独立交付，避免从紧贴的拼版误切邻图。
6. **接入真实完成结果。** 固定图与玩家画作分别处理，奖励、收藏墙和详情共用最终结果；明确旧记录如何兼容。
7. **按授权集中验收。** 先看外观，再检查完成、保存、失败、重玩和淡出。分别记录实现、构建、功能验收与用户视觉认可。

### 可复用的生成简报

> 为山径 Trailbound 绘制一枚圆形水彩旅行手帐徽章。路线／地点为【地点】，季节与时刻为【设定】，记忆是【玩家刚经历的事】。一个明确主体【主体】，辅景为【少量辅景】。画面按圆形重新构图，连续铺满圆形内缘。外侧完整米白纸边，灰金细线轻轻收束，保留纸纤维与颜料层次。外轮廓为正圆，四周留透明余量，整枚完整入画，圈外无残点。与【参考徽章】统一纸色、画风、圆径与边宽。无文字、UI、星芒、外凸尖角、金属浮雕、发光、矩形内框或不透明方底。此图是艺术化旅途记忆，不是实拍。

若是玩家创作，分别准备场景画心和透明圆环，生成简报明确留出合成位置；不要生成一张带假笔迹的完成图替换玩家结果。需要生成或修改精细手绘时使用项目可用的图像生成工具。

## 9. 验收清单

- **轮廓与边缘：** 1:1 等比显示，整圆完整；纸边四周可见，无明显粗细跳变，无裁边、角饰突出、透明区脏点或重复套框。
- **画意与辨识：** 64 px 看得出主体；128 px 可区分同组各关；280 px 纸纹和笔触自然，画心没有矩形残留或填空色块。
- **真实性与一致性：** 题材、季节、光照吻合路段；同组外径和纸色一致；实拍、手绘与玩家创作身份清楚。
- **动态结果：** 玩家涂色和取景真实保留，合成不覆盖纸边、不切掉判定目标，奖励和手帐内容一致。
- **保存与旧记录：** 未完成不发奖；成功完成后自动入帐；失败可重试；重玩不重复；历史 ID、原画、文字和日期不被美术升级改写。
- **展示与适配：** 米白纸页、较深奖励背景都看得清边缘；手机与桌面不裁边；加载失败有可读文字；退出、后台暂停和减少动态效果正常。

自动化可以核对尺寸、alpha、资源与状态，无法代替对“像不像圆形手帐小画”的实图判断。当前文件只定义依据，不记录未执行的验收为通过。
