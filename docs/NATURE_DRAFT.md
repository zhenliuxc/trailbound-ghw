# 地方自然与地点手账 · v0.13候选

之前的三张地图反复使用同类圆丘、树木和尖峰，手账收集的是泛化动物插画，难以记住具体地方。此候选按地区重做场景轮廓，并让手账围绕地点、区域照片与自然知识展开。

## 本候选的变化

| 路线 | 场景方向 | 手账主题 |
| --- | --- | --- |
| 武功山 | 长草脊、湿润山地、低处云海；避开通用球形小丘 | 山脊草甸、云海变化、罗霄群峰 |
| 虎跳峡 | 两侧高山、陡峭岩壁、谷底江流；河道继续参考原坐标 | 高路与深谷、两山夹江、山村与路标 |
| 鳌太 / 秦岭 | 岩脊、石海、林带和局部积雪；地形不是一片全年纯白 | 林带变化、岩面地衣、太白山石海与古冰川 |

这些插画基于当地景观资料作艺术化设计，不是新的GIS测绘或真实DEM。原参考轨迹、源水系、峰点与照片文件没有改写。动态环境、步态、声音与大幅照片弹窗继续沿用既有实现。

每页地方手账包含地点主题、对应区域照片、完整原图来源与摄影署名、一句观察提示、一段自然知识及其来源。照片仍按原图的实际区域与历史范围说明，不把它当成当前精确位置的现场照片。点击缩略图可以查看完整本地照片。

在既有“记住”操作后，便笺显示在地图下方，行走不被打断；打开打卡照片时显示该点的知识。没有强制测验或额外管理按钮。地方主题按路线顺序出现，随机种子只改变发现时段与侧向位置。

## 手账兼容

保留原九个记录ID与浏览器存储键，使旧记录仍可读；原ID中的bird等词是兼容标识。界面内容已改为所属路线的地方主题便笺。便笺是虚拟漫游中的区域知识记录，不能证明现实到访、精确照片坐标或物种鉴定。
