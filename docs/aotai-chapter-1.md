# 鳌太线 · 秦岭地貌旅程

本轮按用户“继续完成鳌太线”补充独立行走页面，沿用 2D 示意图、Q 版旅人、实景打卡、手绘互动及圆形徽章。仅处理鳌太线，不迁移武功山、虎跳峡或其他路线，不发布、不提交。

## 实现边界

- 这是一段压缩时间的虚拟地貌旅程，沿鳌山至太白山的大体东西关系构图，不提供现实穿越导航或两日穿越行程。山坳歇脚处是游戏场景，不指定现实营地。
- 实景只使用项目已有的三张开放许可照片。白起庙为对应地点；两张太白山照片标明“区域实景”，不冒充石海或主脊的定点照片。
- 保留四个原有收藏 ID 与徽章。石海补画、山脊辨形、林缘让路、雾中配对分别在途中触发，不把小游戏标在地图上。

## 结构选择

architect 工作流先以现有行进、画作和手帐流程为依据，比较两份草图。采用 B 的单一行程游标，按顺序拥有抵达、照片、发现、游戏、歇脚、入夜、清晨与结束状态。主机局限于 `src/aotai-walk/`，不另建全路线通用框架。

采纳 A 的两点：照片显式区分定点与区域；每次画作挂载有独立取消信号，异步返回不得写入过期画面。未完成退出只消耗本次邂逅，不发奖；手帐由现有收藏控制器保存，去重及首次记录规则不变。

主地图复用 PixiJS 8 与现有角色资源、角色选择器、发现转场及手帐弹层。手绘互动使用 Canvas 2D，并通过现有小游戏控制器接收鼠标、触屏与键盘，新增能力标志，不冒充虎跳峡游戏。

## 已实现

- `aotai-walk.html`：PixiJS 8 程序绘制的森林、连绵山体、石海、薄雪、路径、帐篷与云雾。默认跟随，右上角主动切换全图。地图保留起点、终点、打卡图标和名称，小游戏不另设标记。
- 旅人：两位现有 Q 版角色可切换；按路径距离播放行走帧，坡度影响速度与步幅，朝向和镜头分别平滑。歇脚依次卸包、坐下、喝水；入夜有星光和帐篷暖光，清晨恢复站姿和行进。
- 四段小游戏：三块石海补画、山脊辨形、为羚牛让路后继续、三对雾中画片。保留键盘、重试和退出；内容载入失败时不会开始计算互动。
- 收藏：沿用现有四个 ID 和圆形徽章，完成后自动入帐，保留发现与奖励淡出。未完成退出不发奖；照片重看和翻手帐不会消耗后续行程事件。
- 声音：使用已有免费配乐、风声与轻脚步；随夜色和薄雾改变混音，用户开启后播放，离开或切后台暂停。
- 首页：增加鳌太线手绘封面与新页面入口。武功山、虎跳峡原有旅程继续保留；共用桥接只增加鳌太线注册及直接操作能力。

### 地图占比修复

全图原先受长路线宽度限制，窄屏取景检查失败，山体包围范围只有 162.5 / 566 像素，见 `map-framing-before.txt`。现在全图分别适配横向路线与纵向山体，窄屏同时使用更紧凑的地图容器，避免把山峰单纯拉成细针。人物、树木、岩块和帐篷补偿比例；打卡图标仍为固定屏幕尺寸。修复远山下沿的平直色带，并让图标避开小人和右上角视角按钮。

取景规则在宽屏、窄屏以及实际 368 × 300 地图尺寸下通过两项检查：山体范围至少占视图高度 65%，起点、山脊与终点完整可见。日志见 `map-framing-after.txt`。实际手机宽度检查为 CSS 390 × 844，地图高 300，无横向溢出，打卡图标与视角切换框无相交。
