# v0.7.1 验证记录

53项自动测试通过；JavaScript语法、静态资源、SVG引用、九张WebP照片与署名完整性检查通过。

本版增加基于可控动画时钟的DOM验证：一次出发后自动行走、镜头/完整路线切换、暂停与后台冻结、情境自动暂停、选择继续、三张照片到达/重看/错误处理、重看后恢复此前状态、四关完整结束、鳌太提前结束及重玩。纯状态机验证还覆盖大时间步不会跳过情节、非法/重复选择、不同选择造成不同步伐/状态/回忆、等雾后真实清除雾效果。原坐标、插值与旧风险引擎测试仍保留。

最小DOM夹具和可控时钟不是浏览器。静态SVG输出仅检查地图几何和人物，不是MLH运行截图。未执行真实设备渲染或播放录音。

## v0.7.1 背景裁剪回归

53 项测试通过。新增测试在 320×435、390×460、990×646、1280×460 四种视口下，以整图/跟随两种缩放和三种相机位置共 24 个组合，调用安装版本 PixiJS 的实际 FilterSystem._calculateFilterArea。确认滤镜区域经过相机变换后覆盖整个屏幕，尺寸保持在屏幕加四像素的范围内；相机移动时会重新计算本地裁剪区域。

该测试执行实际 PixiJS 坐标与边界逻辑，但使用模拟 Application，没有真实 WebGL 上下文。手机和浏览器的最终视觉仍需实机复核。
