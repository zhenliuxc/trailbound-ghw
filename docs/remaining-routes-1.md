## 路线与互动

| 路线 | 本章范围 | 行进中触发的互动 |
| --- | --- | --- |
| 四姑娘山长坪沟 | 喇嘛寺 → 枯树滩 → 红石阵 → 木骡子，保留去程章节 | 枯树滩对齐枝影；红石阵移动透镜观察；木骡子林缘拖开视野看草甸与雪山 |
| 莫干山 | 莫干岭西坡 → 竹林石阶 → 莫干岭口 → 大坑侧山林，保留既有古道选段 | 竹林接八声雨滴；古道十级石阶；林隙竹叶弹弓 |
| 九溪龙井 | 九溪烟树 → 九溪十八涧 → 龙井茶园 → 龙井村 | 溪谷推叶；浅溪依次点石；茶园茶芽消除；村口茶盏展开 |

三条路线不增加过夜。地图与时钟表达虚拟行程，未将构图距离或游玩秒数换算成真实 GPS 里程、实际步速。

互动分别位于独立路段，中间保留行走。地图仅有地点图标和名称；小游戏不显示地图按钮。到达照片停下展开实拍，到达游戏先显示自然线索，再进入手绘。完成操作后自动收藏圆形徽章，停留并淡回山径；跳过不授予徽章。旧记录的保留、重复收藏处理及保存失败反馈复用公共手帐组件。

旧轻互动曾在 6～10 秒后自行结束。本批长坪沟三关及九溪涉溪/茶盏的专用适配器取消此超时，必须完成操作才进入奖励；玩家仍可主动跳过。不修改其他路线的旧轻互动时间规则。

## 地图与复用

- `src/content/day-routes.ts`：地点、路线节点、海拔示意、天气阶段、互动位置和封面文案。`src/content/day-photos.ts`：照片与署名。
- `src/journey/day-route.ts`：三个日间旅程共用的路径取样与状态机。照片、游戏、停步和终点按同一距离序列触发，人物与标记也读取同一路径。
- `src/day-walk/main.ts`：共用页面宿主，接入照片弹窗、手绘会话、发现过渡、选角、声音和后台暂停；不复制三个宿主。
- `src/day-walk/landscape.ts`：按地域分别绘制雪峰/针叶林/溪谷、竹林/石阶/山涧、缓丘/溪流/茶垄/村落。背景保持程序绘制的 2D 示意图。
- `src/day-walk/scene.ts`：复用 `MapCamera`、`mapCharacterScale` 与角色素材。默认跟随，用户主动切换全图；跟随人物 40 CSS px、全图 20 CSS px，地图高度使用 `journey-map.css`。同轴缩放保持人物比例。
- `src/journey/walking-turn.ts`：从麦理浩径提取原有平滑转向与落脚补偿，麦理浩径及本批三条路线共用，转向算法未重写。
- `src/journey/scenic-game.ts`：保留旧手绘轻互动，集中处理响应式绘制/输入坐标、素材等待、键盘操作与明确完成。莫干山复用既有 `runtime/mogan/`；九溪推叶与茶芽消除复用现有成熟玩法。
- `src/templates/day-walk.html`、`scripts/build-day-pages.mjs`：同一模板生成三张地图与来源页；三张手绘页继续复用已有公共片段与 `journey/art-page.ts`。
- 首页封面入口由七条 `CHAPTERS` 数据生成，按钮进入独立旅程。全国地图及入口文案统一为 **浙江 · 德清**、**浙江 · 杭州**。

本次没有改动武功山、虎跳峡和鳌太线的地图或小游戏设计。共用游戏页加入三条路由；公共布局识别适配器的直接输入模式；麦理浩径转向的调用改为共享模块。后续验收应覆盖这些集成边界，不能把编译成功当作浏览器验证。

## 实拍与地域依据

沿用九张已有许可照片，没有下载未经确认的社交平台图片。照片页和来源页均保留作者、原始标题、原页、许可和裁切说明。

- 长坪沟：森林、溪谷、草甸三张区域实拍。未核准枯树滩、红石阵、木骡子的精确摄影机位，照片文案明确注明区域配图；不把它们称为三个地标的定点实拍。
- 莫干山：竹林、木制步道、溪水三张区域实拍。木制步道图片安排于“林间步道”，明确不是莫干岭古道石阶。
- 九溪龙井：九溪十八涧溪流、九溪十八涧石径、龙井村与茶园三个对应场景的历史实拍。

路线关系核对参考：

- [四姑娘山管理局 · 长坪沟](https://www.sgns.cn/understand/cpg)：喇嘛寺起步、枯树滩、红石阵和木骡子；木骡子为去程观景终点，不把本章写成长穿毕。
- [杭州政协网 · 九溪至龙井徒步线](https://www.hzzx.gov.cn/cshz/content/2024-07/08/content_8755727.htm)：九溪烟树、九溪十八涧、龙井村。该页面路线另含龙井八景，本章不含延伸段，不直接借用全线里程。
- [湖州发布 · 莫干山古道背景](https://www.thepaper.cn/newsDetail_forward_2597949)：用于地域背景。既有选段采用仓库 OSM 莫干岭西坡至大坑侧资料，不能用背景文章的完整古道长度替代本章选段长度。

长坪沟和莫干山的定点照片仍是后续素材缺口。本批没有声称已经补齐。
