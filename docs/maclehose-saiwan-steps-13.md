## 当前体验

地图行进至西湾山登高末段时展开新关，随后才抵达西湾山实拍。地图保留 2D 示意、默认跟随和两位可选 Q 版旅人。新触发位置取自现有上坡路径点，未重绘其他地形或地标。

提示是“轻点下一块石阶，慢慢走到山肩外”。玩家依次完成五级石阶与平台上的三步，镜头缓慢拉开，岩壁与草木逐渐让出白沙海湾和蚺蛇尖。点击远处石阶、海面或尚不可用的平石都不会前进，也不会获奖。连续乱点不能跳过动作。

走到平台后，轻点宽平的歇脚石；人物靠近、卸包、坐下，留出约 4.5 秒安静看海，之后自动展示圆形徽章并淡回行进。保留 `coast-sand` 和原“海湾展开”收藏身份及圆形画作，不新增重复收藏、不改写已有首条回忆；新完成记录记下登阶和坐下观海。

键盘 Enter、空格或向上／向右可辅助逐步前进，到平台后 Enter 坐下。支持重试、退出和减少动态效果。竖屏单独裁取石阶与最终海湾，使用与画面相同的相机反算点击坐标。

## 素材与实现

- 使用内置 imagegen，参考 v12 总稿、既有两位角色与有署名的西湾山实拍，生成远景山海、透明石阶平台、透明近景山肩，以及蓝衣／双辫旅人各八个登阶和停留姿态。完整原图、提示词、生成和参考来源记录在 `art/maclehose-saiwan-steps-v13/`。
- 场景原生 1672×941，人物图集原生 1774×887。没有用插值放大冒充原生 4K。五份分发 WebP 合计 2,147,170 字节，每次只加载当前角色的图集。处理脚本为 `scripts/build-maclehose-saiwan-art.mjs`，分发来源为 `dist/scenes/maclehose-saiwan-v13/credits.json`。
- 继续使用已有小游戏控制器和 Canvas 2D 分层适配，没有新增引擎或依赖。模型、相机、绘制与适配位于 `src/runtime/coast-memories/shoulder/`。台阶落点与点击区域共用一份数据；人物透明裁边与支撑脚锚点由素材脚本产生。
- 石阶落脚、卸包复用项目已打包的免费材质声，音量克制。风与海浪的声景跟随同一个展开进度渐变，不重启环境循环，不声称香港当地实录。来源继续保留在麦理浩径致谢及原音频清单。
- 真实打卡照片及许可入口继续保留。新关为地理参考后的艺术化构图，并非地形测绘或真实平台复原。
