## 人物与步态

旧步行素材的大部分帧都是张开双脚，缺少真正收腿经过的姿势。用内置 `image_gen` 生成一次独立八帧水彩行走图，保留草帽、围巾、外套和背包造型；原静立、拍照及观景素材继续保留。新图包含明显的收腿姿势，但最终循环观感仍需实际查看。

- 网站资源：`dist/characters/trailbound-walk-v2.webp`。
- 原图、提示词、来源和素材边界：[walk-v2.md](../art/characters/walk-v2.md)。
- 素材准备脚本：`art/characters/walk-prepare-v2.mjs`。读取源图 alpha、生成实际裁切框与脚锚，并转码整张 WebP；没有拼接或变形角色像素。
- 帧数据：`art/characters/walk-v2.json`；由准备脚本生成 `src/runtime/map-walk-art.ts`，供渲染直接读取。

八帧共用固定比例，以每帧脚锚将鞋底放回同一条路线。`src/runtime/map-gait.ts` 统一帧节奏与触地时钟，接触和承重阶段略长，经过阶段略短；起步逐渐进入步频，恢复行走从脚落地的阶段开始。调整步速时平滑改变步频。静音期间继续记录触地，途中开声不会补播之前的脚步。

静态图与步行图分别预加载并复用缓存。步行图失败时保留静立人物和失败提示，两份资源均失败时显示文字。暂停、场景、奖励、手帐与后台状态停止步行动画；减少动态效果时使用静态姿势。原有朝向滤波与脚底路线坐标继续沿用。

## 地图细节与标记

`dist/scenery.js` 与 `dist/illustration.js` 增加坡面笔触、岩层线、湿岸、浅滩、深水层与顺河向细纹。草甸增加草穗，竹林使用落叶，林地使用蕨叶，峡谷、雪地和海岸使用相应碎石。树冠按覆盖范围避开路线，地面细节避开海面。新增景物在地图建立时生成，由 SVG 与 Pixi 使用同一份绘图数据。

`src/runtime/map-labels.ts` 按屏幕像素统一安排起终点牌、虎跳峡地标与照片名称，避开人物、图标、顶部天气和总览控件。文字宽度区分汉字与拉丁字母，边缘保留余量；记住相对位置，减少跟随镜头时反复跳位。端点优先放置，附近没有空位时继续寻找合法位置，并将结果纳入其余文字的碰撞区域。移动较远的名称带细引线。原来的地点、顺序、照片入口与触控图标继续保留。

同步更新相关脚本和样式的资源版本，避免旧 `illustration.js` 与新 `scenery.js` 混用。
