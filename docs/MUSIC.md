## 播放方式

1. 声音默认关闭。点击页面顶部“声音 · 关”，由这次用户操作创建并恢复 AudioContext。
2. 行走时只播放地图环境声及与步态一致的短脚步，不循环整段旋律。
3. 抵达打卡点并打开照片时，自动淡入对应短乐段（约6–10秒）和音效，之后留下环境声。卡片显示曲名及播放状态。持续停留不会反复重播。
4. 点继续走时，照片声景淡回行走环境。离开照片后重新打开，该点短乐段会重新播放。情境卡片只留环境声；普通暂停与旅程结束会淡出。
5. 切换打卡点或地图约0.4秒淡出旧声、0.55秒淡入新声，并停止旧场景尚未开始的音符。关声音会淡出并挂起音频；切后台立即清理声源并挂起。

声音为艺术化表达，不是现场声学复原。草叶、江水、雪声由滤波噪声形成不同底色，鸟鸣、钟和敲击由振荡器生成；不代表真实当地鸟种或现场声音。

## 实现与验证

`dist/audio.js` 保存九套不可变配置、音高序列、纯函数乐谱，以及懒创建音频引擎。每个场景独立增益，音符有起音/衰减包络、立体声位置及少量合成混响；主输出接压缩器。完成的音符清理节点，快速切换最多保留三组场景，不建立第二套行走时钟。

新增11项 Node.js 检查，覆盖九个真实照片ID、不同乐谱、有限参数、可重复噪声、只在明确开启后创建音频、重复渲染不重播、切曲释放、快速切换资源上限、脚步释放、暂停/快速恢复、后台静音、开音失败及照片交互。最小音频夹具检查节点和调度，不渲染或播放音频，也不模拟浏览器的自动播放策略。

总计90项自动检查通过。真实 Chrome/Safari、iPhone/Android 的首次开音、后台恢复、音量、音色和听感仍待实机确认。不支持 Web Audio 时页面提示“此浏览器暂无音效”，玩法照常。所有新增代码与音乐设计由 ChatGPT/Codex 完成，没有 Cursor 操作记录。

API 参考：https://webaudio.github.io/web-audio-api/ （2026-10-14查阅）。
