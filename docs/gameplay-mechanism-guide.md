# 手绘与画境小游戏 · 玩法机制设计指南

本指南按六大判断维度整理 24 项核心机制。

本指南供路线与小游戏设计选型使用。它扩展机制范围，不代表各路线已采用这些机制，也不代表相应组件已经实现。产品方向遵循 [游戏设计宪章](game-design-charter.md)，各路线当前采用的玩法见 [路线与小游戏](ROUTES.md)。

## 核心理念：机制服务于画意

玩家的判断与操作，应当像是在修补、唤醒、品读或走入一幅手绘旧画。笔触、纸张、器物、人物与风景共同构成规则，画面中的变化让玩家理解操作的结果。

一道合适的机制同时回答三个问题：这里发生了什么，玩家为什么愿意参与，完成后留下什么记忆。数学或物理规则可以支撑玩法，但玩家首先看到的是水往哪里流、枝影如何呼应、山路怎样接通。

机制选择以实际路段、季节与事件为起点。程序绘制的 2D 示意地图承载行程，精细手绘承载事件与小游戏，真实照片承载地点实景。画境中的折叠、缩放与时间变化属于明确的艺术表达，不改变地图里的真实地点关系。

## 全景机制工具箱

六个维度按玩家主要判断分类。一关可能涉及多个维度，设计稿需注明一个主机制及必要的辅助机制。同一维度可以复用部分输入、渲染和状态表达；配对、装箱、消除等具体规则仍分别建模。

| 判断维度 | 编号 | 核心乐趣 |
| --- | --- | --- |
| 空间拓扑与画境重构 | 01–06 | 看懂结构、错位、遮挡与连通，让画境重新合一 |
| 路径规划与腾挪推演 | 07–10 | 安排路线、让出通道、处理阻塞与边界 |
| 图样辨识与盘面连锁 | 11–14 | 找到呼应、规律、互补与连续变化 |
| 物理力场与动态微操 | 15–17 | 感受重量、弹性、风阻与惯性 |
| 笔触介入与工艺显影 | 18–21 | 改变干湿、浓淡、色彩和形态，亲手留下作品 |
| 韵律、时间与轻叙事 | 22–24 | 捕捉节拍、状态变化与人物心意 |

表中的手绘结合方式均为本项目的候选设计。经典参考只用于理解某一机制或表现手法，不表示对应作品拥有表中全部功能。已核对的主要来源列在文末。

### 维度一：空间拓扑与画境重构

核心乐趣是辨认结构与连接关系。完成时，玩家能看见原本断裂、遮住或错开的画面重新成立。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 01 拼片、旋转画轴 | 边缘轮廓、笔触走势、方向与邻接关系 | 残片或错位画轴补回画面；接合处颜料逐渐晕开，细纸边连成完整画芯 | 传统 Jigsaw 的拼片规则；旋转是否启用按单关决定 |
| 02 折纸、翻页、叠透 | 折叠后的正反关系、遮挡次序与对称边界 | 翻折纸角连接两岸，或叠合半透明描图纸组成印章 | [Paper Trail](https://www.papertrailgame.com/) 的折纸造路；叠透另按具体构图设计 |
| 03 画中画、借位造路 | 跨图层的重合点、远近比例与路径接续 | 移动写生稿与远近山峦纸层，让断桥或山路在画中接通，随后人物实际通过 | [Gorogoa](https://www.annapurna.com/interactive/gorogoa) 的画格组合；[Old Man's Journey](https://store.steampowered.com/app/581270/) 的地景造路 |
| 04 视错觉、光影投射 | 观察角度、光源位置与投影轮廓 | 转动纸制物件或移动画内光源，让枝石投出可辨认的鸟兽、人物或山形 | [Shadowmatic](https://www.triadastudiogames.com/shadowmatic) 的投影辨形；Monument Valley 的透视空间思路 |
| 05 画框分镜、因果重排 | 空间顺序、人物进入下一格的条件与事件因果 | 调换连环画页或四条屏，让相遇、让路和抵达形成连贯故事 | FRAMED 的分镜重排；Storyteller 的场景与角色因果 |
| 06 正负空间、水墨互换 | 哪些墨色或留白区域可以通行，切换后人物立足处是否成立 | 墨与留白互换，水面倒影成为画内山路，飞白成为可踏的云阶 | Shift 的图底切换思路；Miegakure 仅作空间转换的延伸阅读 |

构图变化需要明确的视觉锚点，人物落脚点与变化后的通路对应。写实路线的行进地图继续保留地理关系，借位造路发生在手绘事件中。

### 维度二：路径规划与腾挪推演

核心乐趣是读懂通路与阻塞，决定先动什么、从哪里经过。路网、边界和可操作物件在画面中可辨认。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 07 连线、引流、光路 | 连通、方向、先后顺序、阻挡与分流 | 风穿山坳，水沿画中溪道流动，墨迹顺纸纹进入目标区域；接通后立即出现连续流动 | Pipe Mania 的通路连接；光路与分流作为独立变体 |
| 08 华容道、滑块腾挪 | 有限空间中的移动次序、阻塞与让位 | 挪动镇纸、竹简、茶宠或纸屏风，为画中人或水流腾出通道 | 华容道、Rush Hour 的空间腾挪 |
| 09 一笔画、织网、解绳 | 路段是否已走过、交叉处的上下关系、哪些连接必须先解除 | 一气勾勒山形，用线串起铃铛，或按依赖顺序抽出卡住的纸签 | The Witness 的画线路径；Hook 的连接解除。节点奇偶仅用于适合的内部规则 |
| 10 围地、分割、牧群 | 边界是否闭合、区域属性如何隔离、群体到来前应怎样改道 | 在手帐画境里围出花圃，布置纸桥或导向，让画中鱼群、蚂蚁或牧群抵达目标 | 围棋的围地思路；Lemmings 的群体引导；鲤的水中运动意象 |

通路成立后需要有真实反馈：水流过、人物通过、群体抵达。短关中的规则通过少量可见关系表达，不要求玩家先学习节点术语或复杂线路符号。

### 维度三：图样辨识与盘面连锁

核心乐趣是从手绘细节中发现关系。配对、收纳和连锁分别依靠不同判断，不能只换一组图案便算新的玩法。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 11 记忆配对、镜像寻踪 | 盖住物件的位置记忆，或可见物件的轮廓、正反和倒影对应 | 叶脉、窗花、枝影与山形成对出现；配对后局部回到原画 | Memory 的记忆配对。可见镜像配对是另一变体，不强制加入记忆负担 |
| 12 消除、合成、连锁 | 交换或投放顺序、邻接关系，以及一次变化引出的后续组合 | 茶叶、颜料块或花瓣组成盘面，组合后以水彩扩散表现变化 | Triple Town 的相邻合成；Suika 的碰撞合并；[KAMI](https://www.stateofplaygames.com/kami) 另提供区域变色思路 |
| 13 器物收纳、嵌合陈列 | 形状互补、尺寸、分类逻辑与摆放朝向 | 整理画师行囊、旅行器物或茶席；归位后从物品组合读出一段故事 | [Unpacking](https://www.unpackinggame.com/) 的物件摆放与叙事；Cats Organized Neatly 的形状嵌合 |
| 14 数织推演、刺绣显像 | 行列线索如何交叉约束落墨与留白 | 经折或绣布上的清楚线索对应落针位置，逐步显出图案 | Picross 的行列推理；扫雷的邻域计数可作另一变体，两套规则分开说明 |

颜色可以承载气氛，关键关系同时由轮廓、纹理或位置表达。数织保留可以理解的线索，节气符号只有在数量和规则清楚时才承担提示。

### 维度四：物理力场与动态微操

核心乐趣是物体对操作持续作出回应。玩家通过动作和反馈理解重量、风向、惯性与张力。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 15 弹弓、蓄力抛射 | 角度、力度、弧线、风阻、反弹与落点 | 松果、纸团或种子沿淡彩轨迹飞行，接触后有对应的碰撞、纸响或落地反应 | Angry Birds 的抛射关系；Alto 仅作连续运动与画面节奏参考 |
| 16 物理平衡、支点机关 | 重心、支点、放置顺序与连锁倾倒 | 调整画架、独木舟、竹筒水车或秤砣，让有重量的器物达到目标状态 | Super Stacker 的堆叠平衡；奇妙装置的物理因果 |
| 17 风力、倾角、张力维持 | 外力强弱、惯性提前量，以及何时加力或松手 | 以风送叶、牵线放纸鸢，或通过扇风控制画内茶炉火候 | Flower 的风与运动体验；星露谷钓鱼的持续控制思路，按本项目降低操作负担 |

动态关提供看得懂的力与运动方向。失误后的局部修正、撤销或重试方式写入单关方案。地图中的安静步行节奏与动态关的强度需要错开。

### 维度五：笔触介入与工艺显影

核心乐趣是操作留下可见痕迹。笔迹、颜色、形态或拓印结果与玩家输入对应，收藏保留这次互动的意义。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 18 擦拭、晕染、显影 | 操作区域、水墨量、扩散边界与停手时机 | 拂去画面浮尘，以水笔晕开色块，或让画内密信的题跋逐渐出现 | 大神的笔触介入；Splatoon 的表面覆盖反馈。显影工艺按本项目另行设计 |
| 19 套色版画、拓印叠章 | 图层先后、叠色关系与套准角度 | 分色版刷墨、对位、按压，揭纸后得到套色小画；印章逐层补全图案 | 版画与拓印工艺；[Pentiment](https://pentiment.obsidian.net/) 仅参考手稿、木刻视觉与动画 |
| 20 修剪、生长、做减法 | 保留哪些分支、哪里还有生长空间、减去哪些部分才能显形 | 在画中修枝引藤，或通过篆刻、刮蜡和留白显出主体 | [Prune](https://prunegame.com/support) 的修剪与生长；篆刻是另一个候选变体 |
| 21 丹青调配、茶汤合成 | 原料属性、浓淡、干湿、加入次序与研磨路径 | 调配画内颜料或茶汤，混合过程改变最后的色泽与扩散效果 | Potion Craft 的研磨、配料与工艺操作思路 |

自由创作允许不同结果，完成依据是玩家完成了可理解的创作动作。精准套色、描摹或配比属于另行选择的规则，不默认施加在自由画关卡上。画内虚构工艺与现实地点介绍分别标明。

### 维度六：韵律、时间与轻叙事

核心乐趣是观察与回应。声音、景物状态和人物动作给出线索，玩家的选择决定当下发生什么。

| 编号与机制 | 玩家真正需要判断什么 | 手绘与纸本结合方式 | 参考及借鉴范围 |
| --- | --- | --- | --- |
| 22 节奏、声音拼图 | 节拍快慢、点击时机、声部次序与组合 | 竹雨、脚步、铃声或捣茶声组成短句，操作让画中物件与声音一起运动 | Rhythm Heaven 的节拍规则；Florence 仅作互动与叙事情绪配合的参考 |
| 23 四时流转、晨昏拨动 | 时间前后哪些状态改变、哪些状态保留、何时能够推进事件 | 拨动画内日晷或时间线，利用影长、水位、开花或冻结的变化完成画境任务 | The Gardens Between、Braid 的时间控制思路；具体季节效果属于本项目候选设计 |
| 24 寻物、取景拍照、轻剧情 | 细节线索、构图取舍、发生时机，以及怎样回应画中人 | 根据线索发现物件，定格飞鸟掠过，或通过对话和让行留下不同记忆 | [Hidden Folks](https://hiddenfolks.com/press/hidden-folks-1) 的场景寻物；TOEM、Alba 的摄影与探索 |

声音线索同时提供视觉表达。轻剧情可以由一次明确操作启动连续演出，随后自然结束；它不必额外叠加拼图、计分或连续点击。时间操控发生在已说明的画境或回忆中，日间地图仍遵循路线确认的季节与行程。

## 路线选型依据

每个候选玩法用以下信息说明适配理由。

| 选型问题 | 设计稿需要给出的答案 |
| --- | --- |
| 为什么发生在这里 | 具体路段、季节、可见景物或事件依据；真实资料与创作部分分别写明 |
| 玩家想做什么 | 一个能理解的动词和目标，如让路、接通、拓印、辨影 |
| 玩家需要判断什么 | 轮廓、通路、次序、力度或时机；叙事关可以是一次有意义的选择 |
| 操作后哪里变了 | 画面、人物、物体和声音中的直接变化；完成效果与操作有因果关系 |
| 为什么值得收进手帐 | 对应的地点、经历、画面与文字；圆形徽章保留本关的记忆 |
| 和前后两关有什么不同 | 核心操作、主要判断、动静节奏和完成画面，至少能解释具体差异 |

一关默认聚焦一个主机制。需要辅助机制时，方案说明它如何帮助玩家理解主任务。新的判断逐步出现，手机操作不同时承担精细拖动、计时和多变量控制。

路线节奏依据玩家实际经过的路段安排。打卡点、小游戏与环境变化分别承担信息、互动和行走节奏；一个地点可以只有照片或一段风景，不必固定配一关。取景拍照属于可选机制，不能成为各路段的默认填充。

长坪沟采用十月彩林中的一日山谷徒步。森林、枯树滩、马道与木骡子的景物分别承载认影、解绳、借位接路与叶脉拓印，操作保持简单，每关完成都有圆形徽章。路段分布与当前玩法见 [路线设定](ROUTES.md)，不增加过夜或跨季行程。

## 共用体验与组件边界

所有机制沿用相同的旅程衔接：地图出现自然线索，展开手绘事件，玩家参与并得到反馈，完成后自动收进圆形徽章，徽章随画面淡回山路。跳过、退出和仅观看不写入完成记录，同一事件不重复收藏。

以下是可复用能力的归类，不是现有引擎能力清单。已实现模块及调用关系以 [架构说明](ARCHITECTURE.md) 和源码为准。

| 能力 | 适合共用的内容 | 由具体机制决定的内容 |
| --- | --- | --- |
| 输入与构图 | 指针、触屏、坐标转换、命中区域、取消与尺寸变化 | 拖动约束、可操作物件、手势含义 |
| 空间与路径 | 图层变换、遮罩、吸附反馈、通路查询 | 拼片邻接、折页正反、借位通行、腾挪与解除规则 |
| 图样与盘面 | 选中反馈、物件布局、操作历史、可撤销动作 | 记忆信息、配对关系、消除结算、合成和数织约束 |
| 动态模拟 | 时间步进、运动状态、接触反馈 | 力、张力、流量、材料参数与完成条件 |
| 笔触与工艺 | 笔迹保存、覆盖遮罩、颜料层、输入轨迹 | 干湿扩散、套版次序、调色配方、自由创作结果 |
| 声音与叙事 | 音频开关、暂停、时间线、镜头过渡 | 节拍、人物回应、因果条件、场景时序 |
| 奖励与资源 | 加载与失败状态、完成事件、收藏去重、徽章淡出 | 本关纪念画、完成文字与可保留的创作数据 |

共用框架承载输入、生命周期与反馈，机制保留独立规则。维度编号仅用于查阅，不作为统一状态机的分支清单。复用从已确认的具体关卡中提炼，不为覆盖 24 项机制预先搭建全部引擎。

## 画面、声音与完成反馈标准

- 手绘细节参与判断。可动图层与背景保持笔触、光照和材质一致。
- 画面适配手机竖屏、横屏和电脑可用空间，物件比例与命中坐标同步变化，页面下方不留大块空白，也不恢复游戏页致谢。
- 目标和关键线索在小屏幕上可辨认。误操作有可理解的反馈，重试不需要重看整段开场。
- 按下、移动、松手和完成各有对应的画面变化。笔迹和摆放结果持续保留，直到规则要求它们发生变化。
- 配乐、环境声与材质声分层，使用来源与许可明确的免费素材。静音仍可完成核心判断。
- 连续动画、自动行走和短暂停留可以承担叙事节奏；奖励条件仍对应玩家实际参与的事件。
- 徽章是本次旅途的记忆。首条已收藏记录、旧画作和旧日期不因重设计被自动覆盖。

每份方案包含以下字段，供讨论与后续制作使用。

| 字段 | 内容 |
| --- | --- |
| 状态 | 提案、已确认、实现中、已实现、已验证；各状态附实际依据 |
| 路线与路段 | 地点、前后路段、季节、日间或过夜阶段 |
| 画意与事件 | 值得停留的景象；进入前的自然线索；创作与实景的边界 |
| 主机制 | 01–24 中的主机制及变体；辅助机制如有则说明原因 |
| 玩家目标 | 一句话说明操作与希望出现的结果 |
| 输入与判断 | 手机、电脑各自的操作；玩家看什么、决定什么 |
| 可见反馈 | 初次操作、推进、失误、恢复与完成各自的画面和声音 |
| 完成条件 | 哪个事件算完成；哪些状态只算观看、跳过或退出 |
| 节奏与难度 | 预计时长、需要学习的规则、与相邻关卡的差异；不统一规定成功次数 |
| 手绘与素材 | 背景、活动物件、遮挡层、纪念画与实拍来源；可复用项和缺口 |
| 收藏与衔接 | 圆形徽章、回忆文字、自动入帐与淡出、回到山路后的状态 |
| 复用与定制 | 已有组件、需要扩展的共用能力、本关独有规则 |
| 待确认事项 | 尚未选择的机制、画面或节奏；不将提案写成已实现 |

方案评审关注玩家是否看得懂、操作是否改变画境、是否记住这段路。实现、测试和发布分别记录；这份文档更新不自动授权各路线开发或测试。
