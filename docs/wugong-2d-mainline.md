# 武功山切回 2D 主线

后续更新：用户已将背景改为程序化 2D 示意图，实际抵达时展开手绘与照片。当前样段与验证见 [武功山示意地图](wugong-schematic-map.md)。下文保留本次入口恢复的历史记录。

2026-10-18。按已确认的 [游戏理念与设计美学约定](game-design-charter.md)，把武功山入口切回 2D 行走、沿途水彩互动与旅行手帐收藏。此次只恢复入口和流程，不把既有 2D 程序山体与人物称为已完成的新手绘长卷。其他路线未迁移，3D 实验源码、资源与历史记录保留，未提交或发布。

## 入口与路线

首页武功山使用已有水彩草甸画作作为出发封面，明确东江村反穿、观音宕过夜、第二天经吊马桩和金顶下至景区大门。封面是入口插画，不是人物行走时使用的地图。

封面出发、下方出发按钮和“走进手绘山路”指向同一个 `wugong-walk.html?walk=1&scene=handdrawn-main-1`。首页保留的中庵旧地图不再作为武功山出发画面或行走入口；旧路线的零进度条和三站待解锁相册在该入口隐藏，实景仍在 2D 路线中抵达时展开。2D 页移除“走进立体山路”推荐，手绘独立页的返回地址也改为 2D 山路。

行走页沿用当前完整 2D 路线、脚步、营地休息、照片、时间天气与声音。默认跟随，地图内右上角由用户主动切全图。尚未重绘场景或调整现有美术比例。

## 水彩互动与手帐

草甸、观音宕营地、吊马桩和金顶的到站照片卡片，分别接入已有纸鸢、邂逅帮拍、拨云见山和金顶拼图。只有实际抵达后才能从卡片进入对应互动。

水彩互动复用既有小游戏、奖励和手帐控制器，通过 `wugong-art.html` 展开。只有真实完成才允许展示纪念和收藏，原存储键、画作 ID、去重与首次记录规则保持不变。顶部手帐入口读取同一份已有收藏。进入手绘或手帐时暂停行走、天气时钟、脚步和行走配乐；退出后恢复原路段，打开照片的状态保持原样。切后台仍遵循原有暂停规则。

共用手绘桥接源码移至 `src/wugong-walk/art-overlay.ts` 与 `art-page.ts`，2D 行走页不依赖 Three.js 场景。归档 3D 页引用相同桥接，保持可访问，不从主入口推荐。

## 验证记录

严格 TypeScript 编译与 `npm run build` 已完成。沿用已获得的武功山行走与沿途事件验证授权，集中检查本轮入口、照片卡片、手绘与手帐返回，不重复整条路线历史回归，不用此前的通过记录充当本轮证据。

真实浏览器从首页封面出发，进入 2D 页并自动行走；默认跟随、主动全图切换正常。途中打开手帐读取已有收藏及大图，旅程时钟在阅读期间保持不变，关闭后恢复原行走状态。

随后使用页面公开的“从营地走山脊”入口，实际走到吊马桩，照片加载成功。从到站卡片打开拨云互动，通过键盘辅助逐朵完成三朵云，进度依次为 1/3、2/3、3/3，完成后出现水彩纪念；点击“收进手帐，继续走”返回原吊马桩照片，路程与时钟未推进。再次打开手帐，原有同一画作仍只有一条记录，地点与首次文字保留。此次没有注入内部状态或用静态样稿代替互动，也没有复测另外三个小游戏的完整玩法。
