# 长坪沟 · 地形与地点图标

范围：长坪沟十月一日往返地图。继续使用程序绘制的 2D 示意图与现有 Q 版旅人。

## 本轮变化

- 右侧与右下方增加相连的近侧支脊、明暗坡面、沟槽、针叶林与秋色阔叶林群落，前景补充碎石和疏草地。
- 主溪流向下游延伸；山坡支流接入主谷，保留道路和人物落脚的可读性。
- 下干海子、上干海子使用浅草盆地；木骡子使用开阔草甸。没有新增虚构的打卡地点。
- 八处地点共用圆形外框、尺寸和线宽，图案按景物区分：

| 地点 | 地图图案 |
| --- | --- |
| 喇嘛寺 | 寺院 |
| 原始森林 | 针叶树与阔叶树 |
| 枯树滩 | 枯枝与浅水 |
| 溪谷 | 曲流与溪石 |
| 下干海子、上干海子 | 草地盆地 |
| 红石阵 | 红褐岩块 |
| 木骡子 | 远山、溪流与草甸 |

地点图标保持在原路线坐标，名称只在图标附近避让；没有引线。小游戏收藏徽章与地点标记仍为两套用途。

图标与名称排布分别封装在 `src/journey/landmark-symbol.ts`、`src/journey/landmark-label.ts`，由路线配置选择使用。目前只为长坪沟配置新符号。莫干山、九溪以及其他路线的地图内容、玩法和素材未调整。
