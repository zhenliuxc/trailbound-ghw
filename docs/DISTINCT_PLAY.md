# 同一条路线里的不同趣味

当前候选将24个瞬间重组为13类有独立条件的轻玩法。每趟按顺序遇到三种不同玩法；九溪三个区域的候选类型集合也互不重叠。当前只保存草稿，未部署。

| 路线 | 第一段 | 第二段 | 第三段 |
| --- | --- | --- | --- |
| 武功山 | 移动视线跟随飞鸟，留在光圈中片刻 | 横向拨开两片云影 | 移动光斑，在目标轮廓上停留 |
| 虎跳峡 | 指尖停住，等山羊放松和转头 | 跟随飞鸟越过峡谷 | 点不同溪石，组合远近回应 |
| 鳌太线 | 按顺序发现雪地足迹 | 移动2.4倍透镜，查看苔衣细节 | 将光斑留在雪斑上 |
| 麦理浩径第二段 | 在湿沙上画一笔，放手后让浪收走 | 左右翻转贝壳视角，看纹理和光泽 | 触水后停手，等待桥影回稳 |
| 长坪沟 | 用透镜观察苔木的微小世界 | 引导落叶沿三个水路弯点前进 | 停止搅动，等待远山倒影回来 |
| 莫干山 | 连点雨滴，留下自己的一小段节奏 | 按顺序点亮石阶转角 | 将竹叶放进溪石凹处 |
| 九溪龙井 | 点溪石回应，或引导落叶过弯 | 翻看新叶，或让叶脉接住光 | 连点檐雨，留下雨后节奏 |

## 行为

- `dist/moment-play.js` 管理独立的完成条件、目标、局部绘制和状态文案；`micro-moments.js` 保留统一的时钟、手势、暂存和手帐入口。原六种视觉分类继续用于原录音/音效选择，不再等同于玩法类型。
- 点错脚印不会前进；落叶需要逐段通过水路；小透镜使用局部裁切和真实2.4倍细节位移；贝壳随横向手势翻转；拨云依赖横向距离；光斑和飞鸟需要短暂停留。沙画在拖动时保留，松手后才被潮水收走。
- 多次点按会产生独立雨滴与波纹，不把浏览器合成的click再算一次。溪石有三种位置音色和短回应；节奏声与触屏动作对应，依旧需要玩家明确开启声音，静音玩法完整。
- 操作不足时只留下尝试的回忆，不提前声称完成。静静观看也可记录；未操作就提前继续仍可直接跳过。过程没有分数、失败惩罚或必做任务。
- 现有动画入口和后台暂停保持。每段最多约10秒；常规操作约3.4秒后回到旅程，尚在探索的其他六路线可延续到约6秒。长拖、触屏取消、切图、后台会释放捕获。完成条件不阻塞旅程。
- 键盘/开关设备可用回车逐步操作当前目标，方向键移动。减少动态效果时停用循环运动和落滴，保留静态反馈。
- 手帐继续保存look/tap/drag与具体文字，旧记录和24个徽章ID保持兼容。玩法进度仅在当前近景中暂存，不改变存储格式。

## 验证

`npm run check` 与全部160项测试通过，日志 `distinct-play-test-output.txt`。新增/改写回归验证每地图三类互斥、按序目标、松手后潮水擦除、横向转动/拨云、停手恢复、连续点按和去重、透镜裁切位移、键盘替代、三个视口后台恢复和位置音色。七路线完整旅程、照片、旧手帐、静音和原资源许可回归继续通过。

静态绘制每近景控制在300个节点以内、手势轨迹最多24点、节奏事件最多6项；不新增下载、依赖或计时器。节点预算不代表真实设备帧率。

`previews/distinct-play-review.png` 展示七地图各三个实际SVG近景，配套压缩SVG与 `scripts/render-distinct-play-review.cjs` 可重现。预览为真实模型驱动的静态美术检查，不是浏览器截图或手机实测。真实CSS、触屏手感、WebGL帧率与音色听感仍待试玩验证。
