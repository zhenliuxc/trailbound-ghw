## 体验

- 九溪「水绕石行」：点落叶旁的水面，水纹产生方向性推动；落叶受水流、惯性和溪石碰撞影响，经过三处水口才完成。水口错过会等待调整，不以任意滑动距离发奖。
- 莫干山「竹涛一阵」：移动竹筒接八滴雨，雨滴具有下落位置与速度。只有实际接住才推进；漏接可以继续。反馈含滴水敲击和逐个变化的音高。
- 武功山「草浪来信」：上下控制纸鸢，风向周期变化，连续穿过三处不同高度的风口。错过重来当前风口。纸鸢为虚构的游戏意象。
- 三处都取消原先几秒自动退出；可重试、跳过、用方向键操作。完成后短暂庆祝，再调用既有手绘奖励弹窗与保存逻辑。旧手帐文字、标签与图像版本不改写。
- 声音默认关闭，通过现有开关或小游戏内的声音按钮开启；背景环境声音沿用原路线，新增操作声由 Web Audio 合成，按实际接取、碰撞、错过和完成事件触发。静音、离开页面和后台暂停遵循原生命周期。

## 画面与加载

新增独立 PixiJS 场景，不再移动整张奖励图。静态远景和动态操作对象分开绘制；武功山与莫干山复用既有、时节相符的水彩场景，九溪增加不规则溪石、苔痕、浅水石子、叶脉和水纹。静态几何只构建一次；触控移动合并到动画帧处理。减少动态效果模式停止装饰运动，保留完成玩法所必需的物体运动。

GPU 初始化失败或上下文丢失时，使用同一份几何和规则的 SVG 回退。异步初始化后若互动已退出，立即释放迟到的渲染器；退出互动释放自有 GPU 纹理。

新绘图资源队列最多并行两项，按当前路线预取；高优先级请求提前排队。图片完成 decode 后才替换奖励节点，复用已解码 Image；出错显示说明，奖励仍可收好。路线切换取消过时的排队任务、清理旧打卡照片引用，绘图缓存按上限回收。小游戏在图像未就绪时仍能用矢量场景运行。

## 验证与限制

- 新增 14 项定向自动检查：真实输入可完成三种玩法、等待/误操作不发奖、错过与重试、减少动态效果、PixiJS Graphics 几何 API、320 与 990 宽度的 DOM 模拟操作、暂停/跳过、完成后一次性存档、声音静音及清理、渲染器延迟初始化/失败回退、旧手帐保留、加载并发与图像复用、取消过时资源及失败重试、decode 失败。
- 原测试夹具继续覆盖旧互动兼容路径，新小游戏集成测试显式加载新增模块，不将旧互动通过误认为新玩法验证。
- npm run check 与 git diff --check 通过；最终 npm test 报告 25 个测试文件全部通过，0 失败。新增两个文件直接执行时报告 11 + 3 = 14 项定向检查全部通过。
- 真实 PixiJS Graphics API 检查不是 WebGL 画面验收；DOM 尺寸模拟不是浏览器排版或实体手机验收。
- 当前没有可用浏览器控制工具，尚未验证真实浏览器画面、手机触控手感、GPU 帧率、弱网瀑布图或实际音频听感。没有声称加载卡顿已经在设备上消除。

## 主要文件

- dist/mini-games.js：玩法状态、碰撞、目标、共享矢量场景与 PixiJS 生命周期。
- dist/image-cache.js：图片预取、并发限制、解码及缓存。
- dist/app.js：玩法、操作、奖励与路线资源集成。
- dist/audio.js：事件音效。
- tests/mini-games.test.cjs、tests/image-cache.test.cjs：新增定向检查。
