# 麦理浩径地标标注校正

2026-10-21。本地修复并完成相关浏览器检查，未提交、未发布。

## 原因与改动

地景和标签都使用 `PLACES[id].site`，但旧样式按文字方向平移整个按钮。图标随文字一起离开地景。桌面全图中，西湾山图标水平偏移约 62 像素，西湾和赤径约 50 像素，起终点也有偏移。

`dist/maclehose-walk.css` 将 44 像素的点击区域固定在投影坐标，图标居中。名称单独排在图标左、右、上或下方。名称本身也能点击，打开该点照片。`dist/maclehose-walk.html` 更新样式缓存版本为 `landmark-align-17`。

路线顺序、地景坐标、照片和事件数据保持原值。其他路线未改。本轮只修改直接维护的 CSS 和页面样式引用，没有改动 TypeScript，无需重新编译。

## 实际检查

- 本机浏览器检查桌面 1454 × 818 和手机尺寸 443 × 959 的全图。七处地标均显示，名称矩形没有重叠。
- 七处图标中心与其投影坐标的差值均小于 0.01 CSS 像素，属于排版取整误差。该数值验证图标定位，不代表 GPS 测绘精度。
- 手机随行视角检查浪茄及邻近标注，图标保持同一地景位置。
- 从起点打开浪茄照片后停留，再直接点击地图上的浪茄名称，正确打开浪茄实拍。关闭后保留暂停状态。
- 当前预览收集到的控制台警告和错误为零。已恢复临时视口设置。
