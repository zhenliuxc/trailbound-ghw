# 旅行手帐 · 翻看与展示优化

基于原站点版本 35（Sites 源码 `6e5398d52a85192726c6f4948a3a31931b320329`）、开发分支 `codex/recover-site` 的 `1acbe0c` 实现。开始时工作区无未提交改动，GitHub 与线上源码树一致。

## 本轮实现

- 标签墙采用米白纸色卡片、统一画作比例及标题／路线／翻看提示位置；宽屏五列、中屏四列、手机两列。保留原水彩画作、路线筛选、去重与按需追加。
- 详情改为连续阅读：上一枚／下一枚、当前位置、左右方向键、手机短距离横滑。按打开时的路线筛选读取全部已保存回忆，不受墙面已加载数量限制；到首尾停止，不循环跳转。
- 详情头部与翻页栏固定，正文独立滚动；桌面图文并排，手机大图在上、文字在下。关闭按钮保留 44px 触控面积；关闭后焦点回到打开详情的原标签，不改变标签墙位置。
- 翻页加入轻微位移与淡入，支持减少动态效果。横滑避开链接、折叠说明等控件，纵向滚动和缩放仍可使用。
- 只保留当前及前后相邻的画作节点，提前加载、解码并复用；关闭后释放阅读缓存。缺图时继续显示提示和文字，不影响翻页与退出。
- 延续阅读时暂停行进／小游戏／声音的行为，关闭时按原状态恢复；不修改历史数据或奖励判定。

## 当前状态

实现已完成。用户随后明确要求“发布一下”，本次直接发布，不运行尚未授权的自动测试、语法／素材检查、浏览器、真机或音频验收。发布终态以 Sites 返回为准，不能将部署成功当作交互验证通过。

建议获得授权后覆盖：筛选范围内连续翻页（含超过 12 条）、首尾及仅一条记录、快速切换、键盘与触摸方向／滚动判别、相邻图片节点复用、旧记录／缺图展示、关闭后的焦点与暂停状态。实际手机和电脑仍需检查长文本、短屏、字号放大及底部控件的显示与触控。
