# 五个水彩标签互动 · 2026-10-15

在恢复版本25基础上，补齐剩余5张图稿的互动和获取流程。23张图稿现在都有运行时绑定；总目录29个互动，原来的24个保留。武功山、虎跳峡、秦岭虚拟章节、麦理浩径与九溪龙井各增加一次可选片刻，长坪沟和莫干山不变。

| 标签 | 操作与完成条件 |
| --- | --- |
| 吊带追风 | 横划草甸送风；累计横向移动达到阈值，或键盘激活两次 |
| 铃声先到 | 点亮左、中、右三处；开启声音后播放合成铃音，静音也可凭亮点完成 |
| 牛牛先请 | 轻点左侧退让处并静候1.8秒；移动离开会重置等待。仅观看或点在右侧不会获奖 |
| 横着也能到 | 从左到右依次点亮三个沙地落脚处；可用键盘逐点完成 |
| 再坐五分钟 | 轻点开始，等1.8秒茶香舒展；无需实际等待五分钟 |

五个片刻均注明「游戏虚构片刻」。人物、动物图案沿用获准的水彩WebP，以图片作为互动主画面；目标亮点与进度提示为覆盖层。未新增扁平SVG奖章。

## 记录和历史兼容

新片刻完成才发对应标签。跳过新片刻保存一条普通记忆，不发标签，也不立即重复弹出。原存储key/version:2、历史图谱和旧edition:3图不变；新标签保存artVersion:4。每次旅程保留独立回忆，收藏种类不因重复获取而增加。

追加片刻的出现窗口按顺序截断，保证前一个未收集的景物不会遮住新片刻。100个随机种子逐项检查可达性与非重叠。西湖原有三组随机景物仍保留。
