2026-10-15：在七路线完整玩法候选上细化其余六条的18个瞬间。当前只保存代码，不部署。

| 路线 | 新增反馈 |
| --- | --- |
| 武功山 | 飞鸟随视线移动、草穗随拖动倾斜、云影和光斑移过草坡 |
| 虎跳峡 | 山羊微转头和动耳、飞鸟与峡谷影子、水流碎光 |
| 鳌太线 | 雪峰与林缘背景、脚印揭示、细密苔衣、雪斑上的移动光束 |

每个瞬间有独立动作提示和地点关联回忆；保留轻触、拖动、静静观看、跳过、暂停恢复与静音流程。仍由现有单一动画入口更新，不新增计时器、网络资源、奖励门槛或必做操作。减弱动态效果时不播放循环摆动与落滴，保留静态操作反馈。

`npm run check` 和全部154项测试通过，见 `regional-effects-test-output.txt`。四项新增测试覆盖18种提示/回忆/可见反馈、深层减弱动态检查、连续坐标响应、竹叶雨滴分阶段、落叶/潮线/倒影变化。
