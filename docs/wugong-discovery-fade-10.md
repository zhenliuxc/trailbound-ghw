# 武功山发现与记忆淡出

2026-10-18，本地实现，未提交、未发布，观感待用户验收。仅调整武功山现有 2D 行走主线。

## 本轮行为

六个游戏到达触发位置后，人物先停稳，在地图上出现对应线索与一句发现文字，随后自动展开手绘互动。林间落叶、草甸纸鸢、营地星空、清晨云、金顶石色与下山翻页各有不同内容。普通模式的发现约 2.6 秒，游戏与遮罩约 0.65 秒淡入。地图继续保持默认跟随，图上没有新增常驻游戏标记。

完成互动并保存成功后，圆形徽章与记忆停留约 1.5 秒，再用约 0.95 秒淡出。叶影、星空、来路小画与原有纸鸢、拨云、石语共用这一节奏。移除了快速缩小飞走的收藏表现。原有游戏通过 iframe 返回时，整个视图再淡回地图，其他路线仍保留原来的手动收藏行为。

未完成退出、跳过或取消发现不发奖。保存失败继续保留重试；同一记忆重玩不改写首次记录。转场与自动收藏在切后台时暂停，返回后接着播放；销毁或取消后不执行迟到的打开、继续回调。减少动态效果时保留阅读时间，仅做短透明度过渡。

## 实现位置

- `src/wugong-walk/scroll/discovery-transition.ts` 定义六种发现线索并控制打开游戏的时机，`scroll/main.ts` 接入真实行进事件。发现过程中可用 Escape 停留在山路。
- `src/wugong-walk/visible-motion.ts` 管理可暂停、可取消的浏览器动画；`trail-keepsakes.ts`、`camp-night.ts`、`art-overlay.ts` 使用它处理出入场。
- `src/runtime/reward-controller.ts` 仅在已有 `autoCollect` 分支使用记忆淡出。当前只有武功山手绘页开启该分支；默认手动流程维持原行为。
- `dist/wugong-transitions.css` 配合页面与原有小游戏样式，淡化遮罩、场景和徽章。沿用 Web Animations 与 CSS，没有接入新框架或生成新底图。

沿用用户已授权的武功山完整行走与沿途事件测试范围，集中核验本轮转场，不重复以此前整程记录作为新证据。

构建成功。第一次运行相关六个文件共 48 项通过；随后给自动奖励补充减少动态效果断言，并单独重跑该文件 7 项通过。本轮最终为 49 个不同检查项，见 `docs/previews/wugong-discovery-fade-10/related-checks.txt` 与 `reward-checks.txt`。其中生命周期、后台暂停、降级与保存失败属于受控模型检查，不能替代实际浏览器或设备验收。

实际本地浏览器操作验证了：

1. 从东江村出发走至叶影互动，实际翻叶配对完成。徽章为圆形，先显示“已收进手帐”，对话框透明度从 1 淡到约 0.082，关闭后自动继续行走。
2. 营地星空实际连完七笔，徽章对话框从透明度 1 淡到约 0.164，随后回到夜间营地。住一晚、清晨整理背包、第二天出发与山脊拨云事件顺序连续。
3. 拨云游戏实际完成三片云，自动入帐并返回山路；另开同一游戏页观察奖励，收藏按钮隐藏，奖励层透明度由 1 淡到约 0.347。
4. 重进营地样段，在星空发现文字与线索可见时按 Escape。等待超过原过渡时长后，仍停在营地，游戏没有迟到打开。
5. 打开实际手帐，仍为 7 条历史收藏，叶影、星夜与拨云重玩没有新增重复项；关闭手帐也能淡回默认跟随地图。两个验证页面的浏览器控制台没有警告或错误。
