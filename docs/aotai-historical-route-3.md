# 鳌太线：塘口进、汤峪方向出山

用户确认按历史路线修正鳌太线，随后指定冬季，保留 2D 示意图、现有两位 Q 版旅人和四枚圆形徽章。仅改鳌太线，不提交或发布；沿用本批已授权的集中测试。

## 路线与呈现

- 塘口、药棚、2900营地、盆景园、白起庙、鳌山导航架、西跑马梁、药王庙、麦秸岭、水窝子、飞机梁、连峰、2800营地、南天门、金字塔、西塬、太白梁／九重石海、大石河、东塬、万仙阵、雷公庙、东跑马梁、大爷海、拔仙台，再返回大爷海，经大小文公庙、上下板寺下山。
- 下板寺之后以接驳虚线与车辆离山，标明汤峪方向，不把接驳距离算成徒步，也不提供逐段现实导航。
- 共用一份命名地点与路径数据生成地图、行进站点、过夜和事件位置。海拔只驱动游戏爬升／下降动作，不把展示坐标当成 GPS，也不以游戏点位差冒充累计爬升。
- 相连山体、支脊、谷地、低处针叶林、高处冬日积雪与裸露石海；去掉山体底部悬空的边缘及大块平涂蓝灰底板。默认跟随，右上角主动切全图，拥挤次要地名在随行时再显示。
- 在盆景园、水窝子、2800营地、大石河安排四次过夜，形成五程压缩时间的旅途。宿营节点为历史地理展示，不是当前宿营建议。
- 四个游戏依次落在白起庙至鳌山石海、飞机梁连峰、2800营地林缘、万仙阵薄雾。游戏仍随行自动发现，不在地图上摆游戏按钮。完成后继续自动入帐和淡出。
- 沿用三张有许可的实拍：白起庙对应地点，太白梁和拔仙台仅使用明确标注的太白山区域配图；未补齐新的定点照片。

## 来源与数据边界

- [2009 塘口—下板寺历史实走](https://www.doyouhike.net/topic/375783)：路线主干、东西关系和汤峪出山方向。
- [历史多日节点](https://www.8264.com/youji/5273647.html)：盆景园、水窝子、2800、大石河的先后关系；其鹦鸽出口不采用。
- [历史出山方式](https://www.8264.com/youji/2401095.html)：上下板寺与汤峪之间的接驳关系。
- 对用户的里程答复为历史记录交叉估计：约 70–80 公里、累计上升约 4000–6000 米、重装约 5–7 天。未找到同一条完整且可核算 GPX 前，不把这些量级估计写成精确测量或游戏计数。不同记录的出口、绕行和仪器滤波不同。
- [国家林草局说明](https://www.forestry.gov.cn/c/www/zhzs/658083.jhtml)：现实鳌太禁止穿越；本章仅作历史地理虚拟体验。
