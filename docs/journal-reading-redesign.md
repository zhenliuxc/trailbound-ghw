# 旅行手帐图文合一 · 待测试

用户确认图鉴和回忆是同一件事：一幅图配一段文字，不需要导入、导出功能。此决定同步记录于根目录 AGENTS.md。

## 本轮实现

- 手帐直接展开图文纸页，移除独立图鉴、未收集占位、收集进度和原来的页底详情区。
- 已获得的画作和对应标题、地点、完整回忆、时间、天气放在同一页中；地方知识保留为该页内的次要折叠内容。
- 普通记事保留文字，不补发图或展示空徽章。旧标题、画作版本及重复旅程不去重、不替换。
- 电脑宽屏两栏，中等宽度单栏左右图文，手机单栏上下图文；图片保留比例，正文不截断。
- 路线筛选保留；每次展示 12 段，新记录在前。继续翻阅只追加新页，不重建已展示的图片，并把键盘焦点放到新增内容。
- 移除导出按钮、备份说明、下载逻辑和图鉴聚合逻辑；导入入口仍不提供。
- 读取、保存使用原有 discoveries.js 和存储键，未执行数据迁移或清理。浏览器自动保存提示保留，容量提示不再引导导出。
