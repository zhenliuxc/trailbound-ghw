# 渲染与第三方库

## 画面分工

主线采用 PixiJS 的 2D 场景图。地图用程序绘制山体、谷地、水系、植被与小径；人物使用现有可选的 Q 版素材。DOM 与 SVG 承担地点图标、名称和界面。封面、小游戏和纪念画使用手绘水彩素材，打卡弹窗展示地点实拍。

地图、地点、输入命中、遮罩与脚点共用坐标转换。世界坐标、容器像素和设备像素比分开处理。公共镜头负责跟随与全图切换，人物屏幕尺寸与跟随平滑度由共享组件约束。滤镜范围按所在容器的坐标定义，不把屏幕矩形直接当作世界矩形。

| 能力 | 当前依赖 | 用途 |
| --- | --- | --- |
| 2D 绘制 | PixiJS `8.22.0` | 主线地图、精灵、场景图、局部滤镜及部分小游戏 |
| 2D 物理 | Matter.js `0.20.0` | 需要物理行为的小游戏与场景能力 |
| 地理制图 | d3-geo `3.1.1` | 构建全国路线地图几何 |
| 构建与类型 | TypeScript `5.9.3`、esbuild `0.25.12` | 严格类型编译与浏览器打包 |
| 图片处理 | Sharp `0.35.5` | 素材制作与图像输出 |

版本由 `package.json` 与锁文件锁定。本文件描述已使用的工具，不列未采用的框架候选。

## 场景与生命周期

`src/journey/` 管理镜头、投影后的地点标记、照片与游戏弹窗、发现和返回转场。`src/runtime/` 提供小游戏控制器、角色、输入、奖励、存储与共用视图。路线自己的模块维护地形绘制和行程状态。

场景只使用所属宿主的时钟。暂停、后台或弹窗状态决定哪些动画和声音停止；关闭和退出时释放图层、监听、媒体与异步任务。游戏完成先形成真实结果，再经保存和奖励转场返回地图。

云雾、草木和人物分层，局部模糊与颜色调整不降低整幅图清晰度。画布分辨率按实际尺寸和设备像素比设置，图片按可见主体裁切；触屏构图改变时，命中和拖动坐标同步调整。

## 资源与分发

素材源位于 `public/`，制作源和生成脚本按 [架构说明](ARCHITECTURE.md) 管理。主游戏画面与小徽章分开提供，不放大低分辨率徽章代替场景。相同资源复用加载与解码结果；加载失败保留可读文字与退出路径。

第三方许可保存在 `public/vendor/`、对应素材目录以及构建输出的许可证文件中。保留按素材记录的作者与修改方式，具体依据见 [素材来源与许可](PROVENANCE.md)。

## 画面标准

程序地图负责空间可读，手绘负责细腻的发现与回忆。库的存在、GPU 能运行或构建通过，都不能代替风格与交互验收。基本检查覆盖电脑与手机的主要流程、画面裁切、脚点和操作区域，音频需要实际试听。
