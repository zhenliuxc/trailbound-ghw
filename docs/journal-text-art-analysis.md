本次为源码、素材配置与用户截图的分析，没有执行测试，也没有读取用户浏览器中的实际 localStorage。不能据此列出用户当前所有未完成记录或其数量。

## 结论

当前 29 类互动均配置水彩奖励图：18 类基础 v4、5 类相遇 v4、6 类补充 v5。对应文件出现在 dist/badges/ 中。没有发现“完成互动后仍未配置画作”的类别；未进行线上图片请求、解码或显示验收，因此这不代表加载问题已排除。

纯文字的直接原因是 edition=3 且 earned 不是 true。discoveries.js 的 tagArt 此时返回 null，手帐不会展示奖励图。原来页面出现的“一段沿途回忆”属于未获得标签的占位，不等于图片丢失。

## 还有哪些可能产生纯文字

所有当前互动都可能在未完成时生成文字记录，并不是某几类专门没有配图。

- 普通互动：用户已经操作过，但通过“继续走”、Escape 或打开照片提前离开时，finishMicro 会保存 earned=false 的记事。
- 额外人物／动物相遇：bonus=true 时，即使没有操作就离开，也可能保存一条文字记事。
- 三个 PixiJS 小游戏：未完成时生成“我试着与这里的风雨玩了一会儿，下次再来”等文字，不发奖励图。
- 旧版手帐通常使用旧图集。它们不是当前 earned=false 的文字记事，不应混为同一类；某些旧文字与现版场景名称不同。

## 用户要求清空历史的处理状态

已实现当前浏览器内的主动清理：仅在检测到旧手帐时显示提示。点击“清空这份旧手帐”后，确认框明确告知会永久删除当前浏览器中这份手帐的全部记录、无法恢复、不影响其他浏览器和存档；取消或不操作不会写入存储。

确认后才将 trailbound.field-journal.v1 替换为空记录，同时写入 historyRevision=1。之后的新记录不再被清理。不调用 localStorage.clear，不清理其他站点数据，也不删素材或 Git 历史。没有旧手帐的新用户不会看到清理入口。存储权限失败会明确提示未能清空。

用户浏览器的历史尚未通过工具删除；发布后仍需在页面主动确认。原 cce12cf 的自动清理草案已被替换，不会随页面打开自动执行。

针对性自动验证已完成；实际浏览器画面、实体手机和听感未验收。详见 journal-reading-release.md。
