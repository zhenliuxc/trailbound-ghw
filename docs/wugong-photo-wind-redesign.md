用户已确认：吊带追风是邂逅美女的故事，应围绕拍照展开；原山脊取景改为风路解谜。此次制作仅覆盖这两项，其他路线按讨论稿逐项确定。

## 吊带追风

沿用 `wugong-wind-hiker`、原画与标签，改成一段完整相遇：招呼 → 她请玩家帮拍 → 取景 → 快门 → 查看照片／重拍 → 给她看 → 告别 → 手绘纪念。

- 拖动取景框、用独立按钮调整远近和拍照。取景须保留人物面部、上身和一定的山野空间；宽容判定，不要求停留或重复成功三次。
- 实际取景位置、远近与人物姿态会冻结为当次照片。预览照片从纸框里展开，给她看时移至一侧，露出人物回应；告别后才完成。
- 不合格的试拍给出构图提示，可以重新取景。查看照片、静置或只完成交谈均不获得画作。
- 本轮当次构图用于场景内预览；手帐仍收藏原水彩画，同一 ID 一条记录。没有加入照片文件导出或新的存储格式。
- 复用已生成的草甸背景、三姿态人物与草叶图层。人物采用已有姿态切换，没有宣称新增回头、口型或真人配音。

## 云海开信

沿用 `meadow-butterfly`、云海浮岛原画与标签，改成先规划再观察的连线路径谜题。

- 在来风口、谷地、山坳和远谷出口间点选或连续连线，按「送出这阵风」后观察结果。
- 邻接关系在画面中有淡线提示。高脊挡风，洼地引起回流，未接到出口的风停在半途；分别提示原因，允许撤回一步或重画。
- 一条合适的谷地风路完整送风后完成。没有自动等待完成、三处停留或摄影步骤。
- 云雾随送风进度分层移开，错误路径会让近处雾团积聚；保留原画中的谷地云海。草叶网格、风中微粒与纸页过渡共用游戏时钟。
- 这是手绘场景中的连线解谜与视觉反馈，不是气象流体模拟。

## 两端操作与资源

操作按钮放在画面下方，避免遮挡人物和连线节点。竖屏使用完整宽度和可滚动面板，横屏将操作放在场景一侧。画面、取景与点击使用同一比例坐标；手机节点文字随显示尺寸放大。

键盘：方向键移动；云海空格选点、Enter 送风、Backspace 撤回；拍照空格／Enter 操作、＋／－调整远近；R 重试，Escape 退出。保留暂停、静音和减少动态效果。

路线提前请求所需素材，复用现有解码缓存与上传准备。场景／人物加载失败时阻止送风或快门完成，并提示重新展开。渲染失败保留同样规则的 SVG 降级场景。

声音复用已打包的草叶录音与短叶声拟音，新增送风、沿路转向、受阻、招呼、展示照片和告别事件。快门使用合成短噪声、双击音和已有拟音，不是新下载的真实相机录音。新增风声支持空间位置，用户主动开启后才播放；原许可记录不变。

主要文件：`dist/wugong-stories.js`、`dist/wugong-games.js`、`dist/mini-games.js`、`dist/app.js`、`dist/audio.js`、`dist/style.css`、`dist/route-moments.js`、`dist/journey.js`。
