## 已接入的流程

1. 桥头一带出发，沿现有历史高路轨迹行进。
2. 二十八道拐：鼠标／触屏在人物前方按住带路，连续经过折返；松开即停。键盘方向键／WASD辅助。局部弧长窗口约束引导范围，人物按实际路程前进，不能点击终点瞬移。角色转向、步频和转弯减速；镜头跟随，近景岩壁退开，到顶后主动收藏。
3. Halfway：以对面山墙为主体的新水彩画面，拖动看山、歇好了继续；不发收藏。
4. 龙洞：人物沿新画作的小径自动经过，窄水线使用局部水流动效，随后沿高路继续；不放虚构地理标记、不增加一套描线任务、不发收藏。
5. Tina’s 一带为高路终点。可就此结束，也可进入张老师小路江边支线。
6. 中虎跳江边：拖动取景、调整远近，轻按快门拍一帧，按住短连拍（最多五帧）；选片、重拍、主动收下。实际保存当次相机及水流状态的栅格画面。
7. 江边到达后明确尚需返回。沿张老师小路原路返程，约 7.2 秒顺序过场，减少动态效果时约 2 秒；可暂停，最终回到 Tina’s 一带。

全部路线的现有轨迹首尾加入起点／终点标识；虎跳峡用桥头与 Tina’s 一带的端点名称。地图地标与 UI 文字位置分开，标签随显示尺寸调整，地理锚点不随画幅变化。

## 代码边界

- `src/runtime/tiger-trail/rules.ts`：纯状态规则、连续步进、相机与取景、拍摄请求、选片和完成条件。
- `src/runtime/tiger-trail/geometry.ts`：画中代表性小径，**不是 GPX 或全部 28 弯复原**。
- `src/runtime/tiger-trail/scene.ts`：PixiJS 8.22 主渲染，等比镜头与统一输入坐标；分层水彩、8 帧人物、局部水网格和白浪。SVG 仅作图形环境不可用时的可玩降级。
- `src/runtime/tiger-trail/adapter.ts`：控件、键盘、按住快门、缩略图、异步捕获结果队列。
- `src/app.js`：真实锚点触发、主线／支线状态、顺序图、返回及结束。
- `dist/tiger-route.js`：地理坐标、来源及状态；实际坐标投影后产生触发距离，不编造进度百分比。
- `dist/discoveries.js`：新手动地标目录及截图持久化兼容。
- `dist/tiger-trail.css`、`dist/index.html`：控件与照片条在画面外；桌面／竖屏使用实际容器比例。

场景使用项目已有帧循环；退出销毁 GPU 对象与监听，后台暂停。捕获结果带场景代次和请求 ID，重试／退出后迟到的结果不能写入另一轮状态。键盘焦点离开画面时释放移动键，避免错过 keyup 后持续前行。
