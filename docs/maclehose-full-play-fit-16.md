# 麦理浩径五关实玩与屏幕适配

日期：2026-10-21。状态：本地实现和浏览器检查完成，未提交、未发布。

## 本轮改动

五个小游戏共用随窗口伸展的画面容器。手机竖屏将操作放在画面下方，低矮横屏将操作放在右侧，电脑使用可用宽度和高度。游戏页移除“致谢”，路线资料页及素材许可保留。

螃蟹关在竖屏随前进展开沙地，拖动漂木时镜头保持稳定。泊船起点移近渡头，竖屏能同时看见小船与系桩。物件保持原比例，绘制和输入使用同一套坐标变换。

林间回声增加横屏取景调整，小鸟和点击位置一起移动。潮汐收笔补上声音、重试和键盘重试，并修复适配后松手未结束笔迹的问题。竖屏裁切后，笔迹仍落在指针位置。

实现位于 `dist/maclehose-art.css`、`src/runtime/coast-memories/` 和 `scripts/build-wugong-art.mjs`。共用控制器的工具栏开关为显式选用，其他路线不启用本轮适配。

## 浏览器实玩

使用本机浏览器和真实指针操作，未注入路线进度、完成状态或手帐记录。

| 游戏 | 实际操作及结果 |
| --- | --- |
| 登高望海 | 点击山路一次，自动爬升，站在高处望海。原行程看到徽章入帐；适配后竖屏复查了自动爬升、站立望海和返回山路。 |
| 横着也能到 | 拖开两根木头时仍被第三根阻挡，不发奖。第三根移开后螃蟹通过并入帐。竖屏按可见物件再次拖开三根木头，看到徽章。 |
| 潮汐收笔 | 在沙上拖动并松手，潮水收走笔迹，徽章自动入帐。适配后竖屏复测声音开关、重试和松手完成。 |
| 林间回声 | 开启声音并重听，先按左、右，再按中、左、右回应。原行程完成入帐；适配后横屏静音状态按可见小鸟再次完成两段回应。 |
| 赤径慢潮 | 拖船到渡头，停稳只进入拿绳阶段。绳圈放错位置不发奖，拖到系桩后入帐。适配后竖屏再次完成靠岸和系绳。 |

完整旅程页到达北潭凹，显示五段手绘记忆。七处实拍均检查加载，赤径码头显示 Wpcpey、原始照片链接及 CC BY-SA 4.0。手帐筛选麦理浩径后显示五枚独立徽章，图片全部加载；重玩未增加重复记录。

大浪坳之后，原行程页签在没有连续操作记录的期间推进到终点。赤径实拍及泊船关随后分别补验。本报告不把该段写成单次连续操作的完整证据。

## 屏幕检查

每个游戏检查三种布局，共十五个页面样本。下表记录浏览器实际返回的 CSS 尺寸，区别于设置面板中的目标尺寸。

| 布局 | 实际视口 | 画面可用高度 | 结果 |
| --- | --- | --- | --- |
| 手机竖屏 | 443 × 959 | 约 727 px | 五关均填满容器，提示和操作在屏内，无致谢页脚。 |
| 手机横屏 | 959 × 443 | 约 299–317 px | 五关均在屏内，操作移至侧面，小鸟没有被裁出画面。 |
| 电脑 | 1636 × 1023 | 约 794 px | 五关随屏幕展开，页面没有额外纵向空白或横向溢出。 |

实际截图和尺寸记录位于 `docs/previews/maclehose-fit-16/`。本机浏览器多尺寸检查不等于实体手机验收，声音开关与流程检查也不等于人工听感验收。

## 自动检查与限制

`npm run build` 成功。以下相关检查共 29 项通过：

```sh
node --test tests/maclehose-coast.test.cjs tests/maclehose-saiwan.test.cjs tests/maclehose-layout.test.cjs
```

原始输出保存在 `docs/previews/maclehose-fit-16/model-checks.txt`。新增检查覆盖镜头与输入坐标一致、不同构图下小鸟可见、画沙松手后完成，以及沙地区域之外拖动不发奖。

同时尝试了共用控制器的 `tests/mini-games.test.cjs`。其中四项旧用例在首页全国选线地图初始化时失败：模拟元素缺少 `ownerDocument`，未进入待测游戏行为。临时补充模拟 DOM 后还暴露 `classList`、`ResizeObserver` 及页面跳转模拟缺口。诊断改动已撤回，本轮没有为这些夹具问题改动其他路线产品代码，也没有把四项写成通过。

原行程截图位于 `docs/previews/maclehose-full-play-15/`，包含入帐、阻挡判断、七处照片、终点与筛选手帐。适配后的互动与构图证据位于 `docs/previews/maclehose-fit-16/`。
