# 武功山纸鸢体验改稿（未发布） · 2026-10-15

基于已发布版本29 / GitHub b8859d6。用户截图指出原型的几何风筝、细圈、背景和控件不协调，本轮集中修正武功山「草浪来信」互动。

## 改动

- 换成原创水彩燕子纸鸢：纸纹、羽纹、竹骨与暖色纹饰，独立透明 WebP，78,066 字节。沿用暖季草甸背景；不把整张奖励图作为操作对象。素材来源与校验值见 dist/sprites/manifest.json。
- 去掉金色过圈，改为寻找草甸中的流动风带。上下牵线带动有惯性的纸鸢，在风中稳定2.6秒借到一阵风；离开后当前蓄风衰减。三阵风的高度不同，需重新调整；完成才发原手绘标签。保持旧手帐与标签图像版本。
- 牵线弧度、两条飘带、纸鸢倾斜、细小风中草籽独立运动；进入风带有风声与柔和气声音符，事件有节流。减少动态效果时保留必要操控，停止装饰摆动。
- 专属面板使用视口约束；目标、阶段与蓄风条在画面内显示。声音与重试按钮放到下方，压缩上部空白，保留44px按钮操作高度。宽度同时受可用高度限制，避免只压缩画面高度导致坐标变形。
- 图像异步加载与此前限并发队列共用；素材未就绪或 GPU 不可用时保留燕形矢量回退，退出时释放独立纹理。

- npm test：26个测试文件通过，0失败。新增5项定向检查，更新2项受玩法规则影响的旧小游戏检查。
- npm run check 与 git diff --check 通过。
