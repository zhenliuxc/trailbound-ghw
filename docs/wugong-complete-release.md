## 四段已实现的玩法

| 标签及原 ID | 完成条件 | 操作与反馈 |
| --- | --- | --- |
| 草浪来信 `meadow-bird` | 顺风起飞，穿过山脊侧风，再放线进入云海，完成一整段航程 | 拖动／方向键牵线；沿途风带、侧风、航程与声音变化。脱风只回退局部进度，飞过的山段保留；不再累计三次停稳 |
| 云海开信 `meadow-butterfly` | 从来风口规划一条通往远谷的有效风路，再主动送风 | 点选／连线／键盘规划；高脊阻挡、洼地回流和未到出口分别反馈，可撤回或重画 |
| 吊带追风 `wugong-wind-hiker` | 招呼、帮拍、构图与快门、给她看照片、回应及告别 | 拖动取景、远近按钮与独立快门；照片冻结当次构图与姿态，可重拍。使用原水彩人物，未调用设备摄像头 |
| 金顶石语 `meadow-flower` | 六片画片的位置与方向全部正确，拼回完整石坛水彩 | 拖放或选片后点目标格；左右旋转、底稿开关与键盘操作。使用现有高分辨率石坛画，保留原奖励标签 |

沿用精细水彩、纸色和原有品牌。纸鸢、草叶网格、云海、人物三姿态及石坛素材均复用已有手绘；本轮没有重画地图或替换收藏图。完成后仍经过手绘纪念、收进手帐及继续行进；未完成退出不发奖，重玩保留首次记忆，不恢复导入、导出或清空。

`dist/kite-flight.js` 负责连续飞行规则，`wind-scene.js` 用同一状态绘制风带、纸鸢、牵线与声音线索；云海和摄影沿用 `wugong-stories.js`，拼图沿用 `art-games.js`。更新路线介绍，使其对应当前四种操作。四段均纳入资源等待、失败提示与重试；退出后忽略迟到资源，后台暂停不会推进互动。

声音复用已有且有许可记录的叶声、拟音和原创合成音色。补充连续飞行的山段声音，继续使用图集拼片锁合、风路、摄影快门、告别、完成与收藏反馈；本轮没有下载新录音，不把拟音称为真实相机、纸张或当地实录。
