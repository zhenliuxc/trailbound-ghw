# 武功山 · 林间、营地与山脊行走

2026-10-17。最初范围是「林间上坡 → 草甸转弯 → 营地坐下」，采用武功山景区导览图的斜俯视山体全景方向。用户随后要求默认随行、可打开全图，纯图标、到达自动展示真实照片及介绍，拉长后半段并授权完整行走测试。当前可走范围为东江村 → 绝望坡 → 观音宕 → 吊马桩 → 金顶 → 景区大门，其他路线不动。最新一轮将视角切换移到地图右上角，并复用现有绘制继续细化草甸，见 [地图视角与草甸细节](wugong-meadow-controls.md)。此前动作与时间天气的实现和验证见 [动作与时间天气](wugong-motion-weather.md)，full-route-8 的结果见 [完整行走验证记录](wugong-full-route-check.md)，不代替新版证据。

## 实现

- `src/wugong-walk/model.ts`：数值高程边界解析、统一地形投影、曲线路程、地面接触查询，以及到站落稳、营地卸包、坐下、喝水和第二天出发的状态。
- `src/wugong-walk/gait.ts`：锁定地形落脚点、左右脚轮流摆动、坡度与弯道缩步、停止时落脚、承重转移和连续转身。
- `src/wugong-walk/environment.ts`：两天一夜的游戏内时钟、平滑天气、风、晨昏和星夜，以及独立景象选项。读照片或切后台时暂停，不访问实时天气。
- `src/wugong-walk/renderer.ts`：组合程序背景、人物、营地与草木遮挡，按显示密度生成近景物件并剔除离屏物件。人物、道路、物件和点击共用当帧投影。
- `src/wugong-walk/camera.ts`：默认随行、可切换全图，首帧定位到人物，跟随稳定路程位置，返回同一帧的只读正反投影及地标可见性。
- `src/wugong-walk/backdrop.ts`：一次编译的数值地形索引，常驻全图与超扫近景窗口，串行生成、缓存上限、取消与渐进回退；镜头每帧复用背景，越过覆盖余量时才补绘近景。
- `src/wugong-walk/vegetation.ts`：植被覆盖、林线、树冠与草甸笔触。与地形共用高程、坡度和光照，远处林冠与地形按纵深合成并缓存；路边树和草叶单独参与人物遮挡。
- `src/wugong-walk/character.ts`：程序关节人物，腿部解算、脚底固定、身体前倾、转身、背包惯性和一致风向的围巾。坐下时弯曲关节并下移重心，不压扁人物。
- `src/wugong-walk/main.ts`：鼠标/触屏点击路面、起点和营地；出发/停步/继续/重走；空格与方向键；声音主动开启；后台暂停及离开清理。
- `src/wugong-walk/terrain-paint.ts`：根据顶点亮度场绘制连续明暗渐变；不再为每个地形三角形只填一个平均颜色。
- `src/wugong-walk/visits.ts`：六站实景与介绍、署名及许可、原生模态卡片、预加载和失败重试。阅读不会发奖或写入手帐。
- `dist/wugong-walk.css`：独立样段样式，桌面与手机布局、统一纯图标、景点卡片；不增加当前位置标签。
- `scripts/build-runtime.mjs`：单独打包 `dist/wugong-walk.js`，其他路线不下载这段代码或地形数据。

本段复用已在项目中署名的 Scott Buckley《Reverie》免费 CC BY 4.0 配乐，以及 Kenney CC0 脚步与布料录音，音量按样段调整，默认关闭，切后台不补播旧脚步。没有下载或购买新音频，未称为当地实录。

## 本轮植被调整

用户指出独立添加的树木不协调，同意先用连续地表覆盖表现森林、草甸和林线，保留少量路边近景细节。该意见是本轮实现方向，调整后的实际效果尚未验收。

- 移除遍布地图及沿路排布的大树图形，低海拔森林改为地形底色与密度变化的细小树冠相连。树冠随山坡光照变色，与山体按纵深交错绘制；不使用统一描边。
- 林线由高度、坡度及连续变化的斑块共同决定，逐渐过渡为疏林、裸岩和草甸；高处保持开阔。草甸底色加入受光的浅绿、克制的草金与沿地形投影的短笔触。
- 路边仅保留七棵有树干和分枝的近景树，用不同形状的多组树冠表现；移动端限制树木额外放大，保留人物经过时的前后遮挡。
- 路边草叶与远处少量细草共享风向及传播节奏，路边草叶在人物靠近并移动时弯曲，根部位置固定；减少动态效果时取消环境风动。营地座位周围留出空地。
- 默认全图、统一地点图标、人物步态、营地动作与已有交互入口保留；未改其他路线，未加入新素材或网络请求。

- 地形显示网格从 241 × 281 改为 481 × 561。近景按目标最高 6.4 像素/场景单位重新绘制，整幅地图等效最高 7680 × 5504 像素；这是可按视野生成的目标密度，不是预先下载的整幅 8K 图片，实际缓存密度受设备预算限制。
- 缓存覆盖完整地图和宽高比外延；随行只保留一个近景和最多一个正在生成的新窗口，新窗口完成前继续使用已有背景。天空、远山和植被随机种子固定在世界坐标，窗口更新不重新排布。
- 人物保持关节程序绘制，树木、石头、帐篷按当前显示密度生成。视角切换不重置路程、营地动作或声音；镜头不读取身体起伏或脚点摆动。
- 地点图标仍为统一 CSS 尺寸。每帧按同一投影更新，画面外图标连同键盘焦点入口隐藏；点击由最近实际绘制帧反算坐标。
- 主画布扩大，手机视角控制单独排列；新增缓存生成提示及可继续行走的清晰度回退。页面隐藏暂停构建，销毁后拒绝旧任务写回。
- 设计比较、模块边界、缓存分配与静态修正记录在 `docs/wugong-camera-design.md`。没有测试授权，未运行自动测试、浏览器、手机、性能或音频验收。
