# 旅行手帐标签墙 · 已完成定向验证

用户最新要求移除“清空这份旧手帐”功能，旅行手帐排列成标签墙，点击打开详情。本说明取代版本 34 关于直接展开纸页及确认清空功能的设计说明。

## 本轮改动

- 移除旧手帐清理入口、确认事件、提示和底层 resetHistory／historyState 逻辑。读取手帐不进行写入、清空或迁移；原有存储键继续使用，已有记录保留。
- 标签墙统一图画、标题和路线位置；宽屏五列、中等屏幕四列、手机两列。保留去重、路线筛选与追加分页。
- 点击标签打开原生 dialog：大图、标题、地点、完整回忆、时间、天气及折叠的山野知识。右上角固定 44px 关闭按钮，支持 Escape、原生焦点约束，关闭后返回对应标签。
- 阅读详情时暂停行进和小游戏时钟、声音；关闭后按之前的行进状态恢复，后台切换后保持暂停。尊重减少动态效果。
- 不恢复导入、导出或独立图鉴。完成互动才保存、不重复新增的规则保留。
- 旧的无图文字记录仍可阅读，不伪造奖励图。已清除的历史不会恢复。

## 验证与发布准备

用户回复“对”，授权本轮集中测试后更新原站点。定向验证已通过：

- `journal-tools`、`journal`、`presentation`：标签打开详情、关闭事件及焦点返回、分页和路线筛选、重玩去重、读取不改写旧存储、无清空 API／入口、阅读暂停行进与小游戏、后台切换保持暂停、未完成互动不记录。
- `expansion`、`landscape-tags`、`nature`、`feedback-rain-fixes` 中与本轮相关的兼容断言：历史标题与图画保留、完整回忆和地点说明在详情中可读、缺图降级可读。
- `dist/app.js`、`dist/discoveries.js` 语法检查，静态素材引用检查及差异空白检查通过。未运行全套测试。

DOM 测试模拟 dialog 打开／关闭事件，不代表真实浏览器的 Escape 默认行为、焦点约束或布局验收。手机与电脑实际排列、长文字滚动、触控、音频暂停／恢复听感仍待实际设备验收。

将使用本次已验证源码更新原私有站点，保持项目与访问范围不变。发布结果以 Sites 的终态和版本号为准。
