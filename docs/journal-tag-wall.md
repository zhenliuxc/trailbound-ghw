# 旅行手帐标签墙 · 待测试

用户最新要求移除“清空这份旧手帐”功能，旅行手帐排列成标签墙，点击打开详情。本说明取代版本 34 关于直接展开纸页及确认清空功能的设计说明。

## 本轮改动

- 移除旧手帐清理入口、确认事件、提示和底层 resetHistory／historyState 逻辑。读取手帐不进行写入、清空或迁移；原有存储键继续使用，已有记录保留。
- 标签墙统一图画、标题和路线位置；宽屏五列、中等屏幕四列、手机两列。保留去重、路线筛选与追加分页。
- 点击标签打开原生 dialog：大图、标题、地点、完整回忆、时间、天气及折叠的山野知识。右上角固定 44px 关闭按钮，支持 Escape、原生焦点约束，关闭后返回对应标签。
- 阅读详情时暂停行进和小游戏时钟、声音；关闭后按之前的行进状态恢复，后台切换后保持暂停。尊重减少动态效果。
- 不恢复导入、导出或独立图鉴。完成互动才保存、不重复新增的规则保留。
- 旧的无图文字记录仍可阅读，不伪造奖励图。已清除的历史不会恢复。

本轮未运行测试、未发布；用户此前的测试授权针对上一轮，本轮等待确认。

获准后重点覆盖：清空入口／删除逻辑不存在、读取不改写存储、点击详情、关闭焦点、Escape、背景暂停、分页、手机标签对齐。旧测试中的直接图文展示和清空功能断言需要更新；原生 dialog 的真实浏览器体验仍需可用浏览器或用户验收。
