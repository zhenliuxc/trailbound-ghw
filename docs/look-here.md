# 你看这里

“你看这里”在九溪龙井的溪林停步处与茶坡转角提供折纸路笺。当前实现只在本机保存游戏风景取景和配文，公开路笺后端未接入。

## 当前体验

- 跟随视角中，玩家在指定路段累计 12 秒有效探索后可看见纸笺。暂停、照片、小游戏、失焦和后台不累计探索时间；全图隐藏纸笺入口。
- 每个地点有一张固定的“山径创作路笺”，画面来自当前 2D 场景取景。它是创作示例，不是真实玩家投稿或地点实拍。隐藏后不补下一张。
- 玩家可选择三个取景锚点，在 1.0 至 1.3 倍范围缩放，捕获 4:3 的地图风景。取景排除人物层，保留画面自身的地景。
- 新稿配文为空，支持纯照片、自行输入文字和主动采用推荐句。已有文字采用推荐前需要确认替换。字数按可见字素计数，80 字为建议值，不限制超出后的本机保存。
- 每份新稿默认匿名，也可选择词库中的笔名。署名随记录保存，不随以后偏好变化。
- 离开未保存编辑时可保存、放弃或继续编辑。保存失败保留编辑内容并提示重试；只有存储成功才显示已保存。
- 私藏照片显示在现有旅行手帐中，与圆形游戏徽章各有记录类型，不把照片当作游戏通关奖励。
- 独行设置和隐藏示例只影响本机。打开纸页暂停旅程，关闭后恢复原状态与焦点。

入口纸面为 `112 × 40 px`，点击范围为 `112 × 44 px`；设置按钮纸面为 `36 × 36 px`，命中范围为 `44 × 44 px`。触屏控件保留至少 44 px 的可操作范围，正文、取景和编辑根据可用空间排布。

## 模块与数据

| 职责 | 维护位置 |
| --- | --- |
| 两个地点、探索区间、取景锚点、推荐句 | `src/content/look-here.ts` |
| 有效到访与入口状态 | `src/journey/look-here/model.ts`、`controller.ts` |
| 草稿、取景、配文、署名与离开确认 | `src/journey/look-here/editor.ts` |
| 用例编排、异步失效、保存状态 | `src/journey/look-here/application.ts` |
| 纸页、设置、相册与动画 | `src/journey/look-here/view.ts`、`paper.ts` |
| 本机依赖接入与偏好 | `src/journey/look-here/local.ts`、`preferences.ts` |
| 私藏照片类型与持久化 | `src/runtime/private-photo.ts`、`private-photo-store.ts` |
| 统一存储出口与手帐墙 | `src/runtime/journal-store.ts`、`journal-controller.ts` |

照片使用 IndexedDB `trailbound-private-photos-v1` 的 `photos` 仓库，记录类型为 `private-local`。游戏徽章继续使用原手帐存储，两者不互相覆盖。记录保存照片内容、地点身份、创建时间、场景版本、取景参数、文字与署名。场景更新不自动重拍或改写已有私藏。

地图只向应用层提供画面捕获与旅程状态；界面不直接操作数据库。异步捕获与读取受会话代数约束，关闭、切换或销毁后的回调不能更新新纸页。保存期间防止重复提交，退出释放监听、动画和存储连接。

## 实现边界

当前没有相机或本机真实照片上传入口，没有账号、远端媒体存储、跨玩家内容池、公开发布、撤回、举报或人工审核流程。本地匿名、隐藏和到访秒数不构成服务端身份、访问资格或发布能力。

产品方向允许用真实照片连接现实足迹与游戏地点，并让路过的玩家看到公开路笺；这部分未接入当前工程。后续接入仍须将游戏取景、真实照片、私藏和公开记录区分，保留现有存档。人工审核链路不在当前范围。
