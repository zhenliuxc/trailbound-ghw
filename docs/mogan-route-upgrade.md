## 三段玩法

| 画作与原 ID | 当前实现 | 操作与完成 |
| --- | --- | --- |
| 竹涛一阵 `bamboo-drop` | 叶尖蓄水、落滴、移动竹筒、筒内水面和水花；八个接中的声音组成有停顿的短句 | 指尖移动或左右按钮／方向键；只有雨滴真正越过可见筒口时才计入。漏滴落回石阶，同一音符重新出现；不扣已接进度 |
| 古道留痕 `bamboo-step` | 新的十级石阶互动：远近不同的水彩石阶、左右鞋履、收拢的脚印提示、落脚反馈和前行过渡 | 左右脚交替，在宽容的提示窗口落脚；手机两块操作区及按钮，电脑 A/D 或左右方向键。错脚、太早、错过均不增进度；错过在原级再来。提供更慢的节奏 |
| 林隙远山 `bamboo-leaf` | 保留已有弹道与连续碰撞规则，重新接入统一水彩竹林舞台，加入竹叶网格运动、弓弦回弹、纸叶飞行/回落、命中收束和录音反馈 | 拉弓松开发射；方向键/空格蓄力，或展开默认收起的角度与力度控件。真实碰到纸签才完成，碰竹回弹、越界后可再试，不按发射次数发奖 |

三段都遵循进入、实际操作、完成收束、手绘画作展开、收进手帐和继续行进的流程。仍使用原三幅纪念画、原 ID 和现有去重/保存规则；不会新增重复标签，不恢复导入、导出或清空，不自动删除历史记录。旧手帐已有文字和日期保持不变，新记录采用与新玩法一致的文字。

## 美术与两端界面

- 沿用莫干山宽幅水彩背景、清理后的竹筒、既有竹弓/纸叶/竹干/纸签；保持竹林、雨后石阶、暖季绿色植被和合适的徒步鞋履。
- 新补一张 1024×1024 透明水彩图集：苔色花岗岩阶面、左鞋、右鞋和竹叶枝，共 **266,450 bytes**。不使用粗几何块替代主美术。主物件保持刚性，透视仅等比缩放。
- 原始 ImageGen 图保存在本环境的 `/workspace/generated_images/exec-40d790dd-b14c-409e-bbfb-9be9db535281.png`。只裁切、等比缩放和编码，保留原 alpha；打包时避开上方鞋跟的邻格残片。真实叶尖坐标与帧边界写进清单，落滴从同一点发出。首次图稿也保留，未删除生成原图。
- 清单：[mogan-props-v1.json](../dist/sprites/mogan-props-v1.json)；打包：[package-mogan-assets.py](../scripts/package-mogan-assets.py)。生成的 TypeScript 坐标在 `src/runtime/mogan/assets.ts`；实际浏览器检查范围另记。
- 电脑采用宽画面，手机采用方形操作区；短横屏使用画面和控件并列。操作按钮位于画面外，触控至少 44px。弹弓微调默认收起，减少大面板；接雨和石阶有按钮替代精细拖动。
- 游戏读取进入时的路线虚拟天气：雾气、雨丝与晴景对应当前状态；晴天接雨只保留叶尖的滴水。减少动态效果关闭装饰雨丝、网格摆动和飞行尾迹等，仍保留必要的游戏状态提示。

## 实现边界与加载

- `src/runtime/mogan/rules.ts`：接雨与石阶的严格 TypeScript 规则、状态、事件和键盘；弹弓复用现有 `art-games.js` 的规则。
- `scene-model.ts`：由同一游戏状态计算物件、碰撞相关原点、遮罩、提示与完成画面。水面和水花跟随筒口，落滴越过筒口后不补算接中。
- `scene.ts`：PixiJS 纹理/节点、叶片网格、图像 SVG 降级、尺寸变化和资源释放；控件与公共流程在 `adapter.ts`。
- `createMoganGames` 通过现有 `registerGame` 注册三幅画；为适配器补充坐标、按键、控件与天气接口。主程序只组装，不在主循环添加三套分发代码。
- 提前取当前路线的图集与背景，复用图片解码结果；GPU 节点、精灵和裁切纹理按场景保留，不在每帧重新创建。按显示尺寸和设备像素比选择画布分辨率，避免窄屏也固定分配 1600px 宽画布。浏览器首轮发现发行包没有可选 Prepare 扩展，已补充通过 WebGL 纹理系统绑定上传的路径，保留扩展存在时的上传方式。尚无真机性能结论。
- 必需图片未准备好或失败时不推进规则、不接受盲操作；可以重试或继续走。GPU 初始化失败使用同一水彩图和规则的 SVG 降级。退出后忽略迟到加载并释放纹理、画布和 ResizeObserver；保留统一后台暂停和手帐/奖励生命周期。
