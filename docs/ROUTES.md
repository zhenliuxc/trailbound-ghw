# 路线、季节与小游戏

本文件描述七条主线当前的旅程内容。页面入口、名称与事件目录由 `src/content/catalog.ts` 提供；地点顺序、示意坐标和触发位置在各路线内容模块中维护，文档不另复制坐标和事件 ID。

游戏时钟与天气用于叙事，不是现实天气预报、实测徒步耗时或通行建议。地图保留主要地点、地形和先后关系，允许为构图调整距离与比例。

## 共用体验

全国地图选点后展开手绘封面，点击出发进入 2D 示意地图。默认跟随可选的 Q 版旅人，用户可以主动切到全图。地图显示地点图标与中文名称，照片与小游戏分别触发。

每次互动先以声音、景物或人物动作提示发现，再进入手绘画面。完成后展示本关独立的圆形徽章，保存成功后自动淡回山路。跳过、未完成、只观看以及普通抵达不发小游戏徽章。重玩沿用既有事件身份，不重复新增收藏。

## 武功山

- 地域：江西 · 萍乡。
- 季节：夏季绿色草甸，未指定具体月份。
- 行程：东江村反穿，两天一夜。第一天经过林间爬升、绝望坡和高山草甸，在观音宕／星空营地过夜；第二天经吊马桩、金顶、福星谷、中庵方向，下至景区大门。
- 景色与天气：林带逐渐让位于草甸和山脊；云影、雾、雨、暮色、营灯与清晨随旅程状态变化。星空互动要求夜空可见。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 东江村上山林间 | 林间的叶影 | 翻开纸叶，找出四对相同叶形 |
| 开阔草甸 | 借一阵草甸的风 | 操控纸鸢随风飞行 |
| 观音宕营地入夜 | 星夜入帐 | 对照手帐星图连星，完成后衔接入睡与清晨 |
| 次日吊马桩山脊 | 山脊上的云 | 拨开近处云雾，看见后面的山 |
| 金顶古祭坛 | 古祭坛边的石语 | 拼合古祭坛与山色的小画 |
| 福星谷下山林间 | 把来路排进手帐 | 按旅程顺序排列四幅小画 |

营地旅人拍照保留在事件档案中，不属于当前主路自动触发的六关。阴雨天气未开启星夜时不补发星夜徽章。

## 虎跳峡

- 地域：云南 · 迪庆。
- 季节：暖季峡谷，保留远峰积雪；未限定具体月份。
- 行程：桥头、纳西雅阁、二十八道拐、茶马客栈、中途客栈。客栈过夜后经龙洞瀑布至中峡客栈。中虎跳江边是可选支线，沿张老师小路下行后原路回到中峡客栈。
- 景色与天气：高路、峡谷岩壁、谷底金沙江的高差清楚；白天晴风、暮色窗灯和清晨续程相接。下降时江声渐近，上返时渐远。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 二十八道拐 | 山弯初见 | 沿引导补画 S 弯，随后观看旅人上山与金沙江激流 |
| 中途客栈暮色 | 半山灯火 | 翻出两对山影与窗灯小画，完成后继续过夜 |
| 龙洞瀑布后的歇脚处 | 崖间飞瀑 | 给岩壁与草木的两处留白涂色，保留笔触和配色 |
| 可选中虎跳江边支线 | 江声入峡 | 调整圆形取景，让江中巨石与白浪同时入画 |

主路和支线分别有完整结束关系。不走江边支线时，旅程在中峡客栈结束，也不显示缺失收藏墙。

## 鳌太线虚拟章节

- 地域：陕西 · 秦岭。
- 季节：冬季。
- 定位：历史地理关系的虚拟徒步，游戏中的动物行为和过夜安排属于玩法编排。
- 行程：塘口进入，沿鳌山、飞机梁、金字塔、太白梁、大爷海至拔仙台。登顶后回到大爷海，经文公庙、板寺方向下降，末段以汤峪方向接驳结束。
- 章节：五程四夜，宿营依次设在盆景园、水窝子、2800 营地、大石河。下板寺至汤峪方向不画成连续徒步山路。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 白起庙后的鳌山石海 | 石海纹理 | 轻推雪球，沿石槽滚入雪窝 |
| 飞机梁至连峰 | 秦岭长脊 | 按住前进，风强时在岩后停步，风缓再走 |
| 2800 营地后的林缘 | 冬林初遇 | 退入近侧平台，腾出主路，等大小两头羚牛通过 |
| 大石河营地 | 雪夜营灯 | 把两根帐绳系到地钉，再点亮营灯 |

覆雪森林、裸露石海、风口和河谷分别表现风雪强弱与遮蔽关系。最后一关位于大石河，随后以登高回望和出山收束。羚牛的等待、通行和提示动作是虚构规则，不作为现实近距离避让教程。

## 麦理浩径第二段

- 地域：香港 · 西贡。
- 季节：暖季绿色海岸，未限定具体月份。
- 行程：浪茄、西湾山、西湾、咸田湾、大浪坳、赤径、北潭凹，一日海岸旅程。
- 剧情时钟：09:00 至 15:30。
- 景色与天气：上午清亮海面、山肩云影和午后暖光；外海沙岸逐渐转为林缘与赤径内湾，不安排过夜。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 西湾山山肩 | 转角见海 | 点击可见山路，旅人连续登高、转过山肩，站立望海 |
| 西湾沙滩 | 横着也能到 | 挪开挡住沙路的漂木，让小螃蟹走过 |
| 咸田湾沙滩 | 潮汐收笔 | 在湿沙上画一笔，松手后等待海浪带走笔迹 |
| 大浪坳上坡林缘 | 林间回声 | 听两段鸟鸣，按顺序点击回应；静音有同步视觉提示 |
| 赤径渡头 | 赤径慢潮 | 拖船靠泊，再将绳圈套上系桩 |

西湾山的体验重点是登高后视野打开，不需要逐级点击台阶或卸包坐下。外海的浪声、林间鸟声与内湾缓水声随地点切换。

## 四姑娘山长坪沟

- 地域：四川 · 阿坝。
- 季节：十月彩林。
- 行程：喇嘛寺、原始森林、枯树滩、溪谷、下干海子、上干海子、红石阵、木骡子，原路返回喇嘛寺。
- 剧情时钟：08:30 至 16:30，一日山谷徒步。
- 天气：晨雾彩林、薄云渐开、午间草甸山风、返程午后暖光。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 去程枯树滩 | 枯枝认影 | 看纸上枝桠，点出水中相同的倒影 |
| 干海子马道休息处 | 马铃解绳 | 先拉开上面的绳头，再解开下面的一圈 |
| 木骡子林缘 | 画里有条路 | 上下移动近处纸片，把两段小径接通 |
| 返程彩林栈道 | 叶脉留秋 | 在纸面轻擦，拓出落叶的叶脉 |

去程三关、返程一关。返程通过观看方向、光色和叶脉互动表现同一山谷的另一面，不重复去程照片和小游戏。

## 莫干山竹林步道

- 地域：浙江 · 德清。
- 季节：湿润绿竹林，未限定具体月份。
- 行程：莫干岭西坡、竹林、古道石阶、莫干岭口、林间步道、山涧、大坑侧山林，半日古道选段。
- 剧情时钟：09:00 至 12:00。
- 天气：细雨、雨歇薄雾、林隙微光。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 莫干岭竹林 | 接一小段竹雨 | 移动竹筒，接住四滴叶尖雨滴 |
| 莫干岭古道 | 拂开落叶，沿古道上山 | 扫开石阶落叶，再看旅人走过山弯 |
| 大坑侧山林 | 借一阵风，送出叶笺 | 观察竹梢，等风朝向远山时点击送出叶笺 |

竹竿、竹节、叶丛、石阶湿痕与坡面层次承担主要辨识。照片中的莫干山木制步道不冒充莫干岭石阶。

## 九溪龙井

- 地域：浙江 · 杭州。
- 季节：春日新芽，未限定具体月份。
- 行程：九溪烟树、九溪溪谷、九溪十八涧、龙井茶园、龙井村，半日溪谷与茶园旅程。
- 剧情时钟：09:00 至 11:30。
- 天气：溪谷薄雾、树隙晴光、午前茶园微风。

| 路段 | 小游戏 | 主要操作 |
| --- | --- | --- |
| 九溪溪谷 | 推一圈水纹，送落叶过溪 | 点击落叶后方水面，以水纹推叶绕过溪石 |
| 十八涧石径 | 踏石听溪 | 依次点击前方相连的三块溪石，旅人踏石过水 |
| 龙井茶园 | 一芽两叶，留一页春天 | 辨认并点选一枚嫩芽和两片嫩叶 |
| 龙井村口 | 慢慢注水，等一盏茶 | 按住注水，水面过半后松手，观看茶叶舒展 |

溪流绕石、林间转角和茶垄随坡面展开。溪林与茶坡还接入本地“你看这里”纸笺，规则见 [你看这里](look-here.md)，它不占用小游戏奖励身份。
