# 七条绘本旅程的完整玩法

最新版本改为每地图三种不同玩法，详见 [DISTINCT_PLAY.md](DISTINCT_PLAY.md)，全部160项测试通过；当前候选仍未部署。

本候选把精细 SVG 绘制与遇见玩法接到现有七条路线。已完成代码和自动回归，尚未部署到原私有站点。

## 旅程

选择路线并出发，小人沿真实参考走向自动行走。途中仍有原来的情境选择和三张真实地点照片。玩家主动打开路边的小景物时，小人与旅程时间暂停，近景插画接过画面。轻触、拖动或静静观看后，瞬间作为独立徽章收进手帐，恢复原来的行走或暂停状态。

| 路线 | 近景内容 | 动作 |
| --- | --- | --- |
| 武功山 | 小鸟、山脊云影、草坡阳光 | 跟随视线、划动风与云 |
| 虎跳峡 | 远处山羊、飞鸟、江面水光 | 安静观察、移开视线、点水纹 |
| 鳌太线 | 薄雪脚印、岩石苔色、云缝阳光 | 沿纹理查看、划动云影 |
| 麦理浩径第二段 | 潮痕、沙上贝壳、渡头倒影 | 点潮光、沿贝壳纹理轻划 |
| 长坪沟 | 苔木、木桥水声、山的倒影 | 查看苔色、点水纹 |
| 莫干山 | 竹叶雨滴、石阶纹理、落叶与风 | 看雨滴落下、沿纹理轻划、移开叶影 |
| 西湖九溪龙井 | 水绕石头、浮叶、茶树新叶、叶影、屋檐与竹篮 | 点水、划水、触叶、听滴水 |

24 种既有徽章都对应可参与的瞬间。每趟仍最多收下三个；九溪从六个候选中按溪谷、茶园、村口顺序各抽一个，并降低最近记录的权重。其余六条按原地点次序出现，不宣称每次重新随机选题。

## 连续拖动与回忆

- 拖动过程中实时更新视线、云影、水纹或纹理揭示；贝壳纹理、脚印与苔色通过 SVG 遮罩逐步显现。
- 笔迹保留起终点并抽稀，最多 24 个采样点；长按/长拖最多停留约 10 秒。轻触后约 3.4 秒收下，安静观看约 6 秒收下，未动作提前继续则跳过。
- 点击、拖动与静静观看保留不同的记忆文字，全部与路线地点关联。声音关闭也可正常参与。
- 旅程结束后，只展示这次实际收下的徽章。点击一枚可读对应回忆，再点可收起；重走清空本次收藏但保留全局手帐。错过景物或全部跳过仍能完成旅程。
- 切换路线、切后台、页面缓存、指针取消、按 Escape 和结束场景都会清理拖动状态及指针捕获，恢复适当的暂停状态。微互动与行走共用同一个动画调度入口，没有额外常驻计时器。

## 美术和声音

七条地图共用精细矢量绘制风格，各自保留草甸、江谷、秦岭岩脊、海湾、针叶林、竹林与茶园特征。树林、竹叶、溪石、草花、人物衣物与背包得到细化。SVG 与 PixiJS Graphics 使用相同景物描述，真实轨迹、水系源坐标、照片、打卡位置与旧手帐数据没有替换。

静态背景限制在每条路线 2000 个基础图形以内，莫干山竹林约 1658 个；图形在切图时构建。该数量约束和既有画布像素预算用于控制成本，不能证明手机的实际帧率、耗电或 GPU 表现。

九溪沿用上一版有许可的录音层与离线合成回退；其余六条使用对应风、雪、江水、潮水、叶声或简短鸟音等原创合成反馈。新增动作音只在用户开启声音时发出，有短时节流，并随静音、后台与换场景清理。没有新增音频下载，也没有把通用录音称为任何地点的实地录音。
