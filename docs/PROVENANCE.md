# 素材来源与许可

工程中的程序示意图、生成手绘、第三方实拍、录音和用户私藏具有不同来源。它们在界面与素材清单中分别标识。素材来源记录是当前分发依据，不能作为历史变更文档清除。

## 来源索引

| 内容 | 依据与维护位置 |
| --- | --- |
| 地点实拍 | [照片说明](PHOTO_CREDITS.md)、`public/photos/*credits.json`、各路线照片源码表 |
| 配乐与环境声 | [声音说明](MUSIC.md)、`public/audio/*credits*.json`、音频素材目录中的许可文件 |
| 场景与徽章生成图 | `public/scenes/manifest.json`、`public/badges/manifest.json`、场景子目录的 `credits.json` |
| 角色素材 | `public/characters/traveler-choices-v1-credits.json`、角色目录内许可与 `art/characters/` 制作源 |
| 精灵制作 | `public/sprites/manifest.json` |
| 生成提示词与母版依据 | `art/` 各主题目录，以及 `art/provenance/` 保存的来源清单与提示词 |
| 全国地图数据 | `assets/maps/sources.json` 与同目录地理数据 |
| 第三方代码 | `public/vendor/`、相关素材目录、构建分发的 LICENSE 文件与依赖包许可 |

生成图片用于水彩画境与游戏纪念，不是地点摄影或物种观察证据。参考作品提供设计启发，不能复制其代码、画面和角色后标称原创。程序示意地图也不代表实地测绘或当前通行信息。

## 维护要求

- 第三方素材记录作者、原始来源、明确许可、分发路径与修改方式。免费使用、可随站点分发和可剪辑分别核实。
- 生成素材保留提示词、母版或生成来源、处理脚本、分发文件及必要的裁切信息。素材版本用于缓存和来源识别，不作为开发进度。
- 许可原文与作者署名随实际使用的素材保留。替换文件时同步更新引用和清单，已有收藏仍依赖的画作不自动移除。
- 本机私藏由玩家操作生成并保存在浏览器，不上传到服务器。当前边界见 [你看这里](look-here.md)。
- 保留源码与素材的真实来源，不把构建结果、模拟对象或助手执行记录称为人工实作、实地采录或真实用户投稿。

制作过程截图、构建日志和发布流水账不作为长期文档保留；当前素材的来源和授权明细仍与素材一起维护。
