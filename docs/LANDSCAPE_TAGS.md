## 获得与保存

- 完成相应互动后，手帐显示该标签的中文名字与独立SVG图案；相同标签重复获得会保留每趟回忆，但收藏种类只计算一次。
- 静静看云海等需要“停留”的互动也能完成。未完成尝试和单纯观看仍能留普通文字回忆，显示“一段沿途回忆”，不授予标签；未操作提前继续可直接跳过。
- 拍照点、打开真实照片、单纯经过地点不会发标签。结束页只展示本趟实际获得的标签。
- 保留原24个内部ID与浏览器存储key、version:2。新记录使用edition:3、earned和tag字段；旧记录保留原标题、地点、正文及旧图集，避免同ID换景物后把“山羊”回忆改成“峡谷”。
- `route-moments.js` 为景物、标签、提示、完成文案和资料链接的单一数据源；`route-scenes.js` 为专属近景与标签共用的原生矢量景物。当前来源说明在新手帐的“这片山野”中展示，旧记录仍使用原资料。
- 云海、山雾、春芽、晴日透光都在近景中注明是相应的虚拟片刻。秦岭章节明确为虚拟地貌观察，来源说明保留未经批准穿越鳌太线违法的边界，不提供现实穿越指导。

## 图案与验证

`badges/landscape-v3.json` 对应24枚各不相同的原生SVG图案，总体约131KB，无外部图片、脚本、字体或新依赖。标签图案不包含说明文字，中文名称显示在图案外；图集旧资源保留用于历史记录，移除其首屏预加载。

`npm run check` 和全部166项Node测试通过，日志分别为 `landscape-tags-check-output.txt` 与 `landscape-tags-test-output.txt`。新增6项验证标签与景物/图案/来源一一对应、完成才获取、旧记录兼容、普通回忆与标签不同展示、重走不增加种类、静候与品茶区别及照片不发标签。既有七路线完整旅程、后台、键盘、照片、音频和资源许可回归通过。

`previews/landscape-tags-review.png` 为24枚图案总览；配套压缩SVG保留中文名称，PNG使用本地字体可显示的英文索引。`previews/landscape-interactions-review.png` 为七图各三个真实SVG近景。两者均是静态绘制检查，不是浏览器或真实手机截图；实际触屏手感、CSS、帧率与混音听感仍待试玩验证。站内名称为中文，使用设备字体，不需下载额外字体。

复现脚本为 `scripts/render-route-tags.cjs` 和 `scripts/render-landscape-interactions.cjs`，PNG渲染使用已有运行时Sharp，不是站点运行依赖。原图案由imagegen生成；本轮新图案为仓库原生SVG代码，不修改旧位图。
