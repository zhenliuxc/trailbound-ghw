# 行进反馈、绘本互动与徽章弹窗 · 2026-10-15

基于版本27 / GitHub cd89c29。按本轮要求移除手帐导入内容、补足行进选择反馈、提升互动画面，并在完成后弹出对应手绘徽章。

## 用户可见变化

- 手帐导入按钮、文件输入、导入提示及导入逻辑已删除。旧手帐、收藏图鉴与导出保留。
- 点击行进选择后，在地图内立即显示结果卡：刚选的行动、叙事结果，以及步伐放缓/加快、体力恢复、寒意等实际影响。结果持续约10秒行进时间，可手动收起。选择选项上也可提前看见影响，计算已考虑状态上限。
- 新增七条路线各自的横幅水彩场景图，总计2,420,620字节。武功山暖季草甸、虎跳峡江谷、秦岭虚拟风雪、麦理浩绿色海岸、长坪沟绿林雪峰、莫干竹林和九溪春日茶园分别对应地图时节。
- 29个互动使用手绘景物作为主体，柔和融合在对应场景中。玩法保持拨云、风、描线、角度变化、放大观察、水纹、湿沙笔迹、泡茶等；透镜直接放大水彩图细节。互动进度条显示当前进展。素材的徽章边框在互动视图中被柔和遮罩，完成后奖励弹窗展示完整徽章。
- 完成互动后保存一次回忆，再弹出对应的手绘水彩徽章、名称、地点与结果。旅程停止，收好徽章才恢复；从暂停状态进入或后台切换后仍保持暂停。未完成与跳过不会弹出未获得的奖励。
- 奖励弹窗支持键盘焦点限制、Escape收起、窄屏滚动，以及减少动态效果偏好。重复收好不会重复写入回忆。
