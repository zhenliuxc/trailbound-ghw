# 武功山地图视角与草甸细节

2026-10-17。用户要求将“跟随／全图”放在地图右上角，默认跟随，主动点击后才查看全图；草甸沿用现有场景继续细化。仅修改武功山独立行走页及主页面的武功山预览链接，未发布或提交。

## 实现

视角切换从标题栏移入地图右上角，按钮含简短文字和线条图标，触控高度保持 44 像素。初始相机状态与界面均为跟随，进入页面不会恢复此前选择的全图。全图仍由用户点击切换，切换本身不改变行走或暂停状态。

草甸复用现有高程、坡度、林线、光照与固定种子分布，增加坡面的草色层次和成簇的长短草叶，路边加入少量草穗、碎石与裸土。陡处保留岩面，低处保留林冠；坡面纹理减淡，草甸短笔触沿地形等高方向投影。

静态草丛与风动草叶共用同一套绘制函数。八种草形和光照色板预先生成，静态部分进入已有的背景缓存，近路草叶继续共享天气风势和人物经过时的摆动。没有新增贴图、引擎或依赖，也没有改动路线、步态和景点事件。

主要源码为 `src/wugong-walk/vegetation.ts`、`backdrop.ts`、`renderer.ts` 和 `camera.ts`。独立页面样式为 `dist/wugong-walk.css`；`dist/wugong-walk.js` 由正常构建生成。
