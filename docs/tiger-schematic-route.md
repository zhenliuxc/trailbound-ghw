## 山路慢行第三版

用户指出道路呈格子状，要求把二十八道拐重做成更简单的山路体验。源码中的重复横向台阶每隔 15 个场景单位绘制一次，是当前修正针对的来源。本轮移除这组横纹，将道路改成连续细径，只保留疏落且不等距的砂石；不为纹理效果画出一整段梯子。

“张老师的小”对应张老师小路。本轮保留完整单行名称，增加“通往中虎跳”的小字说明。文字接近画面边缘时在地点的另一侧显示，锚点仍随地图，不拉线连接。地点含义参考此前采用的[徒步者现场记录](https://thefabryk.com/blog/tiger-leaping-gorge-hike)中张老师客栈接入江边步道的描述，只作为路线关系依据，不用于声明当前开放状态。

二十八道拐沿用当前 Q 版人物，改为按住画面连续前进、松开原地停下看景，空格与方向键保留为辅助。转弯由路径完成，不再要求持续追踪小人前方的细线，不再因手指离路而卡住。行走速度随坡度和弯度变化，人物按行走距离换帧；足底轨迹按新画面中的小径设置。走到山肩后镜头短暂展开峡谷，停留后进入原有自动入帐与徽章淡出流程。未行走、短按后等待、途中退出不发奖励。

新手绘使用内置 `image_gen` 工具生成。原图为 `art/tiger-climb-v3/scene-source.png`，1478 × 1064；完整提示词为 `art/tiger-climb-v3/prompt.txt`，站点素材为 `dist/scenes/tiger-climb-walk-v3.webp`，生成与处理记录为 `dist/scenes/tiger-climb-walk-v3.json`。画面是艺术化水彩插画，不当作虎跳峡实拍；旧画作和历史手帐保留。图中山径直接作为行走依据，不再额外叠画规则折线，也不再覆盖旧的悬崖贴片。江边取景玩法保持现有机制。

入口为 `http://127.0.0.1:8000/tiger-walk.html?scene=climb-stroll-3`，二十八道拐单段可通过 `tiger-art.html?entry=tiger-28-bends-v1` 打开。`npm run build` 已完成，日志见 `previews/tiger-climb-stroll-3/build.txt`。相关纯规则用例已改为持续按住、松手停步和空格续行，尚未执行。画面贴地、手机裁切、退出与自动入帐均未测试，等待用户确认。

## 地点与行程

高路按桥头、纳西雅阁、二十八道拐、茶马客栈、Halfway、龙洞瀑布、Tina’s 的顺序呈现。Halfway 安排歇脚和过夜，次日出发。Tina’s 是高路终点，玩家可以在此结束，或经过张老师小路入口，下到中虎跳江边，再沿同一条小路返回 Tina’s。支线不是另一条下山环线，也没有混入天梯、一线天或上虎跳景区。

六个照片打卡标记为桥头、二十八道拐、Halfway、龙洞瀑布、Tina’s、中虎跳江边；其中桥头和 Tina’s 承担起终点功能。纳西雅阁、茶马客栈和张老师小路保留为途经关系、场景建筑或路段文字，不再逐一弹出照片。图标统一尺寸，小游戏没有常驻地图按钮。

地理骨架沿用 `tiger-gorge-redesign.md` 与 `tiger-geography-evidence.md` 中已整理的高路和支线关系。新近核对的[迪庆州体育产业发展规划](https://www.diqing.gov.cn/subsiteIndex/bulletin/ex/articleView.html?articleId=205689&fromSubsiteFlagEx=dqzzf_zfbgs&newsClassId=223&orgCode=&subsiteId=16)支持纳西雅阁、二十八道拐、茶马客栈、中途客栈、中峡客栈的先后顺序；其中官方瀑布名称不直接用来给本轮照片定点命名。图上的折返、山壁、江流与支线位置是艺术化示意，不当作精确 GPS 路线或现实通行指引。

## 互动与收藏

沿用虎跳峡已设计的两个重点互动，而非把武功山草甸与星空换皮：

- 二十八道拐：在地图抵达爬升前，短暂发现提示后进入现有手绘行走场景。按住山径引导实际连续爬升，完成后自动留下记忆。主地图随后接回靠近高点的一段路，再抵达观景打卡位置，避免收藏和照片立即连弹。
- 中虎跳江边：真实行进至江边，先看实拍，再走一小段触发手绘取景。拖动构图、按下快门、选定并定格实际拍到的一帧，随后自动保存并淡回返程。不重复播放从高路下降的示意段。

Halfway 歇脚过夜、龙洞瀑布沿崖经过是旅程场景，不因等待或单纯到达发奖。旧的景深排序、背包收纳、八拍声景与循铃岔路仍保留历史源码和收藏，不重新当作新旅程必经内容。

主地图与小游戏改用同一套用户指定的大眼睛 Q 版行走素材，按已量取的足底锚点定位。地图镜头平滑跟随，并保留右上角手动全图切换；地图用山壁、谷地、不同高度的小路和金沙江区分虎跳峡。沿途风、瀑布与江流采用既有免费录音，接近江边提高水声、返回时逐渐降低；默认关闭声音，后台暂停。

手帐统一圆形展示。江边取景保存原始构图，圆形展示保留完整画幅，旧记录不被改写。新奖励复用已完成的自动保存、失败重试、首次记录保留和淡出流程，未完成或跳过不发奖。

## 素材与可重复构建

- `src/tiger-walk/route.ts`、`journey.ts` 负责路线、照片／游戏触发、过夜、分支选择和返回；`scene.ts` 使用现有 PixiJS 8 绘制 2D 山谷与人物；`main.ts` 接入页面和生命周期。
- `scripts/source-tiger-photos.py` 从 Commons 读取许可、准备六张本地实拍并生成 `photos.ts` 与署名清单。第一次请求原始图遭遇限流，改用 Commons 官方预览资源后取得文件；没有用网页缩略图冒充已打包原图。
- 当前桥头和中虎跳江段有地点说明。Halfway 使用高路峡谷风景区域配图，未宣称是客栈建筑实拍；瀑布照片仅确认位于高路，未把它认定为某个具体瀑布；Tina’s 使用中虎跳区域风景配图。原来的 Halfway 半程路标不再充当客栈照片。图片年份、许可与范围在照片及致谢中保留。
- `scripts/build-wugong-art.mjs` 现在按路线参数生成武功山与虎跳峡手绘页，共用小游戏控制器、奖励、手帐和现有页面结构。`npm run build` 编译 `dist/tiger-walk.js`、公共手绘桥接脚本并生成页面。入口为 `dist/tiger-walk.html`，主页面选择虎跳峡后可进入。
- 原有武功山的地图内容不变。为复用流程，对发现转场、手绘弹窗做了参数化，并为虎跳峡取景增加圆形展示；这些共享位置需要在获准后连同武功山做有限回归。
