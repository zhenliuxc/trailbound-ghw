# 九溪地图：茶坡、林间转角与溪流

2026-10-22。用户认可九溪主地图的三项优化方向后实施。本轮只调整九溪程序绘制的 2D 地景，沿用春日的一日溪谷徒步、Q 版角色、现有地点和四段小游戏。

## 已实现

| 项目 | 实现方式 |
| --- | --- |
| 茶坡与茶垄 | 用同一片曲面计算坡面、明暗、等高曲线和茶垄；茶垄在小径、溪水和村落前收边，去掉原来的七块独立弯曲田块 |
| 林间转角 | 在十八涧后、茶园前补充较高的近岸树冠，树群在转角处逐渐疏开，随正常跟随镜头走出林缘，显露连续茶坡 |
| 水流 | 水纹沿现有主溪与支流移动；主溪从茶坡方向流向九溪烟树，支流汇入主溪，浅潭缓流、石块和踏石附近较快 |
| 分层 | 水纹在水面上、石块和踏石下方；地面小径与人物保持可读，地标仍使用原路线上同一坐标 |
| 暂停与清理 | 动态地景由 `DayScene` 传入旅程时钟；照片、小游戏和后台暂停沿用宿主生命周期。减少动态效果时保留静止水纹，无额外动画循环或定时器 |

茶垄和溪水是艺术化的 2D 示意，不表示真实茶田种植边界或水文测量。转角通过树群与道路的空间关系表现，没有新增游戏或确认弹窗。跟随／全图仍使用公共镜头，角色尺寸与平滑度沿用既有设置。

## 源文件

- `src/day-walk/landscape/westlake.ts`：九溪地形组装与图层顺序。
- `src/day-walk/landscape/westlake-tea.ts`：连续茶坡与林缘构图。
- `src/day-walk/landscape/stream-motion.ts`：沿溪流的水纹与浅潭细波。后续莫干山实施时从 `westlake-water.ts` 提取为共用组件，九溪水道与浅潭参数沿用。
- `src/day-walk/landscape/effects.ts`：地景绘制回调；最初仅九溪使用，后续莫干山也接入，长坪沟仍静态绘制。
- `scripts/build-day-pages.mjs`：九溪行进页更新资源版本为 `westlake-map-flow-4`，小游戏素材版本沿用上一轮。
