# 沙滩画笔留痕与清晰度修复

2026-10-21。本地实现、构建和相关验证完成，未提交、未发布。

## 原因与改动

旧版把 384 × 384 的爱心收藏徽章作为主画面放大，图案挤满屏幕。绘画复用短轨迹模型，最多保留 24 个轨迹点，并在停笔后很快擦除，连续分笔作画也缺少独立记录。

主画面改用已有的 1536 × 1024 海滩水彩 `dist/scenes/maclehose-games-v5/beach.webp`。原始文件和生成来源继续见 `art/maclehose-games-v5/`。该画作为艺术化海岸插画，非咸田湾实拍，本轮未新生成图片。小尺寸圆形徽章继续用于收藏。

独立的沙滩画笔控制器保存多笔轨迹，笔迹用 Canvas 2D 绘制沙面凹痕与细高光。抬笔后保留内容，继续画会重置等待时间。停笔 4.5 秒后，潮水从海边漫入，经过的位置擦淡笔迹；退潮结束才获得徽章，随后自动入帐和淡出。

画面与指针共用坐标变换。海水、前景植物和石头不计入作画区域，空点不发奖。重试清掉本局笔迹，取消的笔画不计入完成，关闭游戏不补发奖励。保留键盘画笔、退出和减少动态效果支持。

实现位于 `src/runtime/coast-memories/tide/`，替换旧 `withTideControls` 包装。路线入口缓存版本为 `sand-brush-18`，地图标注样式继续使用 `landmark-align-17`。
