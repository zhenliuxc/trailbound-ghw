# 手帐路线页签

2026-10-22。用户确认将“按路线翻看”的下拉框改成直接点选的手帐页签，选中项为草木绿，旁边显示已收藏数量，手机横向滑动。

## 实现

- 首页与七条路线使用同一份 `journal-wall.html` 和 `journal-route-filter.ts`。首页手帐也改用 `content/catalog.ts` 的 `ROUTE_SUMMARIES`，与旅程手帐的名称保持一致，没有另外维护显示名称。
- 米白纸签对应未选路线，当前路线使用草木绿底、浅色字与左侧纸边。显示“全部路线”和七个路线入口，未收藏路线仍可选择，但不堆放零计数。
- 数量取自现有去重后的手帐视图，旧记录升级不会重复计数。切换路线重置当前展示页数；重玩、保存和完整原画切换沿用原逻辑。
- 桌面按可用宽度排列，窄屏改为单行横向滑动，保留完整路线名。每个页签至少 44 px 高；键盘 Tab 进入原生单选组，方向键切换路线，焦点项在横向滚动区内保持可见。
- 页签节点在刷新收藏墙时保留，避免每次更新重建焦点。事件随手帐控制器释放，读取和筛选不写入玩家收藏。
- 共用样式源仍为 `dist/style.css`；页面与脚本通过现有构建生成并更新缓存版本。

## 状态

实现完成，`npm run build` 通过，已生成首页与七条路线的共用手帐页面。用户随后授权集中检查并打开本地预览。以下检查通过，用户对最终画面体验的认可仍待反馈。未提交或发布。
