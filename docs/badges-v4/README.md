## 素材与预览

- `../../dist/badges/art-v4.json`：23枚素材的名称、路线、季节、相对文件名、尺寸、字节数与SHA-256，明确标注 `runtimeBound: false`。
- `../../dist/badges/*-v4.webp`：384×384透明图片，适合现有96px标签的高像素密度显示；打包只进行等比缩放与WebP编码，不使用SVG替代手绘图片。
- `review.html`：包含全部图片的自包含中文预览，按路线分组、名称置于图片外，可单独放大；窄屏两列。使用设备字体，不请求外部字体或资源。
- `overview.webp`：静态总览，按同一清单排列，数字对应清单顺序。该总览使用本地可用拉丁字体；中文名称在HTML中展示。
- `prompts.json`：本轮16枚图案的共同风格要求与独立生成提示。
- `refinement-red-stone.json`：红石修订提示与选中输出。
- `generated-*.json`：7枚既有选中图与本轮16枚生成图的本地输入记录。原始大图由生成工具交付，项目另保存轻量图片和原图哈希。

使用 `node scripts/package-badge-art-v4.cjs` 可从记录中的本地原图重新打包，生成素材、中文预览、静态总览与 `validation.json`。该脚本只打包既有图片，不生成或重绘插画。

检查包括：23个唯一图案、所有输入高分辨率且有alpha、输出尺寸与透明角落、单枚体积、哈希与路线数量，并逐张检查主体和季节。`overview.webp` 是静态组合预览，不是游戏浏览器截图或真实手机测试。

打包结果：23枚均为384×384透明WebP，总计1,633,076字节，平均71,003字节，最大82,166字节；23个哈希互不相同。中文预览的23张图片与清单顺序、名称一致，所有图片内嵌，无外部资源请求，预览脚本语法检查与 `npm run check` 通过。本轮没有改动运行时玩法与存储代码。

景物依据沿用 `dist/route-moments.js` 已整理的武功山景区、香港渔农自然护理署、四姑娘山管理局、秦岭保护资料及杭州路线资料。人物与相遇细节为游戏创作；图片不标记精确拍摄机位、平台或日期。
