# 西湾山：轻点山路，登高望海

2026-10-21。用户要求简化西湾山这一关，点击后自动登高望海，不再一步一步点台阶，不卸包坐下。此批只改麦理浩径 `coast-sand` 及其入口缓存版本，其他路线和照片不动。v13 的坐下结尾与逐级操作保留为历史记录，不再作为当前体验。

## 本轮改动

玩家轻点山路即可开始，之后不再要求任何点击。人物连续经过石阶和山肩，走到开阔平台，背着包站立望向海湾与蚺蛇尖。画面在高处停留约六秒，再接既有圆形徽章、自动入帐和淡出。自动登高部分约六至七秒，减少原先逐级确认的停顿。

操作范围是画面内山路附近的宽通道，不再判定某一级特定台阶。轻点天空或海面不会开始或获奖。重复点击不会加速、跳过登高、重开动作或略过望海。Enter、空格和方向键保留为一次启动的辅助输入。

继续使用 v13 已有的分层水彩、两位 Q 版旅人的上阶和站立姿态，平台上复用已有普通步行帧。不生成新画作，不扩大资源体积。删除本关的卸包、坐下、平石点击、相关提示和卸包声音事件；坐姿原素材留作历史存档。竖屏镜头改为对准新的站立望海位置，保留山尖与海湾。

主要源码在 `src/runtime/coast-memories/shoulder/`。状态收为等待启动、自动登高、站立望海、完成四类，没有逐级等待或营地动作。景象与海风声音继续共享展开进度。徽章身份、原有首次回忆、路线触发位置及西湾山实拍保留；新回忆文字改为背包站立望海。
