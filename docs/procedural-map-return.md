# 主地图回到程序绘图

> 历史阶段说明：本文记录 2026-10-17 的程序几何地图尝试。2026-10-18 用户已确认 **2D + 精细手绘水彩 + 旅途手帐收集** 为产品主线，参见 [游戏理念与设计美学约定](game-design-charter.md)。当前仍使用 PixiJS 和程序化动效，但主画面回到手绘水彩语言，不再以粗糙程序几何作为最终主美术。

2026-10-17。用户在查看手绘行走样段后明确放弃本轮方向，认为过于复杂、问题太多，要求游戏主页面使用程序绘图与交互，并要求继续完成调整。

## 当前实现

- `src/app.js` 重新使用 `TrailScenery.build` 生成山体、草木、云雾等几何，交给 PixiJS 绘制；原 SVG 绘图路径继续作为降级显示。武功山不再装载整幅长卷或叠图前景。
- 武功山路线回到与程序景物一致的 720×600 绘图坐标。继续使用 `createVisualRoute` 的平滑曲线、前视朝向过滤和稳定镜头，保留上坡步幅及前倾。
- `src/runtime/procedural-map-character.ts` 直接生成 SVG 背包旅人。关节腿、摆臂、围巾与背包使用现有行走时钟；不再为主地图加载人物画片。旧水彩人物控制器及源素材保留存档。
- 主流程不再构造 `createWugongScene`、`createWugongStops`，因此不再出现本轮长卷界面、手绘停留弹层或自动手绘远景。相关模块与素材仍在工程内。
- 主页面不再展示独立手绘样段入口，旧 `wugong-study.html` 地址返回主页。原样段 HTML 备份在 `art/wugong-study/walk-preview-archived-v1.html`，样段 TypeScript、生成素材和构建产物保留，但不再作为默认构建的独立 bundle。
- 真实照片、路线进度、已有小游戏、音频和手帐沿用既有流程。没有清理、迁移或删除历史记录，没有提交、推送或发布。
