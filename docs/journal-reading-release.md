# 图文手帐更新 · 发布说明

## 最终行为

- 手绘和完整回忆在同一张纸页内直接阅读；路线筛选、日期、地方知识保留，手机单栏，宽屏两栏。
- 移除导入、导出、独立图鉴、未收集占位和页底隐藏详情。每批展开 12 段，继续翻页不会重建前面的图片。
- 同一地图同一景物只留一页；重复完成不新增、不重复写存储。完成状态不能被未完成尝试覆盖。
- 未完成互动离开不生成手帐，包括人物／动物相遇及三个 PixiJS 小游戏。完成后仍需收好画作再继续行进。

## 旧历史清理边界

发布不会自动删除历史。检测到旧手帐后显示“清空这份旧手帐”，用户点击并确认后才执行。确认文案明确：当前浏览器中的这份手帐全部记录将永久删除、无法恢复，不影响其他浏览器或其他存档。取消不写入存储。

只替换 `trailbound.field-journal.v1` 这一项，同时写入清理版本，后续新记录保留。未确认前，保存新奖励不会悄悄确认清理；无旧数据的新用户不触发清理。权限失败不声称已删除。Git 历史及素材文件不删除。

## 验证

用户明确批准测试后，集中执行与手帐、奖励流程和历史清理有关的检查，没有运行整个项目测试套件。

- 首批 11 个相关文件覆盖 81 项既有／更新用例：10 个文件通过；micro-moments 中 3 项旧交互序列仅部分完成却断言保存，已改为完成三步有效输入、遵守输入间隔并收好奖励。只复测失败范围，最终通过。
- 补充 1 项测试覆盖三个 PixiJS 游戏 × 跳过／Escape／切路线：中途离开无手帐、无奖励、无存储写入，通过。
- 对其他文件中仍引用移除 UI 的手帐断言更新后，额外仅选取 7 项相关用例执行，通过。累计 89 项相关用例覆盖通过，非全套测试通过声明。
- 修改的三个运行时 JS 文件语法检查、差异空白检查、资源检查通过。29 类水彩奖励资源齐全。
- 覆盖：图文关联、分页与焦点、路线上下文、重玩去重、取消／确认清理、其他存储键保留、清理后新记录刷新保留、拒绝存储、图片加载失败时文字可读、完成后奖励收纳。

测试含模拟 DOM、事件和 Pixi 对象。当前没有真实浏览器控制能力；未进行浏览器截图、实体手机、GPU 性能或音频听感验收，不能把以上检查当作真机验证。

原站点及私有访问范围保持不变。发布结果由 Sites 原生部署返回确认，用户浏览器历史是否清空仍取决于页面内的主动确认。
