# 麦理浩径：封面与地点地景

2026-10-20。用户要求“修改封面，并将每个地点落地地图中”。本轮仅修改麦理浩径的入口与地图呈现，沿用本线已有集中测试授权。未提交、推送或发布。

## 实现

主站选择麦理浩径后，使用已有 `dist/scenes/maclehose-v1.webp` 海岸水彩作为封面，介绍浪茄至北潭凹的一日旅程；出发进入新版 2D 地图。复用既有素材，未生成新图。旧来源记录仍在 `docs/scenes-v1/sources.json`，画面是场景插画，不称为地点实拍。

七个地点在 `PLACES` 中分别定义地景的落地位置，地景绘制与地图名称共用该坐标；人物抵达、路线先后与游戏触发仍使用原有路线坐标和里程。补充的短小石径连接主路与地景，不是文字引线，也不改变可行走主线。

| 地点 | 地图表现 |
| --- | --- |
| 浪茄 | 沙岸入口、路牌、踏石与岸边灌丛 |
| 西湾山 | 草坡山脊、岩石与小型石标 |
| 西湾 | 沙岸后方屋舍、院落与村径 |
| 咸田湾 | 村屋、沙滩边空地与通向沙岸的小径 |
| 大浪坳 | 两侧低坡之间的山口与路标 |
| 赤径 | 村屋和连接现有码头的村径 |
| 北潭凹 | 林缘出口、石阶、路牌与植被 |

这些是地域类型与位置关系的示意性绘制，不宣称还原实际建筑、石标或路牌外形。地图继续复用 PixiJS 8.22 图形、曲线和海岸遮罩，没有改用整幅手绘底图或新引擎。

七处名称均直接贴近地景，采用相同尺寸的小线条图标，取消旧的圆形大标和整体向下偏移。三处实拍继续保留，抵达后仍可点击回看。默认跟随，只能主动切到全图；不增加小游戏地图入口。

实际查看时发现地图内开场说明遮住浪茄地景和人物，已删除该重复说明。路线介绍保留在封面与页头，出发按钮仍在地图下方。
