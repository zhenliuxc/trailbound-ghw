# 七路线场景音效适配 · 2026-10-16

用户要求“优化一下音效，适配各个场景”，随后明确“给你了全部权限”。按该授权完成整体实现、集中测试、Git 保存与原 Sites 项目发布，不再逐项请求确认。

## 改动

新增 `dist/audio-scenes.js`，为七条路线、21 处照片场景和 29 个现有画作互动提供明确声景。统一自然、细腻、克制的听觉方向，不增加玩法或改变原画、奖励条件及手帐存档。

| 路线 | 声景与区域变化 | 脚步与操作 |
| --- | --- | --- |
| 武功山 | 草甸叶声较近，山脊风声较开阔，金顶减少近景叶声 | 草地／金顶石阶；牵线有轻摩擦，拨云有短风声，拍照有双段快门，拼片有纸声及柔和锁合音 |
| 虎跳峡 | 低处江声、客栈旁远江，瀑布增加较亮的水雾层 | 石径脚步与短回响；取景、水帘、近处木质反馈按画作选择 |
| 秦岭虚拟章节 | 高通雪粒、稀薄风层；大风雪时加强天气层 | 雪地颗粒脚步和短促摩擦，不加入暖季林鸟声 |
| 麦理浩径 | 海岸浪涌，山坡岸风，赤径减为较轻的拍岸水声 | 沙地／山径／渡头木质脚步；沙画为细沙摩擦，水面为轻拨水 |
| 长坪沟 | 林间叶声、近溪水，木骡子降低近水并打开风层 | 土径脚步；倒影拨水、石面微响和开阔处风声 |
| 莫干山 | 竹叶高频层与少量滴水，溪边增加水声 | 石径脚步；雨滴落入才触发滴水与竹木音高，漏接更轻；弹弓有拉动、破风、竹干碰撞和纸叶落点 |
| 九溪—龙井村 | 浅溪逐步转茶园叶声，再转村口近声；晴天不叠强雨声 | 石径、近水、茶叶纸卡与注水设计音；消除反馈保留轻音阶，避免强烈电子提示 |

- 环境、近处反馈和照片旋律分总线。操作成功与快门等近声可短暂降低环境音，随后恢复；照片旋律降低，保留各打卡点原有旋律差异。
- 路线区域、天气、画作 ID 和游戏类型共同选择声景；不同画作不再只依赖同一路线的通用底噪。雨、风雪与大风层随当前地图天气变化。
- 区域切换交叉淡化。录音解码后缓存用于循环接缝的短交叉混合；小幅进度更新不重建声音，也不在每帧反复重置渐变。
- 重复手势有冷却，完成音每个声音场景最多触发一次。素材未准备好时立即使用合成反馈，不在下载完成后补播旧操作；切走或隐藏后迟到结果不能重启声音。
- 普通图文回忆、Pixi 小游戏及减少动态效果模式，都有纪念画展开与收好时的声音。仅主动开启声音后工作，静音和后台暂停继续优先。

## 素材与网络情况

音频文件没有新增或替换，仍为约 537 KB 的六段已有授权录音与节选，低于原 600 KB 上限。按场景实时滤波、调速和混音，结合原创合成风、浪涌、雪粒、材质与乐音，不宣称当地实录；海浪层是经处理的水声与合成浪涌组合，纸片轻响使用叶声拟音。

实际使用的来源保持 `dist/audio/credits.json`：

- [Swale — Ksd5](https://commons.wikimedia.org/wiki/File:Swale.ogg)，CC0。
- [Leaves falling from the trees during autumn in the forest — Wilfredor](https://commons.wikimedia.org/wiki/File:Leaves_falling_from_the_trees_during_autumn_in_the_forest.wav)，CC0。
- [Water drops dripping — ZooFari](https://commons.wikimedia.org/wiki/File:Water_drops_dripping.ogg)，CC BY-SA 3.0；现有衍生节选保留同许可。

已查阅 Commons 风、风雪、雨、潮汐及 Kenney 音效的来源页，部分候选可合法使用，但当前执行环境实际下载返回代理 403。没有将这些未取得文件写成已接入，也没有采用外站音频热链。新增源码、许可说明和页面“声音素材来源”如实说明当前材料的用途。

## 集中验证

相关文件为 `audio-scenes`、`audio`、`water-flow`、`wind-flow`、`wugong-chapter`，未重跑所有路线的完整测试集。规则、声音生命周期与模拟 UI 检查完成：首轮有一项旧水声用例假定环境固定最多三声部，新设计保留分层环境后该假定不再适用；改为验证一次操作结束后回到原有声部基线、重复设置不积累，再定向复测通过。其余相关项通过。

`npm run check` 与差异空白检查通过，涵盖脚本语法、依赖顺序及音频许可／字节／哈希和已有资源检查。

`scripts/test-scene-audio-browser.cjs` 在实际 Chromium Web Audio 中运行：1280×900 桌面和 390×844 手机尺寸，各测七条路线输出及 29 个画作场景的声音响应；音频取样非静音、取样窗口峰值低于削波阈值，0 页面异常、0 失败请求。六个音频资源各只请求一次并复用，隐藏后声音数归零，隐藏／禁用时新事件不发声。此脚本是音频引擎及输出检查，不等于 29 个游戏全部通关。

另外在实际站点页面验证主动开启、后台处理、回前台保持暂停行进安静、手动继续及静音，均通过。声音图／模拟 UI 检查不能替代浏览器；Chromium 手机尺寸也不等同实体手机。未进行人工试听、实体手机外放或真实设备性能验收。

证据：[原生输出与场景结果](previews/scene-audio/browser-results.json)、[站点音频开关结果](previews/scene-audio/app-audio-results.json)。本轮未改动视觉布局，沿用版本 39 的画面。
