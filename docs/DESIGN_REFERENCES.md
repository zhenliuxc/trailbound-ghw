# 山野发现：玩法参考与本项目的取舍

查阅日期：2026-10-14。以下是开发者的官方游戏页面；只借鉴玩法思路，没有复制任何游戏的代码、画面、音乐或文案。

| 游戏 | 官方页面描述的体验 | 对 Trailbound 的设计启发（本项目判断） |
| --- | --- | --- |
| A Short Hike | 小型山地探索，徒步、攀爬、滑翔，寻找隐藏事物、遇见其他徒步者 | 路边要有值得注意的小目标；走路本身也能有所发现 |
| TOEM | 摄影冒险，观察环境、与角色相遇，慢慢欣赏风景 | 让一次观察变成纪念；真实照片打卡与虚构插画发现明确分开 |
| Alba: A Wildlife Adventure | 岛屿与野生动物探索、救助，允许玩家按自己的节奏游玩 | 可选观察、不惩罚漏看，用手账鼓励再来一次 |
| Firewatch | 荒野中的故事，通过无线电沟通和选择推动关系 | 少量有意义的情境选择，比不断点击状态按钮更适合当前漫游体验 |

当前趣味性不足的设计判断：路线和停留点完全固定，玩家大多等待预定事件；看完照片后缺少能留到下一次的个人成果。v0.8 增加“观察 → 记住 → 回忆”的短循环，而不是再增加一组物资操作。

## v0.8 已实现

- 三个地貌各有三种虚构观察：草甸小鸟/蝴蝶/花，峡谷山羊/飞鸟/水光，风雪脚印/光/苔痕。
- 每次旅程随机排列三项，微调出现时段；沿路插画标记与原生按钮都能触发一次观察。暂停时也可观察。
- 不停止行走、不增减生存数值，不设置分数、倒计时提示或漏看惩罚。发现阶段有约十几秒的观察机会，暂停可延长停留。
- 本次发现进入旅程回忆；九项手账跨地图、重玩保留在当前浏览器。存储被禁用时退化为本次页面会话，并明确提示。
- 命名打卡点的九张实景照片继续使用原摄影素材及署名。虚构插画不是实地物种调查，也不是某个坐标的真实照片。

这次增加的是轻量观察玩法，尚未实现自由移动、支线岔路、NPC 对话或摄影构图；也没有进行用户趣味性测试，不能把设计判断当作已验证的留存提升。
