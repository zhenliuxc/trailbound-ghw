# 武功山 · 四段山野小事

基于原私有站点版本 36（Sites 源码 `12a917351951c96c8600cc5130505c6666ac5e56`）和开发分支 `codex/recover-site` 的 `906ae24`。本轮用户要求“完成武功山的全部玩法”。开始时工作区无未提交改动，已同步核对原 Sites 与 GitHub 分支。

## 实现范围

武功山目前有三个景物互动和一个人物相遇，全部接入小游戏层：

| 片段 | 操作与完成条件 | 视觉及声音 |
| --- | --- | --- |
| 借一阵草甸的风 | 沿用纸鸢牵线，稳住三阵风 | 沿用水彩纸鸢、草叶网格、风流和牵线反馈 |
| 等云开，留住山脊 | 移动取景框，对准三处不同山脊；薄云让开时稳住各 1.5 秒 | 新云海水彩全景、云层流动、取景框、取景轻响与空气音色 |
| 在石缝里，读一段时间 | 移动透镜，依次在石拱、石缝、苔色上停稳各 1.2 秒 | 新石坛水彩环境、1.85 倍局部观察、低音提示；不搬动或敲击石块 |
| 隔着草坡，挥一挥手 | 观察人物举手，在每轮回应窗口轻点或按 Enter，完成三次回应 | 新透明三姿态人物精灵、举手与挥手、一来一回的空间音符与叶声拟音 |

三段新玩法均没有观看超时后自动完成的逻辑。云海／石坛必须分别移至不同目标，挥手每轮只计算一次成功，Enter 按住重复触发不能代替三次操作。早按、晚按不会扣除已完成的问候，下一轮可继续。

## 流程与兼容

- 与原四个互动 ID、路线出现位置、手绘标签和历史手帐保持对应。开场文案说明这四段小事，发现提示使用当前玩法名称。
- 三段均使用同一游戏时钟驱动进入、操作、阶段反馈、完成定格、纸页展开、奖励、收藏与返回；结束过渡约 2.7 秒，减少动态效果时约 0.5 秒。
- 继续使用现有完成判定后保存、未完成不发奖、重玩不重复手帐的流程。不新增清空、导入、导出或独立图鉴。
- 支持触摸、鼠标和键盘、重试、退出、切后台暂停、手帐阅读暂停；没有启动另一套独立计时器。
- 新背景保持比例完整显示，画面、观察目标、透镜与指针共享同一坐标换算，手机不通过拉伸石坛或人物来适应方形区域。
- PixiJS 场景复用精灵、Graphics 与掩膜；正常 GPU 绘制时不同时逐帧更新 SVG。GPU 不可用或上下文丢失时保留可玩的画作与矢量辅助层。关闭后清理观察器、场景、纹理，并忽略迟到的资源加载。
- 当前路线提前加载图像，复用已有解码缓存和 GPU 上传准备。新素材总计约 1.00 MiB；不改旧文件名与素材。

## 素材与声音

生成两张暖季武功山水彩环境和一张透明人物三姿态精灵表，按画面实际位置设置观察点。新素材的源图、尺寸、字节数、哈希与处理方式记录在 `dist/scenes/wugong-chapter.json`。原图保留在 `/workspace/generated_images`，站点只打包压缩 WebP。

古祭坛为延续既有标签形象的艺术插画，不宣称精确的建筑复原。新人物延续既有暖季衣着与配色，相遇仍为游戏虚构场景。

声音复用已打包、有许可记录的叶声录音、短叶声拟音和原创合成音色，按玩法调整混音及事件音；本轮没有新增网上实录，也不把拟音说成真实相机、石头或人物录音。原始作者、链接与许可仍见 `dist/audio/credits.json` 及站点素材来源。声音需要用户主动开启，短音仅使用已解码素材或即时合成，不在迟到的网络请求完成后补播旧操作。
