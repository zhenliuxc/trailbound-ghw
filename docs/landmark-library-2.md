# 地点图标库：轮廓、尺寸与密集地名

可复用的设计与验收规范见 [地点图标设计流程与规范](landmark-icon-design-guide.md)。本文保留本轮实现与检查记录。

2026-10-21。用户同意统一改善七条现行 2D 地图的地点图标。此轮已实现，视觉效果仍待用户确认；不调整路线行程、照片素材、小游戏或收藏规则。

## 图形与屏幕尺寸

27 类符号继续使用米白圆底、草木绿线描。竹林保留竹节、细竿与成簇尖叶；其余图形删去小尺寸下混在一起的细枝和重复线条。

- 海湾用弧形岸线和沙点，江流用礁石与折浪，溪谷用纵向曲流，瀑布保留垂直落差。
- 山顶使用不对称峰形与雪线，山脊使用连续折峰，山口强调两侧山坡之间的凹口，草甸用舒缓坡面。
- 干海子表达低洼草地与坡缘，不再用容器轮廓承托植物。茶园保留茶叶与垄线，石海强调成组石块。
- 跟随 30 px、桌面全图 26 px、小屏全图 24 px；命中区保持 44 px。内线宽为 1.85/40，在 24 px 显示时约 1.11 px。
- 可重新查看照片的已到达地点加深外圈。图标类别仍说明地景，具体身份由中文名称补充；手帐圆形手绘徽章独立保留。

`landmark-library.html` 新增图形总览、随行、全图、小屏全图四档预览，尺寸直接使用生成的共用变量。SVG、地图和总览仍从同一个 TypeScript 定义生成。

## 共同排布与接入

`LandmarkLayer` 保持地点投影锚点不变，只调整附近的名称。沿用上一次仍能容纳的名称方位，减少镜头缓慢移动时的左右跳换。排布同时避让右上角视角控件和左下角章节条。

新增 `LandmarkNameLayer`，用于没有照片按钮的次要地理名称，与主要图标共享占用空间。虎跳峡的纳西雅阁、茶马客栈、张老师小路，以及鳌太的山峰、山梁等名称已迁入，旧的鳌太专用排布模块已移除。

```ts
const occupied = landmarks.update(projection, view, placeState);
names.update(projection, view, isNearby, occupied);
```

`MapLandmark.importance` 可设为 `secondary`。只在全图中、且没有可点击照片时，过密的次要圆形符号让位，保留地点名称与说明；随行视角恢复符号。鳌太的四处过夜营地采用此级别，手机全图盆景园不再盖住白起庙。日间路线将沿途无照片的普通地点作为次要符号，起终点与照片地点保持主要级别；长坪沟手机全图的下干海子保留名称，给溪谷照片符号留出空间。恢复符号有间距缓冲，避免相近缩放下反复显隐。该策略不改变地点坐标，也不隐藏主要照片地点。

可见按钮明确设置 `pointer-events:auto`，避免继承地图覆盖层的穿透属性而点到画布。仅保留名称的次要标记不阻挡相邻照片按钮。

## 验证记录

- `npm run build` 通过，包含 TypeScript 构建。实现与验收修复后均已构建。
- `node --test tests/aotai-camera.test.cjs tests/wugong-schematic-trip.test.cjs`：15 项通过。覆盖实际地理锚点的密集名称布局、营地名称保留、名称方位稳定、长坪沟相邻溪谷与草甸的避让，以及既有武功山行程规则。
- 在实际浏览器中检查七张地图的桌面 1454×818 与手机模拟 390×844 全图。最终各图主要名称均显示，文字之间、文字与图标没有交叠，圆形图标没有相互盖住，页面没有横向溢出。图标分别为 26 px 与 24 px。鳌太与长坪沟在手机全图分别收起一枚次要符号，名称仍在。
- 首轮发现长坪沟溪谷与下干海子圆底重叠，修复后复测通过。图标碰撞按实际圆底外缘计算，保留矩形包围盒数据供复核；斜向相邻图标的透明矩形角相交不等于圆底相交。
- 实际点击发现共用按钮继承 `pointer-events:none`，已修复。手机浏览器点击东江村图标，正常展开照片；关闭后再次点图标，照片重新打开。另核对白起庙中心命中自身按钮，盆景园的透明命中区域不会挡住它。
- 自动几何检查只验证边界、遮挡、坐标和状态，不能替代图形辨识度与实际点击验收。
- 截图与前后几何记录保存在 `docs/previews/landmark-library-2/`。本轮没有重新完整实走七条路线、逐张验收照片、真机或音频验收。图标预览页已更新，可切换实际显示尺寸。
