# 九溪绘本美术样稿

本页记录此前九溪版本；最新七路线完整实现与验证见 [FULL_GAMEPLAY.md](FULL_GAMEPLAY.md)，当前新候选尚未部署。

本轮先完成九溪龙井的矢量美术与构图样稿，供确认画风。没有发布到 Sites，原私有试玩站点仍是上一版。

## 画面

- `dist/illustration.js` 用原创路径绘制树冠、枝叶明暗、溪岸湿石、苔色、茶叶丛、茶垄、灰瓦村屋、窗格与小草花。场景同时被原生 SVG 和 PixiJS Graphics 消费；没有用大图遮盖真实路线，也没有新增图片下载。
- 九溪采用 27 棵分层树冠、三片六行茶垄和四条既有水系片段。笔触由低透明度的小路径和不规则轮廓构成，仍是矢量插画；不是扫描水彩纹理。
- 背包人物重新绘制帽子、脸部轮廓、外套、背包口袋、水壶和布料明暗，继续使用原步态与拍照、观察动作。人物新造型用于所有路线，九溪显示尺寸略增；其余六条地图的背景美术未改。
- 九溪的路线描边更细，显示溪水颜色；标记的圆形触摸区域和键盘焦点仍保留。三种小互动增加湿石、叶脉和竹篮编织/提手细节。

## 路线和性能范围

九溪 154 个原始路线节点、真实照片、手帐、声音与互动逻辑没有改写。水系的位置仍来自既有投影数据，显示宽度为插画表达。山丘、茶垄、树林和村屋轮廓是辅助构图，并非精确地形测绘。

当前九溪场景约 914 个基础图形；新增模块约 9.5 KB。几何在地图切换时构建，行走时继续更新既有相机、人物和少量水光/云雾。高像素密度仍由既有画布预算约束。这些是代码与结构检查，不能证明真实手机帧率或耗电。

## 验证与预览

- `npm run check` 通过。
- `npm test`：143 项通过，含原有七地图旅程、照片加载、触摸小互动、后台/暂停及镜头检查，另加 SVG `stroke="none"` 的 Pixi 编译回归。
- `render-picturebook-study.cjs` 从实际旅程 DOM 夹具导出 SVG，再用 Sharp 渲染 PNG。电脑全景、390 宽手机跟随构图及局部放大已目视检查。
- 预览中的页面标题和控制条是用于确认构图的静态排版，不是浏览器 CSS 截图，也不是手机实机测试。中文 PNG 使用 Google Fonts 的 Noto Serif SC 小字集，仅安装于 QA 环境，未作为站点依赖分发。
- 当前缺少可用的浏览器预览能力，未运行真实 WebGL、手机触摸或流畅度测试。下一步由用户确认画风后继续调整，不自动上线。
