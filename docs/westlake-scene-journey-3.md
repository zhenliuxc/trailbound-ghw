# 九溪四关的场景递进

2026-10-22。实施范围为九溪现有四关的画面与操作坐标，让“溪谷、过溪、茶园、村口”可辨。四关机制、事件身份、圆形徽章、旅程地点和天气顺序沿用原设定。其他路线没有新增玩法或素材。

## 已实现

| 路段与互动 | 画面处理 | 操作与反馈 |
| --- | --- | --- |
| 九溪溪谷，推叶 | 新增树冠包围的林荫浅水，连续水面作为漂流区 | 点叶后水面推动落叶，叶片和水纹一起沿水面移动 |
| 十八涧石径，踏石 | 复用原溪流手绘，补足近岸、三处落脚石和对岸 | Q 版旅人从近岸逐块走过，完成后再走上对岸；脚点与各石面的坐标共用 |
| 龙井茶园，辨芽 | 改用开阔茶垄构图，下方纸页保留芽叶辨认区 | 沿用一芽、两处嫩叶的点选，已选项保留并做轻标记 |
| 龙井村口，注茶 | 新增近处屋檐、村巷与木桌，茶盏放在桌面 | 按住茶盏注水，松手后舒展；村景和桌外区域不启动注水 |

横屏、竖屏分别配置背景取景重心。素材保持等比铺满。四关操作区域与绘制共用 `westlake-layout.ts`，由实际画布宽高换算，避免杯子缩小后仍沿用桌面命中范围。

场景配置位于 `src/content/westlake-scenes.ts`，九溪绘制位于 `src/runtime/day-memories/westlake-scene.ts`。现有公共输入、暂停、释放、素材缓存、奖励和手帐保存继续复用。没有新增按钮、采集任务或存储标识。

## 素材与构建

- 两张新增插画由内置 imagegen 生成，以原九溪春日水彩为风格参考，属于游戏插画，不是当地实拍。
- 原图与完整提示词：`art/westlake-journey-v3/`。
- 站点素材与来源记录：`dist/scenes/westlake-journey-v3/`，两张 WebP 均为 1536 × 1024。
- 素材构建：`node scripts/build-westlake-art.mjs`；站点构建：`npm run build`。
- 九溪行进页、小游戏页更新素材版本参数。来源页接入新增插画记录。
