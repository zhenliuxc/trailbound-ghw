## 可用功能

在「翻开旅行手帐」内：

- 导出手帐备份：下载JSON文件，包含全部保留回忆、日期、天气、正文、互动状态与图像版本；不是仅导出当前筛选或当前页。此备份用于同一山径站点的恢复，不内嵌图片。
- 导入手帐备份：接受新版备份及旧version:1 / version:2数据；合并到原手帐。重复导入不重复计数；相同编号但内容不同的回忆分配新的导入编号，保留两条。损坏文件、未知条目、格式冲突、读取失败、超过容量或持久化失败均保留原手帐。
- 跨设备迁移：将备份文件带到另一台设备，在原站点登录后导入；没有新增云端自动同步。
- 按七条路线筛选回忆和图鉴。29类互动分别显示已获得/待收下、地点与玩法提示；西湖随机景物附重玩提示。旧版普通回忆不会凭旧内部ID自动变成新互动标签。
- 手帐容量由120条提高至10,000条，默认显示最近60条，可继续翻页；达到容量时保留已有回忆并提示导出，不自动删除最早回忆。导入文件上限32MB。
