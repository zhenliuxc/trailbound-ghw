# 选择结果关闭按钮、手帐展示与接雨错位修复

日期：2026-10-15。基于原私有站点版本 32，GitHub `4b10574`，Sites `38eae12b0831e295b7e47a8e64bb55312d33ee8f`。

## 用户反馈与修复

1. 选择结果提示卡的 × 按钮跟随文字宽度排列，短文字时落在卡片中间。现在固定在右上角，保留 44×44 点击区域，正文预留右侧空间；手机尺寸使用相同锚点。
2. 截图中的“一段沿途回忆”来自 `edition=3, earned=false` 的普通记录，并非已获得标签丢图。改为同尺寸纸页缩略图，明确显示“沿途记事／未获得标签”，详情解释尚未完成对应互动。标题和地点对齐，不迁移、不删除、不补发旧记录。已获得标签改用有加载状态的懒加载图片；真实加载失败时显示“画作暂未加载”，仍可翻看原文字。旧版图集与历史画作版本保留。
3. 竹筒 v1 素材带有左上角的叶片碎片，透明边界不对称，导致实际筒口偏离几何中心。使用 ImageGen 清理素材，按可见透明边界加少量余量裁切并压缩为 v2。保留 v1 文件并在清单中标记替代关系，当前场景只引用 v2。
4. 筒身、水面和水纹现在共享筒口坐标，水纹限制在开口内。取消接滴时的非等比压缩和独立倾斜，竹筒只平移。筒身大小与纵向位置适配宽幅和竖屏，不再被底边截断。
5. 接滴采用穿过筒口平面的判定，并插值该时刻竹筒横向位置；筒口外的雨滴和已落过筒口后才移入的雨滴不计分。SVG 降级图形与图片也使用一致的筒口位置。
