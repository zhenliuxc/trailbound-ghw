# 虎跳峡 S 弯路线标识与画面铺满

2026-10-19。用户要求“标清楚路线，另外图片和照片占满容器”。本轮只调整当前 S 弯手绘关卡及虎跳峡打卡照片，沿用已授权的本关集中测试。其他路线、另外三处小游戏的布局和历史手帐没有功能改动。

## 改动

- 描画前显示米白衬边、草木绿虚线和三处方向箭头，明确起点与山肩终点。已画部分变为实线；开始操作后保留简短起终点标识，自动行走时收起引导。
- 手绘画面按容器实际宽高计算等比铺满和取景。桌面保持宽幅、窄屏保持纵向，完整 S 弯、人物落脚和标识保留在画内；没有横向拉伸或给侧边另铺一张不同投影的背景。
- 画布显示与输入转换共用同一套取景计算，输入再映射到关卡原有坐标。路径、人物、画线判定继续共用同一条路线。
- 激流镜头沿用当前容器宽高铺满，继续复用既有水彩插画与局部水流动画。
- 虎跳峡打卡照片由 `object-fit: contain` 改为等比 `cover`。图片元素与照片区域完全同宽同高，按中心裁切多余边缘；地点、照片出处和许可保留。
- 虎跳峡地图、手绘页、脚本与嵌入页面更新为 `road-guide-7` 缓存版本。
