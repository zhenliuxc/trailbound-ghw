# 游戏理念与设计美学

山径是一段有地域感的虚拟徒步。玩家沿山路前进，停下来认识地点、参与简单的手绘互动，再把经历留进旅行手帐。体验保持安静、细腻、自然，不以生存数值、连续任务或收藏进度催促玩家。

## 视觉语言

三种画面各有职责：程序绘制的 2D 示意地图交代空间和行程，精细手绘水彩承载封面、事件与回忆，对应地点实拍帮助认识真实景色。

主色为米白、草木绿、青灰与少量暖金。水彩保留纸纹、透明叠色、颜料边缘、自然光照与材质细节；远景克制，近景有值得停留的内容。人物、物件和背景的笔触、比例、光照保持协调。精细画面不以粗糙几何图元代替，图标、辅助线与失败降级可以使用 SVG。

主线使用 2D 与 PixiJS。技术选择服从山路行走、手绘互动与旅行手帐的体验，不因框架能力改变产品方向。

## 地图与空间

首页全国地图用准确的地点、中文名称与地域信息选路线。点开手绘封面，再进入旅程。默认跟随人物，地图右上角提供跟随／全图切换；全图由玩家主动打开。

示意地图允许压缩距离和调整构图，真实地点、先后顺序、山脊与沟谷关系必须清楚。起点、终点、过夜、支线与原路返回都应能从画面读懂。各路线统一可用高度、人物屏幕尺寸和跟随平滑度，保留各自地形。

小径沿坡面、谷地或山脊展开，保留重要转弯与爬升下降。以踩踏草径、碎石、石阶表现路感，避免悬空道路、宽阔土黄色跑道、双亮边和重复横格。人物和小径优先可读，装饰不覆盖它们。

地点图标与中文名称直接落在对应地景附近。图形大小与线宽统一，名称就近避让，不用长连接线搬动整组标记。地图不另放当前位置卡或小游戏标记，具体标准见 [地点图标规范](landmark-icon-design-guide.md)。

森林、草甸、裸岩、溪谷、云海与村落按路段逐渐展开。人物、道路、植被和云雾分层，共用落脚与遮挡关系。云和前景不能长期盖住主要山形。天气、季节与时间变化同时反映在地景、光照和声音上，沿用 [路线设定](ROUTES.md)。

## 人物与运动

使用现有可选的大眼睛 Q 版旅人。人物相对山体保持小巧，脚点贴合路面，上坡缩步微倾，下坡控制重心。朝向参考前方路径并过滤细碎转向，避免瞬间翻面、闪烁与滑步。

镜头跟随行程中心，不追随每一步或呼吸起伏。草叶、围巾、背包和云雾的次级运动服从同一环境与时钟。动画具有可见原因，人物停步、卸包、休息与再出发按路线事件衔接，不能为了增加动画而随意插入动作。

## 发现与互动

小游戏简单、有趣，机制服务于画意。从当地景色、物件和路段事件出发，一句话说明目标，一关聚焦一种主要操作。相邻关卡在判断与反馈上有区别，避免重复拍照、让路或停留对准。

先通过声音、景物或人物动作制造发现，再进入手绘互动。照片打卡与小游戏分开安排，同一点不连续堆叠多层确认卡。行走、爬升、休息和返回之间保留节奏变化，避免长段没有变化或每几步就被弹窗打断。

玩家直接点击、按住、拖动与松开画面，有明确目标、即时反馈和可理解的完成条件。一次有意义的操作可以启动连续演出；空白点击、纯等待或拖动整幅背景不算完成。笔迹和摆放结果按规则保留，碰撞、声音与画面使用同一游戏状态。

玩法选型与公共能力边界见 [小游戏机制指南](gameplay-mechanism-guide.md)。

## 手帐与记忆

每关完成后展示独立圆形手绘徽章，保存成功后自动入帐，短暂停留再淡回山路。未完成、跳过和纯观看不发奖。徽章留下刚经历的具体一刻，纸边、尺寸和材质统一，图案与地点对应，规范见 [徽章设计](journal-badge-design-guide.md)。

画作与回忆组成同一面整齐收藏墙，按路线页签翻看，点击阅读大图、地点、日期和文字。手机页签可横向滑动，不另设未收集进度墙。

保存沿用统一存储与事件身份。重玩不重复新增记录，既有文字、日期与玩家画作受保护；展示升级不自动覆盖原件。保存失败明确提示并允许重试，不在失败时宣称已入帐。照片、徽章和本地路笺保持各自的记录类型。

## 声音与界面

声音包含配乐、自然环境声、材质操作和收藏反馈，音量克制，脚步较轻。风、水、雨、马铃等路段声音应可辨认。用户主动开启，支持静音、后台暂停与退出清理；静音时关键线索仍能读懂。使用免费且许可明确的素材，通用录音如实标识，细则见 [声音](MUSIC.md)。

界面留出画面空间，文字和按钮只提供当前操作所需的信息。关闭位置稳定，触控区域足够。去掉游戏页致谢页脚、多余说明面板、发光光圈和装饰 HUD，来源许可放在独立来源页或适当的小字说明。

电脑与手机适配各自可用空间。图片等比铺满容器并保护主体，避免拉伸人物或在横幅下留下大片空白。构图改变时同步调整触控坐标。保留键盘辅助、暂停、退出、重试与减少动态效果。

## 交付依据

画面需让人看清人物、小径和当前地理主题，走路与遮挡可信，照片地点准确，互动能理解，收藏衔接顺畅。实际观看与操作是体验依据；构建、自动检查和库的能力不替代审美认可、手机真机或听感。

新增路线与改造按用户指定范围进行，复用已有公共能力，不以换背景代替新的路线设计。当前规范随明确产品决定直接更新，不追加版本流水账。
