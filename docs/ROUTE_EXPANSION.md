# 三条新山径（2026-10-14）

游戏现有六条路线，每条独立地图、连续行走故事、三个区域实景照片入口和三个可选旅行瞬间。新增瞬间包括潮痕、贝壳、渡头倒影、苔木、木道、溪水倒影、竹叶雨滴、旧石阶和落叶；手帐保留发生路线、地点语境、旅程进度、天气、时间与个人回忆。原九个瞬间 ID 和浏览器存储键保留。

## 声音与图像

九张新增照片等比缩小为最大 960 px WebP；细节密集照片使用最大 768 px、质量 66 编码，单张 23–107 KB。选择路线时只预取本路线三张照片，打开和重看复用已经解码的 Image 节点，继续行走不依赖照片加载成功。

九枚新手帐徽章由内置 imagegen 逐枚生成，缩小到 192×192，组合为 576×576 透明 WebP 图集（138268 字节）。图集与实际瞬间一一映射，原图集保留。完整提示词见 `BADGES.md`。

新声音由 Web Audio 原创合成：海浪使用缓慢起伏的滤波噪声，长坪沟为溪声与木质/铃音，莫干山为竹叶声、雨滴与石阶节奏。不是现场录音。
