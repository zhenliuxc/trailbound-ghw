# 武功山连续互动流程 · 2026-10-15

基于已发布版本 30（Sites 源码 1ccff67444c590c19f25f39d725182164e0f435e；GitHub 678f334）。用户选择 Puzzling Potions 作为互动体验参考，并同意按此方向实施。

## 实现范围

仅改造武功山「借一阵草甸的风」的表现流程，保留三阵风的实际操控要求、原手绘奖励及全部旧手帐记录。

- 独立 PixiJS 场景保留背景、云雾、风流、牵线、纸鸢、前景草叶、草籽与完成粒子。纸鸢使用 13×7 网格，草叶使用 24×6 网格；复用对象和顶点缓冲，不在正常游戏帧重建整套矢量场景。
- 原创透明水彩草叶素材，与既有武功山暖季草甸配套。WebP 为 181,566 字节，来源与哈希记录于 dist/sprites/wind-layers.json。
- 触碰立即响应；牵线声、脱离风带声、稳住风时增强的风声与阶段音符对应实际游戏事件。声音遵守显式开启、静音及后台暂停，连续风声复用同一音轨。
- 接住一阵风后保留 0.85 秒过渡，再累计下一阵风；完成后纸鸢飞向远处，画面停止环境运动、出现纸边，再展开原手绘纪念。减少动态效果时缩短为静态揭示。
- 收藏时纪念画缩入手帐标记，然后回到行进。动画失败、取消、重复点击和后台切换均不会锁住界面或重复发奖。
- 手机竖屏使用方形互动区域，电脑/横屏保留宽幅；画布与 SVG 降级路径随区域尺寸调整坐标，纸鸢纹理保留比例。44px 操作按钮、键盘操控与焦点处理保留。
- 图像经解码缓存准备后逐个上传 GPU，上传期间仍可使用降级画面。跳过和关闭后清理观察器、场景和独立纹理，忽略迟到的加载结果。

## 参考使用

参考 https://github.com/pixijs/open-games/tree/main/puzzling-potions 的连贯屏幕流程、操作反馈、音画配合及资源管理方式。没有复制其素材，也没有把三消玩法移植进山径。延续项目既有 requestAnimationFrame 与确定性游戏时钟实现过渡，没有额外引入 GSAP。
