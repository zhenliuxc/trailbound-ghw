# 两位旅人的角色选择

2026-10-19。用户要求小人可以选择不同角色，并提供双辫女性旅人设定图。本轮接入当前武功山和虎跳峡两个 2D 行走页面，其他路线地图、玩法及历史手帐没有改写。没有提交、推送或发布。

## 已实现

- 两个页面的页头新增“角色”，提供蓝衣旅人与双辫旅人两张选择卡。默认保留蓝衣旅人，用户确认后才换角色。
- 角色准备完成后再替换地图精灵，加载失败保留原角色，并在选择框内提供重试提示。关闭选择框或退出页面会取消仍在进行的选择。
- 选择框打开时暂停行进、过夜计时和路线音频，保留位置、当前视角、地点和已完成事件；回到地图后可以继续走。切换不重新开始旅程，不操作手帐记录。
- 使用独立的 `trailbound.character.v1` 浏览器存储项；重新进入武功山或虎跳峡时读取上次确认的角色。已有打开的另一页不会自动改变角色。存储不可用时仍可在本页切换，角色按钮的提示说明暂不能记住选择。
- 两套人物均有八帧行走，以及卸包、蹲下、坐下、喝水姿态。虎跳峡 S 弯后的登坡动画也读取所选角色。既有风光、照片和徽章图像不因选角重新生成。

## 素材与实现

双辫角色使用内置 **image_gen**，参考用户提供的设定图，并以现有蓝衣人物的水彩笔触、Q 版比例作为风格参考。没有使用外部付费 API、CLI 生成、Tripo 或新下载的动画库。地图继续使用已有 PixiJS；素材准备使用工程已有的 sharp。

- [完整生成提示词](../art/characters/braided-v1-prompt.txt)
- 原图：`art/characters/braided-source-v1.png`；参考：`art/characters/braided-reference-v1.png`。
- 网站图集：`dist/characters/braided-hiker-v1.webp`；蓝衣和双辫角色各有独立的卡片预览 WebP。
- [帧范围和脚底锚点](../art/characters/braided-v1.json)由 `scripts/art/prepare-braided-character.mjs` 准备，并生成 `src/characters/braided-art.ts`。源图实际为 1536 × 1024，三行高度不同，不能直接按等高格子裁切。图集保留原 alpha；预览只裁切、缩放，未画入背景。
- 行走按统一比例 `54 / 348.5` 显示，营地姿态以站立帧归一到 `54 / 284`。后续集中检查校正了两位角色的营地水平锚点，并加入 240 ms 姿态过渡；实际检查范围见下方记录。
- `src/characters/catalog.ts` 管理两位角色与选择存储，`pixi.ts` 在页面内复用已经加载的角色纹理，`picker.ts` 管理选择和取消。两条路线继续各自管理行程与相机。
- [网站人物素材记录](../dist/characters/traveler-choices-v1-credits.json)保留生成方式、来源、提示词位置和源文件哈希。蓝衣人物沿用原始素材记录。

## 编译与集中检查

首次实现时只完成 `npm run build`，记录见 `previews/character-choice-1/build.txt`。随后用户明确要求“集中检查角色切换、步态、营地动作”，现已完成相应浏览器检查与修复，详情见 [集中检查记录](character-check-2.md)。

本轮包括两人切换与取消、选择保存、观察上下坡与转弯、营地卸包坐下、过夜和清晨出发，以及多标签页中 S 弯人物一致。修复了营地姿势横向跳位和小游戏错误读取另一页角色的问题。42 项相关规则检查通过；未做实体手机、人工试听、长期硬件性能和资源失败验收，没有提交、推送或发布。
