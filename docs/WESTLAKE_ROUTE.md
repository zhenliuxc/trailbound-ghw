# 西湖 · 九溪龙井

新增第七条旅程，选用经典九溪十八涧—龙井村方向的连通选段：九溪烟树附近石板步道至龙井村口，末段接村路。154 个原始 OSM 节点，计算平面长度约 2.18 km；不是从钱塘江九溪公交站开始的全程，也不延伸到十里琅珰。

来源为 [OSM 九溪十八涧步道](https://www.openstreetmap.org/way/981902545)，way 顺序为 981902545、981902551、981902549、286073376、1415410525、1415410524。六条 way 在原节点处连接，未补画连接线，未添加假海拔。原 way 节点与整条路线的节点顺序保存在 `westlake-route-evidence.json`。地图来自 OpenStreetMap contributors，保留 ODbL 来源与署名。

路线的地方背景参考 [国家体育总局对西湖群山、龙井与九溪山径的介绍](https://www.sport.gov.cn/n20001280/n20001265/n20067706/c29452719/content.html)；[西湖景区钱江管理处的九溪介绍](https://westlake.hangzhou.gov.cn/art/2024/5/4/art_1639430_59047007.html)也记录了溪涧和汀步景观。这里只制作虚拟旅行，不提供当前通行或实时水位信息。

溪谷、茶垄与茶村房屋为程序化插画，水系沿用 OSM 坐标，路线原节点不变。三张真实区域照片来自原摄影者的 Wikimedia Commons 授权素材，等比压缩为本地 WebP（最大 960 px，单张小于 110 KB），来源和许可在图片下方折叠，保持图片完整可见。

三枚手帐徽章由内置 imagegen 生成：水绕过石头、茶树尖的新叶、村口屋檐。只在玩家点击记住时创建带地点、进度、天气和时间的旅行瞬间，不由照片打卡自动填入。旧手帐和原十八枚徽章保持兼容。完整提示词见 `BADGES.md`。

三套声音继续使用原创 Web Audio 合成，分别为溪声与短木质旋律、石径与轻拨弦、茶村与稀疏空气音色；不是现场录音。

验证包含所有七条旅程的完整结束、照片预加载和重看、PixiJS 几何编译、320/390px 及宽屏照片镜头、手帐跨路线保留。地图与徽章经过静态渲染目视检查。受管浏览器预览不可用，真实浏览器和手机排版、实机试听未验证。
