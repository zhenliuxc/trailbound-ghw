# 虎跳峡圆形手帐徽章统一

2026-10-22。用户确认按[徽章设计规范](journal-badge-design-guide.md)修复虎跳峡，统一圆形、边缘和大小。本轮修改渲染与展示，复用现有水彩画心；未重新生成原画、改动玩法或改写玩家收藏。

## 实现

- 四个现行游戏的完成图、奖励与手帐接到同一纸边。外轮廓保持正圆，米白纸环配灰金外线、草木灰内线，纸纹限制在圆环内。旧金色尖饰和圈外残点不进入最终展示。
- 共同输出画布为 `768 × 768`，圆心 `(384,384)`，外半径 `360`、画心半径 `336`。可见外径 `720`、纸边宽 `24`、四周透明余量 `24`，是规范中 1024 母版坐标的等比版本。
- 固定画作按已查看的原图配置画心裁切；两张下排素材的圆心略向上校正，避免把原图的边框带入。裁切参数集中在 `src/content/tiger-badges.ts`。
- 瀑布涂色保留原捕获构图和玩家笔触，江边取景保留快门时的圆窗、水流与主体。两关先合成画心，最后绘制纸边；不再依赖原底图边框与另写的裁切半径恰好重合。
- 旧版 576 px 动态捕获按原来的半径 249 读取画心，新增 768 px 捕获直接展示，避免反复裁切或叠加边框。
- 虎跳峡旧矩形作品在收藏墙与奖励中呈现为铺满圆形的缩略图。详情提供“查看完整原画／返回圆形徽章”，原始文件或保存的截图可完整阅读。旧版三枚图集收藏也通过相同纸边呈现。
- 原画读取、边框合成与显示不写入存储；事件 ID、首次日期、文字、取景和笔迹继续由现有收藏逻辑保存。同一缓存图片复用合成结果。

首页与共用手绘页更新了脚本和样式缓存版本。其他路线的地形、季节、行程和游戏规则未修改；共用脚本通过已有构建重新生成。

### 实际页面

在本机内置浏览器操作游戏，使用 `localhost:8000` 验证保存后的画作，同时在 `127.0.0.1:8000` 查看已有收藏。两个来源的记录均未清空或手动覆盖；`localhost` 也有既有记录，不作为全新空存档。

| 检查 | 结果 |
| --- | --- |
| 转过山弯 | 沿画面 S 弯拖动描路，放手后小人登山、播放江景，完成后返回地图；手帐可读“山弯初见” |
| 记住山色 | 实际翻出两对画片；错误配对会翻回，正确完成显示“半山灯火”和“已收进手帐”，随后自动返回 |
| 涂一页山色 | 手机竖屏拖动多笔，岩壁与草木分别达到要求；新捕获为 768 方图，纸边完整，保存后的瀑布与涂色画面可读 |
| 把江声留下 | 手机竖屏拖动圆窗，将巨石和白浪纳入后松手；新捕获保留选定构图，显示“江声入峡”和“已收进手帐”，随后自动返回 |
| 奖励与收藏尺寸 | 两张动态奖励均为 768×768，在 390×844 视口显示为 214.5×214.5 CSS 像素；四枚桌面收藏均为 128×128 CSS 像素 |
| 保存后重开 | 从地图打开手帐，筛选虎跳峡显示四关各一枚；刷新、重开和重玩没有新增同事件记录 |
| 旧矩形作品 | 已有“二十八道拐”改为圆形铺满；“查看完整原画／返回圆形徽章”可双向切换，原有日期 2026-10-18 22:08 与回忆文字仍保留 |
| 屏幕适配 | 检查 1280×900 桌面、390×844 竖屏、844×390 横屏的收藏及详情；手机触点可用，图片保持比例 |

集中验收发现并修复两处显示问题：

- 地图内嵌手帐在手机上有两枚关闭按钮重叠。共用手绘页只提供是否内嵌的标识，虎跳峡样式据此为详情关闭按钮留出空间，复测两处触控框各为 44×44 且互不覆盖。
- 矮屏横向阅读时，原 280 px 徽章被滚动区裁成半圆。虎跳峡改用紧凑的左右布局，徽章随可用高度缩放，标题、记忆与翻页仍可读；独立页和从地图打开的内嵌页均已复测。

从实际收藏墙读取四张最终显示图，检查透明通道与可见边界。四张均为 768×768，可见边界一致为 `(24,24)` 至 `(743,743)`，外径 720；圆外无非透明残点，纸环内无透明缺口。像素结果见 [geometry.json](previews/tiger-paper-badges-1/geometry.json)。本轮未逐一制造旧图集记录、模拟浏览器图片加载失败，也未进行真机或音频验收。
