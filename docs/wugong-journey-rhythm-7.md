# 武功山 · 沿途节奏与地图变化

本轮只处理武功山东江村反穿两天一夜。主地图保持 PixiJS 2D 示意与现有 Q 版人物，默认跟随，玩家主动切换全图。没有发布或提交 Git。

## 地点照片

金顶从游客与石碑近景改为已存档的 `photos/wugong-goldendome-v2.jpg`，展示金顶远望草甸山脊和远山。原作者 RoundNoName，2024-10-05，CC BY 4.0，来源为 [Wikimedia Commons 原始文件页](https://commons.wikimedia.org/wiki/File:Golden_Dome_of_Wugong_Mountain.jpg)。本轮重新读取来源、许可并查看图片，沿用此前下载的 JPEG，未修改像素。照片卡注明秋季实拍与游戏夏季示意不同。其他地点的定点／区域配图说明继续保留。

| 福星谷下山林间，走向中庵 | 新增沿途小画排序，可拖动或点两幅交换 | 林间、草甸、星夜、金顶顺序正确后主动收好 |

六处互动各属不同路段。地图仍只有七个实景打卡图标与名称，没有小游戏标记。照片与沿途互动不合并发奖；新增手帐使用独立身份、现有标签墙与去重逻辑，重玩保留首次日期、文字和画作。下山排序奖励只属于整理这项互动，不补发先前跳过的画作。原营地帮拍仍为存档，不与星夜连续堆叠。

林间插画使用 imagegen 新制，原图与提示保存在 `art/wugong-forest-leaves/`。下山纪念复用已有武功山草甸水彩，小画排序复用林间、草甸、营地与古祭坛素材。没有为其他路线添加新玩法。

## 地图和声音

地图增加移动云影、草叶和林冠随风摆动、林间落叶、偶尔掠过的小鸟。雨时有可见雨丝、湿路和水洼涟漪，雨停后湿痕缓慢消退。暮色、夜色与晨光影响实际山体和天空；营地灯亮起，入睡时渐暗。完成纸鸢后附近山坡短暂保留一只小纸鸢，完成拨云后附近谷雾变薄。

地图使用同一份天气状态控制录音混音：林间树风、开阔处风声和雨落水洼渐入渐出，夜间停用带鸟鸣的林间录音。脚步从 `.10` 降至林间 `.022`、石路 `.028`，雨中再略降低；配乐 `.085`。这些是实际实现的播放增益，不能替代人工听感验收。

新增自然声来自 Joseph SARDIN／BigSoundBank 和 Thimras／OpenGameArt，均为 CC0。风声仅下载并处理所需的完整 PCM 片段，没有将未完成的原始大文件当成完整下载。来源、片段、哈希和处理记录见 `dist/audio/wugong-journey-credits-v1.json`；可复现处理脚本为 `scripts/prepare-wugong-journey-audio.py`。均非武功山当地实录。沿用 Scott Buckley 配乐与 Kenney 布料／纸张／脚步素材。

声音需用户主动开启，静音、后台、打开奖励与手绘互动时暂停地图环境声；地图与小游戏不会叠放两份配乐。新增短互动沿用纸声反馈。
