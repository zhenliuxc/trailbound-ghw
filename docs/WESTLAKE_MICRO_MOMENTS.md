# 西湖九溪：遇见瞬间与小互动

本页记录此前九溪版本；最新七路线完整实现与验证见 [FULL_GAMEPLAY.md](FULL_GAMEPLAY.md)，当前新候选尚未部署。

六种候选分属溪谷、茶园、龙井村口三个区域，每趟各选一个。近期记录的三个瞬间权重较低，并避免完整重复该组合。原二十一枚手帐 ID、浏览器存储 key 和旧记录保留，新增落叶、水光与竹篮三枚插画徽章，共二十四枚。

| 区域 | 候选 | 互动 |
| --- | --- | --- |
| 九溪溪谷 | 石头旁的一圈水、打转的落叶 | 点水或轻划，水纹散开、落叶转动 |
| 龙井茶园 | 一点新绿、茶叶间漏下的光 | 触叶，叶片转动、光影变化 |
| 龙井村口 | 安静的屋檐、等雨停的竹篮 | 轻触后听水滴，看滴水和浅浅水纹 |

场景设定为雨后的九溪午后，沿用既有雾与晴的虚拟天气脚本及真实 OSM 路径。近景是代码绘制的插画，不是新照片或地理测绘。三枚新增手帐图由内置 imagegen 生成，提示词见 BADGES.md。

玩家主动点开才会停步。一次轻触或拖动后，约3.4秒收进手帐并回到原行走/暂停状态；静静观察6秒也会留下不同回忆。提前继续而未动作时跳过收集，错过沿途机会照常结束旅程。微互动安排在剧情与照片之间，不推进旅程时钟。后台与页面缓存暂停，换路线清理旧场景；原暂停与切后台后的暂停状态保留。声音关闭、减少动态效果或本地存储被拒绝时仍可参与。

## 声音来源与处理

从溪谷到茶园再到村口，溪水、叶声、滴水按路程混合，音量渐变，不因每帧更新而重播旋律。三个照片点使用更柔和的原创合成音色，小动作叠加较近的声音。仅开启声音并进入西湖场景时请求录音，解码结果复用；后段滴水按需要加载。下载或解码失败保留合成降级，延迟到达的旧场景素材不会重新出声。

- 溪流：Siddharth Patil / Ksd5，Swale.ogg，CC0：https://commons.wikimedia.org/wiki/File:Swale.ogg
- 叶声：Wilfredor，Leaves falling from the trees during autumn in the forest.wav，CC0：https://commons.wikimedia.org/wiki/File:Leaves_falling_from_the_trees_during_autumn_in_the_forest.wav
- 滴水：ZooFari，Water drops dripping.ogg，CC BY-SA 3.0：https://commons.wikimedia.org/wiki/File:Water_drops_dripping.ogg

原始滴水是在水龙头与水碗间录制，叶声源自加拿大森林；这些是通用声音设计素材，不称为九溪现场录音。节选、单声道、32kHz、64kbps MP3、滤波、音量整平和短首尾淡化；改编滴水 MP3 保持 CC BY-SA 3.0。完整署名、许可链接、字节数及 SHA-256 在 dist/audio/credits.json，界面署名位于关于页的声音素材折叠项。三份 MP3 合计521703字节。

## 验证范围

语法/资源检查和142项 Node 测试通过。新增10项覆盖候选池、地理顺序、最近记录、触摸拖动与点击去重、暂停/后台/页面缓存、跳过与切图、减少动态效果与拒绝存储、分层增益、素材缓存、异步过期响应、离线降级及来源许可。原照片预加载和复用检查继续通过。近景 SVG 与徽章静态目视检查完成，三份 MP3 经 FFmpeg 解码检查。

受管浏览器预览不可用；没有真实手机 CSS/GPU 排版、触摸或实机听音证据。这些检查不能证明手机上最终混音的听感。其他六条路线继续使用既有玩法和合成声景。
