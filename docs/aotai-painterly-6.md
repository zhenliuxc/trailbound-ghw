# 鳌太线四关 · 水彩画面统一

2026-10-20。本轮只处理鳌太线四个冬季小游戏的画面，路线主地图继续使用程序绘制的 2D 示意图。玩法、触发位置、过夜顺序和其他路线不在本轮改动范围内。

## 实现

- 用内置 imagegen 重绘冬林、石海、山脊、前景雪坡，以及独立的羚牛母子、帐篷和雪球。背景与物件采用暖白纸色、青灰雪影、草木灰和少量赭色，保留当前两位大眼睛 Q 版旅人。
- 石海使用画出的自然雪槽，移除三条程序轨道与光滑渐变球。雪槽前景画层与 Matter.js 碰撞路径共用同一逻辑画布。
- 人物落脚和羚牛蹄下加入克制的雪面压痕，行进足迹区分鞋印与分蹄印。画层统一叠加轻纸纹。
- 帐篷根据新画片实际宽高比显示；帐绳、地钉、营灯的绘制与输入共用布局坐标。点灯后保留暖色扩散与坐下动作。
- 游戏外框、按钮、键盘焦点和指引改用纸色与墨绿灰，保持一句核心说明；未增加规则面板。
- 原圆形徽章与已获得手帐保留，不改写首次日期、文字或画作。

素材原稿和完整提示词在 `art/aotai-painterly-v1/`，发布资源清单在 `dist/scenes/aotai-painterly-v1/credits.json`。准备脚本为 `scripts/art/prepare-aotai-painterly.mjs`，只做 WebP 编码与透明边界测量，未覆盖旧素材。

## 验证状态

沿用已获得的鳌太线集中测试授权，完成以下本轮检查：

- `npm run build`：严格 TypeScript 编译与产物构建通过。最后两次构建分别纳入营前卸包姿态、地钉可读性，以及窄屏前景下边缘柔化；构建不当作体验验收。
- 43 项针对性检查通过：`node --test tests/aotai-chapter.test.cjs tests/aotai-camera.test.cjs tests/aotai-audio.test.cjs tests/wugong-transitions.test.cjs tests/wugong-auto-journal.test.cjs`。覆盖四关规则、错误操作不发奖、过夜地点、历史收藏保留、自动入帐与淡出取消。这批在纯视觉的收尾调整前运行，后续仅复查对应浏览器画面与操作，未重复整套检查。
- 桌面浏览器：实际拖动雪球并自动完成返回；按住上梁、岩后歇脚、再次登梁，看到圆形徽章“已收进手帐”；营地两根帐绳各自拖入地钉，再点击画中的灯，进度依次为 35%、70%、90%。
- 窄屏浏览器：四关均查看实际画面。冬林中按住近侧平台退让，主路畅通后等待双方经过，最后自动返回山路；营地实际拖绳、点灯，看到暖光与坐下。手帐按鳌太线筛选显示四段回忆，保留圆形徽章。窄屏模拟不代替实体手机触控验收。
- 窄屏检查发现石海前景底边有明显矩形接缝，已在缓存画层底部增加渐隐并重新构建、重载复查；截图中的接缝已消除。没有改动碰撞路径或玩法判定。
- 石海新版页面读取到的浏览器错误日志为空。未执行全仓跨路线回归、实体手机测试或人工音频试听。
