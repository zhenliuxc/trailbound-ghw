# 七条路线与二十九幅画作的玩法讨论稿

状态：第二轮完整玩法提案。用户本轮明确“暂不测试，先设计其余画作”。云海开信、吊带追风保留已提交的实现，未测试、未发布；其余 27 项已逐项补充玩法类型、首关草案与变化空间，仍待确认。线上基线为版本 37。

目标是先确定每幅画让玩家做什么、作出什么选择、怎样完成，以及为什么值得留进手帐，再安排制作。除明确标注本轮实现的 02、03 外，下文现状以线上版本 37 为准；其余提案、时长、难度与素材补充都是讨论候选，不代表已经实现或得到认可。

## 一 这次要解决什么

版本 37 的 29 幅正式水彩纪念画均已绑定互动。其中 6 类接入了专门的小游戏模块：武功山四段、九溪推叶、竹林接雨；其余 23 类使用通用轻互动。接入独立模块不等于体验已经足够不同：武功山的云海与石坛仍然共用“对准位置后停住”的主要判断，多个场景也反复采用“三次成功后结束”。

用户已指出吊带追风、金顶石语和其他片段的玩法缺少多样性，并希望利用之前生成的手绘画作。此次讨论同时考虑两件事：让动作、思考与节奏有差异；让旧画真正参与游戏，而不是只在完成后出现。

### 已明确的要求

- 精细手绘水彩、纸张与自然材质，沿用当前色彩和品牌。手机与电脑同样重要。
- 进入、操作、反馈、完成、画作展开、收藏和继续行进，应有连续的动效表达，并配合声音。
- 场景、植物、衣着、动物与天气符合路线的美术时节。人物及动物相遇仍是游戏创作。
- 优先复用已有画作与场景，按玩法实际需要补充可动图层。
- 完成互动才获得相应图文；退出或观看不自动发奖。相同画作重玩不重复新增手帐。
- 图画和回忆合在旅行手帐标签墙中，点击查看详情；不恢复导入、导出或清空功能。
- 先讨论方案；之后按用户指定范围实施。功能完成后询问是否测试，发布不能被当作测试通过。
- 已同意把吊带追风改成邂逅美女、交谈与帮拍的故事，把武功山云海开信改成风路解谜。
- 打开玩法思路：拼图、连线、对对碰／配对消除、弹弓发射等都可采用。水彩统一画面，具体机制按画作与路线选择；不把游戏局限在观景、轻点或拖动后等待。

### 本稿建议采用的设计规则

1. 每个提案先用一个核心动词描述，例如牵线、拼合、选路、调色、系泊。动作之外还要有可理解的判断。
2. 同一路线交替安排操作、思考、创作或叙事，避免连续几个片段都在拖到某处等待。
3. 不要求 29 套完全不同的底层技术。可以复用引擎和控件，但相近玩法必须说明任务与反馈的差异。
4. 主小游戏建议约 20–40 秒，轻互动约 8–20 秒；这是待讨论的节奏目标。原有两三分钟主要是行进时长，不能把所有互动时长也算在其中。
5. 错误以局部修正和重试为主。跳过随时可用，安静体验不依赖苛刻倒计时。
6. 声音参与提示与反馈；静音时也有等价的视觉信息。手机不把悬停、精细拖拽或双指操作设为唯一方式。
7. 不统一要求“三轮”“三处”或“八次”。数量应由场景和任务决定，完成条件应有实际含义。

### 玩法机制工具箱

用户明确希望打开思路。以下机制可以成为完整的小游戏；示例用于扩展讨论，不替代逐画确认。

| 机制 | 玩家真正需要判断什么 | 可以结合手绘的方式 |
| --- | --- | --- |
| 拼图／旋转拼片 | 边缘、方向、邻接、轮廓是否正确 | 旧画裁成纸片，拼好后颜料与金边逐渐连成整幅画 |
| 连线／管道／光路 | 连通关系、顺序、阻挡与分流 | 风穿山坳、溪水找路、茶香线索；连接后有可见的流动结果 |
| 对对碰／记忆配对 | 记住位置、辨认轮廓或找到呼应关系 | 叶形、花纹、倒影或山形成对出现，配对后露出原画细节 |
| 消除／连锁 | 怎样安排交换或点选，让目标组合发生 | 茶叶、纸画色块等参与盘面；关卡有明确目标、变化和连锁反馈 |
| 弹弓／蓄力发射 | 角度、力度、弧线、风和落点 | 用水彩落果、纸团或种子表现弹射，轨迹、碰撞、回弹与声音对应 |
| 物理机关／平衡 | 重心、支点、先后顺序和碰撞 | 画架、摆动的小桥、竹制机关等适合有重量感的操作 |
| 节奏／声音组合 | 听懂或看懂节奏，选择时机与次序 | 竹雨、脚步、铃声形成有变化的一段声音 |
| 探索／拍照／轻剧情 | 找线索、作选择、构图与人物回应 | 让旧人物画与风景参与故事，操作决定留下什么瞬间 |

设计时先选择能支撑这幅画的规则，再做山野语境与水彩表现。可讨论多关、组合目标与逐步增加的难度；时长、尝试次数和奖励条件按具体玩法决定。不能只把不同照片套进同一种操作。

### 01 草浪来信 借一阵草甸的风

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-grass-letter-v4.webp)

- **现状**：上下牵线，让纸鸢依次稳住三阵风；已有水彩纸鸢、草叶网格、风流和完成过渡。
- **玩法类型**：连续飞行与牵线控制。
- **提案**：保留牵线飞行作为路线的主要操控玩法。让不同风段有明确变化：起飞时顺风、越脊时有侧向扰动、临近云海时需要缓缓放线；不只把目标高度换三次。
- **玩家判断与完成**：观察草浪和线的松紧，选择牵紧或放松；纸鸢沿连续航迹越过山脊并进入远处的稳定气流后完成。脱离气流会失去高度，但可以重新找风，不立即判整局失败。
- **素材与音画**：复用现有草甸背景、纸鸢、草叶和原画；补足不同风段的运动反馈即可。牵线摩擦、迎风时的草声与飞远后的声音距离随状态变化。
- **手机与电脑**：指尖上下牵线／方向键；避免长时间按住一个精确点。
- **首关草案，待确认**：一段从草坡起飞、穿过侧风、进入云海的连续航程；途中有可读的风向变化和宽阔的通过区域，不再以三次停稳结算。
- **变化空间**：改变侧风、放线空间与顺风带走向；保留最近一段的进度，脱风后可重新找回航线。
- **本项要定**：继续以纸鸢为主角，还是希望改回草甸本身的互动？现有飞行手感哪些部分值得保留？

### 02 云海开信 风穿云隙

图稿名：云海浮岛。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-cloud-island-v4.webp)

- **版本 37 现状**：对准不同山脊，等云让开后停稳，重复完成三处取景。
- **本轮实现，未测试未发布**：沿画面里的谷地点选或连线，从来风口接到远谷出口，再主动送风。高脊阻挡、洼地回流、未达出口分别反馈，可撤回或重画；一条合适风路完成后才获得画作。
- **已确认方向**：把摄影留给吊带追风，这里改为风路疏云。玩家根据山口和谷地画出一条风路，再送出一阵风；云流沿地形分流，薄雾散开，谷中的云海仍然保留。
- **玩家判断与完成**：判断风从哪里进入、怎样顺着山坳绕行。风路合适时，主山脊显露、云留在谷中，形成原画里的“浮岛”景象。风路不合适会让雾在山脊前积聚，玩家修改路线再试；不靠停住指尖或拍三张照片完成。
- **素材与音画**：复用原云海纪念画和已生成的云海宽幅背景，拆出高低云层与山脊遮挡。风沿路径传递，云流随后变化，声音从入口向远谷移动；完成后原手绘展开。
- **手机与电脑**：一笔画风路、点“送风”，可撤销重画；键盘可用少量路径节点规划。操作改变云的流动，不把整幅照片当作拖拽对象。
- **与纸鸢的区别**：纸鸢是实时牵线、不断调整；疏云先规划一条路径，再观察结果并修改。两项同样表现风，但判断和节奏应不同。
- **后续待体验**：本轮采用宽容的谷地节点，支持点选与连续连线、键盘规划；节点布局、提示多少与难度待试玩后调整。

### 03 吊带追风 草甸风口的邂逅

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-wind-hiker-v4.webp)

- **版本 37 现状**：看人物举手，在提示窗口轻点回应，成功三次后结束。用户已指出体验单薄。
- **本轮实现，未测试未发布**：招呼、帮拍请求、拖动构图、远近按钮、独立快门、照片预览／重拍、展示照片、人物回应和告别。照片冻结当次构图与姿态，告别后才完成；手帐继续使用原画与原 ID。
- **已明确方向**：这是在草甸风口邂逅一位漂亮女徒步者的故事，拍照应成为人物互动的主要动作。撤下上一版讨论稿的同行选路方向，本轮按帮拍轻剧情实现。
- **已采用的故事流程**：她在草坡旁回头招呼 → 简短交谈，自然提出帮她拍张照 → 玩家选择取景与构图 → 等她回头、微笑或挥手的一刻按快门 → 给她看照片，得到一句回应 → 告别，画作收进手帐。例如她可以说：“能帮我把身后的山也拍进去吗？”
- **玩家判断与完成**：通过构图让人物与草甸一起入镜，避开遮脸的草叶，捕捉一个自然的表情和动作。拍完后展示照片并结束这段交流，完成一次相遇；无需连续拍满三次。错过瞬间可以重拍，不把人物拍照做成严苛的像素对准考核。
- **素材与音画**：优先复用旧人物画的容貌、暖季衣着、背包与山野环境，以及已生成的挥手姿态。补充少量回头、拍照姿态和发丝／衣角图层，让人物在风里有自然动作。招呼、近处脚步、草声、快门、人物回应与告别串成完整过程；是否需要人物配音另定。
- **手机与电脑**：拖动取景，独立快门按钮／鼠标、方向键与快门键；构图切换或缩放提供按钮，不以双指或悬停为唯一操作。拍照发生在故事内，不需要调用设备摄像头。
- **后续待体验**：交谈节奏、构图自由度和人物反馈待试玩；本轮构图只用于当次照片预览，手帐收藏原手绘纪念。是否另存当次构图以后再讨论，仍保持同一画作一条手帐。

- **素材与音画**：复用原茶芽的形态、绿意和透光叶脉，牌面用轮廓与纹理区分，而不只靠绿色深浅。消除时卡片化成水彩晕染与细小叶影；这些是游戏符号，不冒称真实采摘分类。
- **手机与电脑**：点选两张相邻卡或短距离滑动／键盘选卡交换；盘面尺寸保证手机卡片足够大，静音仍能看清组合与连锁。
- **首关草案，待确认**：5×5 盘面、4 类明显不同的叶形；清开 6 处露光印记后春芽画完整出现。开局保留可用交换，卡住时给温和提示。
- **变化空间**：改变印记位置、加入需要连锁清开的纸带，或允许四连产生横向清扫；每关只引入一种新规则。
- **本项要定**：是否采用茶芽消除？首关先讨论相邻三连，不同时混入记忆翻牌或连连看的连接规则。

### 26 茶垄流光 叠出一片茶影

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-leaf-shadow-v5.webp)

- **现状**：移动光斑，在发亮轮廓上停住。
- **玩法类型**：透明叠影／旋转组合。
- **提案**：在纸面投影台上移动、转动几片半透明叶形，让叠出的影子与目标叶影相合。
- **玩家判断与完成**：判断叶片遮挡、角度与重叠关系，得到正确的复合轮廓后确认。单片移到亮点上不能完成整局。
- **素材与音画**：复用旧画里的叶脉、透光和茶垄配色，补独立叶形遮罩。纸上的光影变化由实际叠层产生，声音保持轻叶与纸面质感。
- **手机与电脑**：选择叶片、拖动和旋转按钮／键盘操作；允许撤销，避免手指遮住目标。
- **首关草案，待确认**：选择两片不同叶形的半透明纸片，移动并转动，让重叠后的缺口与复合叶影相符；主动确认后光沿叶脉透出。
- **变化空间**：增加第三层或改变透光深浅；难点在重叠关系，区别于石坛拼图的碎片邻接。
- **本项要定**：是否接受叠影谜题？它与石坛拼片同属空间操作，需要比较试玩后判断差异是否足够。

### 27 一盏龙井 把水注得刚刚好

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-eaves-v5.webp)

- **现状**：轻点茶盏，等待叶子舒展。
- **玩法类型**：连续注水／倾角与水量。
- **提案**：控制壶的倾角与停止时机，向茶盏注水；水流和杯内水位连续变化，注好后再陪叶子舒展一小会儿。
- **玩家判断与完成**：水流落在杯内、水位处于可接受范围并主动收壶，完成一盏茶。倒偏、过量时可重新来，不能靠一开始的点击与等待完成。
- **素材与音画**：旧茶盏、茶叶和水汽参与游戏；需分开茶壶、杯沿、水流与水面，刚性茶具不随动画变形。流水、杯内声与停水反馈对应同一状态。
- **手机与电脑**：按住注水并拖动调倾角，另有明确停水操作／键盘等价；不强制调用手机倾斜传感器。
- **首关草案，待确认**：移动壶嘴到杯口上方，缓缓倾壶注水，在宽容水位范围主动收壶；看见水位、流量和茶叶变化，倒偏可收壶重来。
- **变化空间**：再讨论杯口大小或不同水流，不同时增加温度、配方等现实专业知识门槛。
- **本项要定**：主要控制水量，还是水量加落点？建议先控制一个主要难点，保持从容。

### 28 村口茶香 茶村寻物

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-basket-v5.webp)

- **现状**：轻点后等待，基本规则与其他茶盏重复。
- **玩法类型**：场景寻物／关系线索。
- **提案**：茶村主人留下一句“水已经热了，还差几样茶席上的东西”。玩家根据篮边、檐下和桌面的动静，找回与提示相符的茶具，并摆成一张可以待客的茶席。
- **玩家判断与完成**：找对茶壶、杯和茶席垫等目标，并放回有对应线索的位置才完成；随便点遍场景不能代替物件关系判断。找错可放回，支持查看当前线索。
- **素材与音画**：原画已经有茶篮、桌凳、蒸汽和屋檐，作为主要寻物空间；补能独立取放的少量茶具与清楚放置点。物件拿起、放回和水汽变化有对应纸面、杯具反馈。
- **手机与电脑**：点物件查看、点目标位放置／键盘巡览与确认；手机提供局部放大与明确轮廓，不把小像素藏在阴影里。
- **首关草案，待确认**：一个村口小场景、3 件目标茶具和少量干扰物；从文字与图示线索判断归位，最后揭示原茶村画。
- **变化空间**：换一条主人留言或物件关系；不扩大地图和反复翻屏，也不依赖陌生文字谜语。
- **本项要定**：是否采用寻物整理？它负责空间线索与摆放，再坐五分钟保留人物交流，避免两幅画都变成等一杯茶。

### 29 再坐五分钟 与茶村主人聊两句

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-five-more-minutes-v4.webp)

- **现状**：点茶盏后等待约一小会儿，人物画出现；与同路线另外两处茶互动接近。
- **玩法类型**：分支对话／人物故事。
- **提案**：作为短的叙事歇脚片段。主人问起刚才的溪谷、春芽或路上所见，玩家选择想谈的片刻，人物用不同的动作和话语回应。
- **玩家判断与完成**：完成一段有分支结果的短对话，并主动告别；没有唯一正确回答，也不需要真的等五分钟。未玩过的场景不写成已经获得的回忆。
- **素材与音画**：旧人物泡茶画作为故事主画面，补少量递杯、抬头或倾听动作。茶水、杯具与环境声配合；人物语音是否需要，单独讨论，不默认新增配音。
- **手机与电脑**：短而清楚的对话选项／键盘选择；不要求打字。
- **首关草案，待确认**：主人问起山路所见，玩家选择一件真实遇到的片刻；经过两轮短回应和一次告别，留下这段茶席相遇。无已有记录时使用初见对白。
- **变化空间**：话题随当前路线经历变化，人物递杯、倾听与回应跟随选择；不杜撰玩家已玩过其他互动，也不要求真的等五分钟。
- **本项要定**：是否保留为独立人物片段？也可与村口茶香合成同一段故事中的两个不同结果，但合并收藏身份需要另行确认。

## 十 旧画怎么用

### 素材分工

| 现有素材 | 优先用途 | 制作前要核实 |
| --- | --- | --- |
| 29 张正式水彩纪念画 | 拼片、图案参照、故事主画面、局部细节、完成纪念 | 线上名称与旧图稿名的映射；画芯和边框能否分别处理 |
| 七幅路线宽幅背景 | 保持同一路线色调、季节与空间环境 | 能否拆出前中后景，避免把整张背景左右平移当完整玩法 |
| 武功山云海与石坛宽幅画 | 风路疏云、石坛拼片参照和观察背景 | 与旧纪念画的主体、光照和观看角度是否协调 |
| 纸鸢、草叶、竹筒、落叶、溪石、水面、挥手人物等现有图层 | 连续操控、因果动效和奖励过渡 | 锚点、可见边界、碰撞和刚性物件比例 |
| 旧版图集、修订前图稿 | 对照风格或兼容旧记录 | 不因它们存在就额外增加同一景物的收藏或换掉用户旧手帐 |

目前正式纪念画主要是 384×384 的标签版。小尺寸画片和对话中可以复用；全屏铺开、近距离放大或拆层时，应先找回原始大图。源文件记录不代表当前工作区一定拥有原图。没有原图时，明确记录缺口，再决定局部补绘，不直接放大到模糊。

画作在游戏过程中出现，只代表它是场景或解谜素材；手帐中是否已获得，仍由完成记录决定。

### 声音与动效原则

- 操作声、物体运动、判定和画面反馈使用同一状态。先有真实接中、拼合或动作，再发对应反馈。
- 采用有许可记录的录音与合适的原创音色；已有叶声拟音不冒称石声、衣料实录或当地录音。
- 动效用于解释规则：纸片锁合、风改变线的松紧、水流推动落叶、杯中水位上升，而不是在同一张图上统一加抖动和光点。
- 手机先明确操作区域与控件尺寸，桌面提供相同能力的鼠标及键盘方式。静音、减少动态效果、暂停和退出均保留。
- 延续“完成 → 画作展开 → 收进手帐 → 回到行进”，不同玩法的结束表现可不同，不强制相同的庆祝节奏。

## 十一 仍可能重复的地方

| 需要比较的提案 | 核心判断怎样不同 | 若试玩仍相似怎样处理 |
| --- | --- | --- |
| 金顶石语、海湾展开、茶垄流光 | 拼片邻接与旋转、折页展开顺序、透明遮挡叠影 | 优先保留最有画作含义的两项，另一项换规则；空间题材本身不算差异 |
| 雾隙见峰、枯树照影、一芽春信 | 翻牌记位置、可见配对找通道、相邻交换形成连锁 | 三者不共用“点两张便消失”的实际规则；若感受仍相近，替换或减少一项 |
| 云海开信、秦岭脊线 | 找到一条通往出口的谷地风路、一次经过全部指定边的一笔画 | 一项判断地形与阻挡，另一项判断连线顺序；不要用同一张连接图只换背景 |
| 草浪来信、竹叶弹弓、涉溪跳石 | 连续实时修正、单次弹道预测、连续落脚距离与检查点 | 弹射与跳跃若同样只剩蓄力条，优先调整跳石为另一方向；先比较动作节奏再决定 |
| 古道留痕、竹涛一阵、瀑布来风 | 跟随长短台阶的节奏、预判移动接滴、自主编排声音 | 主动输入、时机与结果分别对应三种任务，不因都有声音就采用同一拍点条 |
| 牛牛先请、横着也能到 | 为自己的移动选择不占通道的时间、滑动物件清出空间 | 动物自己行动，玩家分别处理时间关系和空间关系 |
| 木骡子开阔、赤径慢潮、一盏龙井 | 支撑与重心、惯性与减速、连续流量与停止 | 物理量与反馈应直接可见，避免都缩成对准中心后按住 |
| 吊带追风、村口茶香、再坐五分钟 | 人物帮拍与构图、场景寻物关系、分支交流 | 人物情绪、探索线索与拍照操作各有实际作用，不能统一成重复点击对白 |

多样性最终以试玩感受判断；“代码类型不同”“提案名字不同”都不作为验收结论。

## 十二 讨论与确认记录

### 建议下一批先比较三种主玩法

| 候选 | 为什么先做 | 需要先确认的取舍 |
| --- | --- | --- |
| 金顶石语：原画旋转拼图 | 延续武功山，直接让旧画参与游戏，容易比较“观察”与“拼合”的差异 | 先用 6 块和淡底稿，还是更自由的切片 |
| 一芽春信：茶芽消除 | 与人物摄影、连线和拼图都有明显不同的盘面决策与连锁反馈 | 先做相邻三连，首关不叠加复杂特殊块 |
| 林隙远山：竹叶弹弓 | 补足角度、力度、轨迹与碰撞的动作体验 | 先用宽目标与短程预览，再讨论侧风 |

这是制作候选顺序，尚未获得实施授权。其他画作继续按下面标准逐项讨论；竹林接雨和溪流推叶已有可复用基底，优先记录需要保留的手感。现有两项是否测试、何时发布另行按用户安排进行。

### 每项确认时要记什么

| 项目 | 需要确定的内容 |
| --- | --- |
| 玩法选择 | 采用本稿、修改后采用、换方向、暂缓，或合并讨论 |
| 核心操作与判断 | 玩家实际做什么，需要理解什么，哪里有选择 |
| 完成与错误 | 哪个可见结果算完成，错误后怎样继续，如何退出 |
| 节奏 | 主小游戏、轻互动或叙事；大致时长和难度 |
| 画作与声音 | 旧画具体参与哪里，需要补哪些图层，哪些声音是规则线索 |
| 两端操作 | 手机与电脑分别怎样完成同一任务 |
| 用户结论 | 明确记录用户原意；提案不能自行升级为已确认 |
