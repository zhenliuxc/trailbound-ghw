# 七条路线与二十九幅画作的玩法讨论稿

状态：第一轮提案，29 项均待讨论。讨论基线为线上版本 37。

目标是先确定每幅画让玩家做什么、作出什么选择、怎样完成，以及为什么值得留进手帐，再安排制作。下文的现状是已有代码行为；提案、时长、难度与素材补充都是讨论候选，不代表已经实现或得到认可。

## 一 这次要解决什么

当前 29 幅正式水彩纪念画均已绑定互动。其中 6 类接入了专门的小游戏模块：武功山四段、九溪推叶、竹林接雨；其余 23 类使用通用轻互动。接入独立模块不等于体验已经足够不同：武功山的云海与石坛仍然共用“对准位置后停住”的主要判断，多个场景也反复采用“三次成功后结束”。

用户已指出吊带追风、金顶石语和其他片段的玩法缺少多样性，并希望利用之前生成的手绘画作。此次讨论同时考虑两件事：让动作、思考与节奏有差异；让旧画真正参与游戏，而不是只在完成后出现。

### 已明确的要求

- 精细手绘水彩、纸张与自然材质，沿用当前色彩和品牌。手机与电脑同样重要。
- 进入、操作、反馈、完成、画作展开、收藏和继续行进，应有连续的动效表达，并配合声音。
- 场景、植物、衣着、动物与天气符合路线的美术时节。人物及动物相遇仍是游戏创作。
- 优先复用已有画作与场景，按玩法实际需要补充可动图层。
- 完成互动才获得相应图文；退出或观看不自动发奖。相同画作重玩不重复新增手帐。
- 图画和回忆合在旅行手帐标签墙中，点击查看详情；不恢复导入、导出或清空功能。
- 先讨论方案；之后按用户指定范围实施。功能完成后询问是否测试，发布不能被当作测试通过。

### 本稿建议采用的设计规则

1. 每个提案先用一个核心动词描述，例如牵线、拼合、选路、调色、系泊。动作之外还要有可理解的判断。
2. 同一路线交替安排操作、思考、创作或叙事，避免连续几个片段都在拖到某处等待。
3. 不要求 29 套完全不同的底层技术。可以复用引擎和控件，但相近玩法必须说明任务与反馈的差异。
4. 主小游戏建议约 20–40 秒，轻互动约 8–20 秒；这是待讨论的节奏目标。原有两三分钟主要是行进时长，不能把所有互动时长也算在其中。
5. 错误以局部修正和重试为主。跳过随时可用，安静体验不依赖苛刻倒计时。
6. 声音参与提示与反馈；静音时也有等价的视觉信息。手机不把悬停、精细拖拽或双指操作设为唯一方式。
7. 不统一要求“三轮”“三处”或“八次”。数量应由场景和任务决定，完成条件应有实际含义。

## 三 武功山 四幅画作

建议沿途次序：草浪来信 → 云海开信 → 吊带追风 → 金顶石语。让连续操控与思考片段交替出现。

### 01 草浪来信 借一阵草甸的风

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-grass-letter-v4.webp)

- **现状**：上下牵线，让纸鸢依次稳住三阵风；已有水彩纸鸢、草叶网格、风流和完成过渡。
- **提案**：保留牵线飞行作为路线的主要操控玩法。让不同风段有明确变化：起飞时顺风、越脊时有侧向扰动、临近云海时需要缓缓放线；不只把目标高度换三次。
- **玩家判断与完成**：观察草浪和线的松紧，选择牵紧或放松；纸鸢沿连续航迹越过山脊并进入远处的稳定气流后完成。脱离气流会失去高度，但可以重新找风，不立即判整局失败。
- **素材与音画**：复用现有草甸背景、纸鸢、草叶和原画；补足不同风段的运动反馈即可。牵线摩擦、迎风时的草声与飞远后的声音距离随状态变化。
- **手机与电脑**：指尖上下牵线／方向键；避免长时间按住一个精确点。
- **本项要定**：继续以纸鸢为主角，还是希望改回草甸本身的互动？现有飞行手感哪些部分值得保留？

### 02 云海开信 云海快门

图稿名：云海浮岛。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-cloud-island-v4.webp)

- **现状**：对准不同山脊，等云让开后停稳，重复完成三处取景。
- **提案**：改为一次完整的摄影时机判断。玩家移动取景框、选择想留下的山脊，在云层开合时主动按快门；不再累计三个停留点。
- **玩家判断与完成**：山脊进入画面、主体没有被厚云遮住时拍下一张有辨识度的构图。拍早了会得到被云遮挡的试拍，玩家选择重拍；允许多种合格构图，不要求复刻唯一标准答案。
- **素材与音画**：复用原云海纪念画和已生成的云海宽幅背景。云层需要独立图层；快门反馈与画面定格同步，定格后再展开纪念画。
- **手机与电脑**：拖动取景框，点独立快门按钮／方向键与 Enter；缩放若需要，提供按钮作为捏合的替代。
- **本项要定**：偏自由构图，还是有一张简短参考构图？只保留一张满意的成片，还是允许比较两张试拍？

### 03 吊带追风 与山友同行

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-wind-hiker-v4.webp)

- **现状**：看人物举手，在提示窗口轻点回应，成功三次后结束。用户已指出体验单薄。
- **提案**：改为一段有连续位移的同行小关。玩家控制脚步，在草径分岔处选择方向；风势变强时，山友会放慢并给出动作提示，玩家决定继续或停步。
- **玩家判断与完成**：读懂可见的路径和山友动作，沿一小段草脊走到会合处。走错会回到最近的分岔，落后时山友会等待；不靠重复挥手累计次数，也不设计坠落惩罚。
- **素材与音画**：旧人物画用于出场与完整纪念；已生成的三姿态人物用于等待、示意与告别。连续行走需要补少量步行姿态和可行走小径图层，不能把整幅人物照片平移当作走路。脚步、衣料与风声分别对应动作。
- **手机与电脑**：大面积前进／停步按钮，分岔时选择方向；键盘有等价操作，操作区避开人物与路径。
- **本项要定**：是否采用“同行选路”？如果更想要人物故事，可以改为有后续结果的山友对话，但不建议同时塞入两套主玩法。

### 04 金顶石语 拼回石拱画片

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/wugong-stone-altar-v4.webp)

- **现状**：拖动透镜，在石拱、石缝和苔色三个位置分别停稳；与云海取景的主要判定相近。
- **提案**：把原石坛手绘变成手帐桌面上的画片拼合。根据石缝、拱线与色块关系摆放和旋转拼片，拼成一幅完整的石拱画。
- **玩家判断与完成**：所有画片方向和邻接关系正确，石拱轮廓闭合后完成。错片可以取下重放，正确拼合有柔和吸附反馈；先以约六片讨论，不设三个独立打卡目标。
- **素材与音画**：优先直接复用旧画的画芯制作拼片，金色边框留到完成时出现。新石坛背景可作为拼片桌面旁的实景参照。这里操作的是纸画，不搬动现实场景中的石块；声音以纸片与轻微锁合声为主。
- **手机与电脑**：拖放加独立旋转按钮／键盘选择、移动、旋转；手机拼片足够大，不依赖双指旋转。
- **本项要定**：采用较自由的不规则画片，还是更容易上手的几块石纹拼片？是否全程显示淡淡的底稿？

## 四 虎跳峡 四幅画作

建议组合：看见峡谷纵深 → 歇脚整理 → 循铃遇见旅伴 → 留下一段水帘声音。不要让四段都变成“点近、中、远”。

### 05 江谷回响 看懂峡谷的远近

图稿名：江在脚下。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/tiger-river-below-v4.webp)

- **现状**：横移视线，累计移动后展开近崖、江谷与远山。
- **提案**：在左右两个观察位置切换，利用不同景物的视差，把山路、谷底江水、远峰放入正确的远近关系中。
- **玩家判断与完成**：观察哪一层移动得多、哪一层几乎不动，再完成一次完整的纵深排序；不是滑够距离就结束。排错后可回到两幅视图比较。
- **素材与音画**：复用峡谷画与路线背景，需把近崖、江水、远峰拆层。远处江声和近处风声保持距离，不因选择错误出现刺耳提示。
- **手机与电脑**：左右机位按钮与可拖放的景物卡；键盘可切机位及调整顺序。
- **本项要定**：是否喜欢这种观察推理？如果不想出现景物卡，可改为在画面中选择对应的景深层。

### 06 雪山同坐 歇脚时整理背包

图稿名：半山歇脚。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/tiger-halfway-rest-v4.webp)

- **现状**：点近、中、远处，获得不同位置的声音反馈。
- **提案**：在木椅旁打开背包，把形状不同的随身物件摆入有限空间，留下能够合上的包口。
- **玩家判断与完成**：选择摆放次序与旋转方向，物件之间不重叠、需要保留的物件均装入后合包。没有唯一摆法，也不设置现实装备知识考题。
- **素材与音画**：旧画的木椅、栏杆与远山作为完整休息场景；补背包内部及少量独立物件。布料、拉链和木椅轻响形成近声，江声仍在远处。
- **手机与电脑**：拖放、点物件后旋转／键盘选择和摆放；小物件可吸附到格位。
- **本项要定**：是否接受背包整理这个主题，还是希望歇脚片段更偏叙事？若采用整理，空间难度宜轻，不做赶时间收纳。

### 07 瀑布来风 编一段水帘合奏

图稿名：龙洞水帘。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/tiger-longdong-waterfall-v4.webp)

- **现状**：移到水帘附近停留，水雾增多后完成。
- **提案**：用水声、滴声与谷风，在一小段时间条上编排自己的水帘声景。玩家可以试听、删改，再主动留下满意的一段。
- **玩家判断与完成**：完成有效编排并试听后确认收藏；没有唯一正确旋律，也不因等满播放时长自动发奖。若只想听环境声，可直接退出。
- **素材与音画**：旧瀑布画拆出水帘与雾层，声音走到哪个位置，哪一段水帘就回应。复用许可允许的已有录音，缺少的声部再补；不声称为龙洞瀑布实录。
- **手机与电脑**：点按较大的节拍格开关声部，提供播放与撤销；键盘可操作。静音时用水纹和时间条表达同一编排。
- **本项要定**：是否采用自由创作型互动？若偏好有答案的挑战，可换成复现一段短节奏，但需与竹林接雨拉开操作差异。

### 08 铃声先到 循铃辨向

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/tiger-bell-first-v4.webp)

- **现状**：点左、中、右三处，听铃声位置，覆盖三处即完成。
- **提案**：铃声从山路拐角传来。玩家转动视线或在分岔处选方向，根据声音方位与远近变化，找到逐渐走近的驮队。
- **玩家判断与完成**：沿声源线索作出方向选择，让声音与可见的驮队汇合；不能把所有位置点一遍就过关。判断错误时声音变远，允许退回上个位置。
- **素材与音画**：旧画中的驴与赶路人作为揭示主体，补少量行走姿态、转角前景与清楚许可的铃声。静音以对应方位的视觉脉冲代替听觉线索。
- **手机与电脑**：左右转向按钮／方向键；不要求佩戴耳机才可完成。
- **本项要定**：偏声音寻踪，还是短的山路记忆？本稿建议寻踪，以区别秦岭的山形记忆。

## 五 秦岭虚拟章节 四幅画作

以观察、形状判断和给动物留出空间为主，不扩成现实穿越教学。路径只用于游戏内推理。

### 09 石海折光 石影推理

图稿名：石海棱光。[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/aotai-rock-facets-v4.webp)

- **现状**：左右改变视角，转动达到阈值后完成。
- **提案**：在手帐里转动一块石形纸模型，观察棱面和投影，找到与参考剪影相符的朝向。
- **玩家判断与完成**：根据凸起、凹面和投影关系判断角度，主动提交一次匹配；转得多不会增加完成度。提交错误时保留角度供比较。
- **素材与音画**：旧画的石纹和棱面作为参照与贴图；需要可转动的简洁模型或数个可靠视角。纹理保持水彩，不把灰色几何体直接当主画面。风声与纸模型转动声克制。
- **手机与电脑**：明确的转向按钮或拖动旋转，另有提交按钮；提供角度吸附，不要求精确到某个像素。
- **本项要定**：对比投影还是对比石块轮廓？只选一种作为主要判断，避免变成两项复杂任务。

### 10 秦岭脊线 一笔连峰

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/aotai-ridgeline-v4.webp)

- **现状**：依次点亮三个转折，显出山脊轮廓。
- **提案**：沿着可辨认的峰谷连续描出一条脊线，经过山坳时判断向哪一条轮廓继续。
- **玩家判断与完成**：笔迹跟随主要山脊并到达末端，形成一条连贯的峰线；不按点击次数结算。离开轮廓时墨线变浅，只需回到最近一段续画。
- **素材与音画**：旧山脊画提供真实可读的轮廓，描线后让原画从淡墨渐显。纸上笔触与高处风声配合，峰线不是额外发光的游戏轨道。
- **手机与电脑**：大容差的指尖描线／鼠标；键盘可在岔点选择下一段，结果仍是一条连续脊线。
- **本项要定**：是自由描线还是少量岔点选择？不建议做三处固定热点的换装版本。

### 11 雾隙见峰 记住山的样子

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/snow-light-v5.webp)

- **现状**：停住指尖，等待山雾让开即可完成。

- **本项要定**：是否接受叠影谜题？它与石坛拼片同属空间操作，需要比较试玩后判断差异是否足够。

### 27 一盏龙井 把水注得刚刚好

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-eaves-v5.webp)

- **现状**：轻点茶盏，等待叶子舒展。
- **提案**：控制壶的倾角与停止时机，向茶盏注水；水流和杯内水位连续变化，注好后再陪叶子舒展一小会儿。
- **玩家判断与完成**：水流落在杯内、水位处于可接受范围并主动收壶，完成一盏茶。倒偏、过量时可重新来，不能靠一开始的点击与等待完成。
- **素材与音画**：旧茶盏、茶叶和水汽参与游戏；需分开茶壶、杯沿、水流与水面，刚性茶具不随动画变形。流水、杯内声与停水反馈对应同一状态。
- **手机与电脑**：按住注水并拖动调倾角，另有明确停水操作／键盘等价；不强制调用手机倾斜传感器。
- **本项要定**：主要控制水量，还是水量加落点？建议先控制一个主要难点，保持从容。

### 28 村口茶香 顺着线索找茶席

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-basket-v5.webp)

- **现状**：轻点后等待，基本规则与其他茶盏重复。
- **提案**：在村口近景中观察水汽、杯具和檐下动静，结合一句人物提示，判断哪条小径通向正在等客人的茶席。
- **玩家判断与完成**：先收集能支持判断的线索，再选择小径，走到与线索相符的位置。错误方向可回头；不能把每个地方点一遍就直接获奖。
- **素材与音画**：旧村落画可拆出屋檐、小路、茶席和水汽；复用已有村景宽幅背景。声音补充线索，静音仍能从可见动静和人物文字判断。
- **手机与电脑**：点场景对象查看线索，点方向选择／键盘轮换对象；保持探索范围小，减少反复翻屏。
- **本项要定**：愿意做一小段线索探索，还是更想看茶村人物故事？若选人物故事，应与“再坐五分钟”合并讨论，避免继续重复。

### 29 再坐五分钟 与茶村主人聊两句

[查看画作](https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site/badges/westlake-five-more-minutes-v4.webp)

- **现状**：点茶盏后等待约一小会儿，人物画出现；与同路线另外两处茶互动接近。
- **提案**：作为短的叙事歇脚片段。主人问起刚才的溪谷、春芽或路上所见，玩家选择想谈的片刻，人物用不同的动作和话语回应。
- **玩家判断与完成**：完成一段有分支结果的短对话，并主动告别；没有唯一正确回答，也不需要真的等五分钟。未玩过的场景不写成已经获得的回忆。
- **素材与音画**：旧人物泡茶画作为故事主画面，补少量递杯、抬头或倾听动作。茶水、杯具与环境声配合；人物语音是否需要，单独讨论，不默认新增配音。
- **手机与电脑**：短而清楚的对话选项／键盘选择；不要求打字。
- **本项要定**：是否保留为独立人物片段？也可与村口茶香合成同一段故事中的两个不同结果，但合并收藏身份需要另行确认。

## 十 旧画怎么用

### 素材分工

| 现有素材 | 优先用途 | 制作前要核实 |
| --- | --- | --- |
| 29 张正式水彩纪念画 | 拼片、图案参照、故事主画面、局部细节、完成纪念 | 线上名称与旧图稿名的映射；画芯和边框能否分别处理 |
| 七幅路线宽幅背景 | 保持同一路线色调、季节与空间环境 | 能否拆出前中后景，避免把整张背景左右平移当完整玩法 |
| 武功山云海与石坛宽幅画 | 云层时机取景、石坛参照和观察背景 | 与旧纪念画的主体、光照和观看角度是否协调 |
| 纸鸢、草叶、竹筒、落叶、溪石、水面、挥手人物等现有图层 | 连续操控、因果动效和奖励过渡 | 锚点、可见边界、碰撞和刚性物件比例 |
| 旧版图集、修订前图稿 | 对照风格或兼容旧记录 | 不因它们存在就额外增加同一景物的收藏或换掉用户旧手帐 |

目前正式纪念画主要是 384×384 的标签版。小尺寸画片和对话中可以复用；全屏铺开、近距离放大或拆层时，应先找回原始大图。源文件记录不代表当前工作区一定拥有原图。没有原图时，明确记录缺口，再决定局部补绘，不直接放大到模糊。

画作在游戏过程中出现，只代表它是场景或解谜素材；手帐中是否已获得，仍由完成记录决定。

### 声音与动效原则

- 操作声、物体运动、判定和画面反馈使用同一状态。先有真实接中、拼合或动作，再发对应反馈。
- 采用有许可记录的录音与合适的原创音色；已有叶声拟音不冒称石声、衣料实录或当地录音。
- 动效用于解释规则：纸片锁合、风改变线的松紧、水流推动落叶、杯中水位上升，而不是在同一张图上统一加抖动和光点。
- 手机先明确操作区域与控件尺寸，桌面提供相同能力的鼠标及键盘方式。静音、减少动态效果、暂停和退出均保留。
- 延续“完成 → 画作展开 → 收进手帐 → 回到行进”，不同玩法的结束表现可不同，不强制相同的庆祝节奏。

## 十一 仍可能重复的地方

| 需要比较的提案 | 计划如何拉开差异 | 讨论后可采取的处理 |
| --- | --- | --- |
| 金顶石语、海湾展开、茶垄流光 | 拼片邻接、折页遮挡、透明叠影分别采用不同判断 | 若仍像同一种空间拼图，替换其中一项；不因为技术可复用就全留 |
| 武功山同行、莫干山石阶、九溪踏石 | 连续前进与选路、节奏落脚、回合路径规划 | 先用简短规则和示意确认区别，再决定是否都制作 |
| 江谷远近、林隙远山 | 前者比较并排序景深，后者利用遮挡选择观察位置 | 若用户认为仍是转动风景，可把一项降为不发新奖励的观景过渡；对应画作获取方式另定 |
| 牛牛先请、横着也能到 | 为自己规划退让路线、为蟹清出通道 | 保持动物自己行动；若解题感太接近，优先让其中一项改为叙事选择 |
| 三处茶主题 | 一盏龙井控水、村口茶香探索、再坐五分钟对话 | 用户可选择合并相近故事；合并前不删除画作、ID 或历史 |
| 云海取景与纯等待类片段 | 云海主动按快门；雾隙见峰要求记住并辨认山形 | 保留安静等待作为氛围，但不让等待本身替代完成条件 |

多样性最终以试玩感受判断；“代码类型不同”“提案名字不同”都不作为验收结论。

## 十二 讨论与确认记录

### 建议讨论顺序

1. 先定武功山四项，重点讨论吊带追风和金顶石语，确认多样性的尺度。
2. 再定九溪的七项，尤其是三幅茶主题画作的分工与是否合并。
3. 讨论竹林接雨、溪流推叶哪些基础值得保留，哪些手感需要改。
4. 其余路线按同一标准逐条讨论；每次只确认一条路线或几幅画，不要求一次批准全部。

### 每项确认时要记什么

| 项目 | 需要确定的内容 |
| --- | --- |
| 玩法选择 | 采用本稿、修改后采用、换方向、暂缓，或合并讨论 |
| 核心操作与判断 | 玩家实际做什么，需要理解什么，哪里有选择 |
| 完成与错误 | 哪个可见结果算完成，错误后怎样继续，如何退出 |
| 节奏 | 主小游戏、轻互动或叙事；大致时长和难度 |
| 画作与声音 | 旧画具体参与哪里，需要补哪些图层，哪些声音是规则线索 |
| 两端操作 | 手机与电脑分别怎样完成同一任务 |
| 用户结论 | 明确记录用户原意；提案不能自行升级为已确认 |
