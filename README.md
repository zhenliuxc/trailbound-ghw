# 山径 Trailbound · v0.9.1 山野动画版

两三分钟的虚拟徒步。点一次出发，小人沿卡通路线持续行走，镜头跟随；路上出现风、云、雨、雪和两次情境选择。抵达打卡点自动停下，展开真实照片。草叶随风、蝴蝶振翅、飞鸟掠过；小人会驻足、拍照和护住衣领。路边还有小景物可以点一下记住，收进跨地图保留的山野手账。最后得到属于这次行程的旅程回忆。

试玩：https://trailbound-ghw-zhenliuxc.royal-box-3224.chatgpt.site （本人私有访问）

## 这版怎样玩

1. 选择武功山、虎跳峡或鳌太线，点“出发，走一走”。不用反复点前进，也不用逐个管理物资。
2. 让小人自动走。想歇一下时点“停下来看看”，再点“继续走”；P/Esc也可暂停。切到后台会停止，不自动跳过行程。
3. 路上遇见事情时暂停，让你选一次：听一会儿风或继续赶路、等雾散开或沿路继续、穿雨衣或赶过雨路、风雪中整理防护或继续前行。选择影响步伐、感受、天气反馈和最后的回忆。
4. 三个打卡点会展开真实照片。点“把风景记住，继续走”；照片收进下方相册，可随时重看，重看结束后恢复原先的行走/暂停状态。
5. 留意路边的小插画：点地图标记或“记住”按钮，收进手账并写进本次回忆。每次最多三项，错过没有惩罚，暂停也能观察。手账只存当前浏览器；重玩保留手账，重新收集本次照片。
6. 鳌太线有提前结束的完整结局；继续走到参考末点也有旅程结尾。结束后可重玩，观察项的顺序和出现时段会改变。

“武功山练习”是只看风景的旅程，没有风险选择。可选声音默认关闭；点“声音·关”开启合成脚步、环境声与鸟鸣。声音由Web Audio生成，不是实地录音，不支持声音的浏览器仍能游玩。

## 运行

解压源码包，直接打开 `dist/index.html`，游戏和照片可离线运行。也可在自己的电脑运行：

```bash
python3 -m http.server 8000 --directory dist
```

运行资源已打包在dist中，包括固定版本PixiJS，浏览器无需安装依赖。开发检查需要Node.js 18+，首次运行先安装锁定依赖：

```bash
npm ci
npm run check
npm test
```

## 实现与验证

`geography.js`、`routes.js`保留路线与照片数据；`game.js`提供原距离插值等功能；`journey.js`负责持续行走、事件暂停、选择、照片和结局；新增 `scenery.js`生成分层插画场景，`pixi-scene.js`用PixiJS渲染光影、云层视差与水光；`discoveries.js`负责可选观察与跨旅程手账；`life.js`负责原生SVG环境动画，`motion.js`计算人物步态与情境动作；`app.js`、HTML和CSS呈现漫游界面。旧的手动物资/风险引擎保留在源码中，默认界面已经移除这些按钮。

74项自动测试通过，涵盖情境姿态、环境冻结、减少动态效果、过渡清理，以及手账保存/存储失败、观察时段、观察不打断行走、暂停观察、随机重玩，以及所有漫游路线完整结束、停留/选择冻结时间、照片重看、后台暂停、重玩、提前结束与原坐标数据。静态SVG只检查地图几何，不能当作运行截图。本次没有真实浏览器或手机测试；音效实际听感和iOS显示仍待实机确认。

本版本由ChatGPT/Codex实现，没有Cursor操作记录。源码已通过 GitHub 插件提交到 [zhenliuxc/trailbound-ghw](https://github.com/zhenliuxc/trailbound-ghw) 的 master 分支。Cursor 实作和 MLH 提交仍待完成。剩余步骤见 `docs/CURSOR_WORKFLOW.md`、`docs/SUBMISSION.md`。

## 本版场景升级

选择PixiJS 8.22.0作为画面层。山脊的明暗面、植被冠层、地表草叶/碎石、云层、溪流和水光分别绘制。PixiJS使用WebGL渲染、柔化云层与色彩滤镜，云影具有轻微视差，溪流水光动态变化，后段逐渐偏向暖色。渲染和漫游共用时间，停留时不继续自动播放。高DPI分辨率最多3倍，并限制约500万像素画布预算，色彩滤镜继承画布分辨率与抗锯齿；仅局部雾带使用低分辨率模糊。

路线折线、小人、命名打卡与可访问操作仍是同一地理坐标叠加层。GPU初始化或上下文失败时自动显示同一套新版SVG插画；不是回到旧的简单三角山。没有新GPS下载，也没有生成或改写真实照片。

PixiJS官方浏览器包完整保存在 `dist/vendor/pixi-8.22.0.min.js`，MIT许可保存在相邻文件。`package-lock.json`锁定开发依赖，资源校验会对比官方安装包和分发包哈希。完整第三方说明见 `docs/RENDERING_AND_LIBRARIES.md`。

本次检查了静态SVG视觉、实际PixiJS场景几何构建和失败降级。尚未在真实WebGL浏览器验证滤镜画面、帧率或手机能耗，不能宣称已达到特定帧率或“最高表现力”。

## v0.7 修正模糊、云雾与步态

上一版的整场景ColorMatrixFilter设置为1倍分辨率，导致高清画布经低分辨率中间纹理后再放大。这处设置已改为 `resolution: 'inherit'`、`antialias: 'inherit'`；画布随实际DPR与尺寸调整，路线和人物的SVG矢量层继续共用相机坐标。出发遮罩的整屏CSS背景模糊已移除。

云从椭圆拼接改为不规则轮廓、亮边与阴面；雾有三条独立漂移带，晴天不覆盖地形，局部模糊只用于云雾。近人物视野通过渐变边缘过渡，代替硬圆洞。云、雾和水光共用旅程时间，暂停后冻结。雨雪粒子只在天气改变时重建，避免每进度刷新都重启动画。

人物改成独立髋/膝/脚的轻量关节步态，双腿交替承重与抬脚，双臂反向摆动、躯干和背包轻微起伏，朝向沿线前方。靴底落在路线基准，小人停止时双脚站稳；开启减少动态效果时保持静止姿态。脚步声节拍与步态时钟一致。没有引入Spine或动画素材授权。

同时去掉每次文字更新都跳到相机目标的行为，相机以时间为依据平滑跟随。切换地图释放旧滤镜和雾层；仍保留GPU失败时的矢量表现。

52项测试覆盖原玩法、实际PixiJS几何、高清分辨率与滤镜配置、相机一致性、步态落地/抬脚、雾和云冻结以及切图资源清理。静态SVG预览检查了姿态与雾景。当前环境无法实测真实浏览器GPU画面，手机清晰度和帧率仍需实机复核。

## v0.7.1 背景覆盖修复

修正 PixiJS 整场景滤镜的裁剪坐标：filterArea 属于被过滤容器的本地坐标，不能直接使用屏幕宽高。现在每帧把可见屏幕反投影到地图坐标，并留两像素边缘，随镜头移动、缩放和窗口尺寸更新。

新增回归检查使用实际安装的 PixiJS FilterSystem 计算过滤后的屏幕边界，覆盖 320/390px 竖屏、桌面、横屏，以及完整路线、跟随和过渡相机共 24 种组合。53 项自动测试通过；本次仍未执行真实浏览器 GPU 验证。

## v0.9 动作与场景过渡

人物新增举起相机、驻足远望、风雪护领、观察后的短手势和结束动作，围巾随步态摆动。草甸有风吹草叶与振翅蝴蝶，峡谷有落叶、水光，雪地有浮雪、呼气与沿路线留下的脚印，飞鸟在地貌上方掠过。全部为原创代码绘制的矢量动画，运行资源仍可离线使用。

照片与情境卡片柔和入场，收起照片和收集发现有短过渡，切换地图有轻雾淡出。照片打开时镜头为人物留出上方空间。装饰层不接收点击，不暂停或推进行程，也不添加操作。详情见 `docs/ANIMATION.md`。74项自动测试通过；人物六种姿态与场景叠加经静态SVG检查。真实浏览器的CSS动效、手机排版和GPU帧率仍待实测。
